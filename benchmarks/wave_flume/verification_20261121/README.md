# 规则波水槽的时长、稳定性与探头验证

设定静水深度 0.25 m、目标波高 0.04 m、周期 1 s、人工声速 30 m/s。D16、D20 分别表示水深方向 16、20 个粒子，流体粒子数为 3,280 和 5,120。造波板用 2 个周期渐增，波高分析窗固定为 3–5 s。每个压缩 JSON 均保存生产入口直接输出的四个探头时序、运行参数和诊断量。[机器判定及各组记录名称](assessment.json)

## 固定步数掩盖了实际时长

在主线提交 `a700e87` 上请求 5 s，D16、D20 分别用完 29,539、36,924 个时间步，因 CFL 缩步仅达到 3.5451、3.3443 s。最大速度分别达到人工声速的 7.90、8.18 倍，最大密度压缩分别为 24.0%、31.8%。两次运行的输出样本数均与各自的实际步数一致。D12 的波高只有 1.92 个粒距，生产入口在积分前拒绝该配置。

更新后的驱动按物理时间积分，记录首次超过原有判据（最大马赫数 0.5 或最大正压缩率 1%）的位置，可选在该步提前结束。时窗未覆盖、记录无效或计算已超出弱可压缩范围时，均无法取得规则波通过判定。

## 动量与粒子轨迹平滑对照

新增 `--xsph-advection-only` 使用相同的邻居、相同的归一化速度修正和系数 0.1，只将修正速度用于更新粒子位置，保留压力和黏性作用后的物理速度。移动造波板时，D16、D20 分别在 0.1121 s 和 0.0882 s 超过 1% 压缩率限值。单独改变输运速度没有解决这两个网格的初始压力与密度失衡。

移动板造波时，对每一步的动量速度使用系数 0.1 的归一化平滑。下表给出 3–5 s 内的强迫频率拟合值。目标波高为 40 mm，探头位置约 1.00、1.16、1.33、1.49 m。逐探头波高容差为 10%。

| 水深格数 | 实际时长 | 最大密度压缩 | 四探头波高（mm） | 末站相位误差 | 反射/入射幅值及拟合残差 |
|---|---:|---:|---|---:|---|
| D16 | 5.0000 s | 0.631% | 10.64、8.55、6.54、4.99 | -40.0° | 28.5%（残差 0.342） |
| D20 | 4.999990 s | 1.056% | 未覆盖 | 未评分 | 未评分 |

D20 在 4.999990 s 首次超过压缩率限值。最后一次求值使用 10.42 µs 的剩余步长，前一条输出的最大压缩率为 0.276%，最后为 1.056%。原定 3–5 s 窗口判定保留未通过。另取两档均已完整记录且早于首次超限的 2.9–4.9 s 作事后诊断，四探头波高在 D16 为 10.64、8.54、6.54、5.00 mm，在 D20 为 11.98、10.05、7.65、5.95 mm。该窗口不用来改变原判定。

速度平滑改变了稳定性，得到的波场有显著沿程衰减。入反射分解假定两支波在探头区间内的振幅各自恒定，应结合归一化残差解读。下一轮应先恢复静水离散平衡，再量化相同激励下逐周期的波高与相位。

## 复算命令

在仓库根目录安装 TensorSPH 后运行。以下开关保留默认物理参数，首个命令示范完整保留未通过的短程记录。

```sh
python benchmarks/wave_flume/run.py --depth-cells 16 --simulate-time 5 --output-every 25 --stop-on-regime-exit --threads 1 --snapshots 0 --out out/stop_D16.json
python benchmarks/wave_flume/run.py --depth-cells 16 --simulate-time .3 --output-every 25 --settle 1 --xsph-settle .1 --stop-on-regime-exit --threads 1 --snapshots 0 --out out/still_smoothing_D16.json
python benchmarks/wave_flume/run.py --depth-cells 20 --simulate-time 5 --output-every 25 --xsph .1 --stop-on-regime-exit --threads 1 --snapshots 0 --out out/smoothing_D20.json
python benchmarks/wave_flume/run.py --depth-cells 16 --simulate-time .3 --output-every 25 --xsph .1 --xsph-advection-only --stop-on-regime-exit --threads 1 --snapshots 0 --out out/advection_D16.json
python benchmarks/wave_flume/regular_wave_campaign.py --records benchmarks/wave_flume/verification_20261121/*.json.gz --out out/assessment.json
```
