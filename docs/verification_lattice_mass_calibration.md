# 晶格质量校准：网格离散平衡欠账结清（L1–L5）

**日期** 2026-11-04 ｜ **范围** TensorSPH ｜ 改动：`src/tensorsph/droplet_impact.py`（新增两个辅助函数 + 一个 `Config` 开关）+ 新增 benchmark/tests/docs。
**数字来源**：本文两张结果表与末节误差表均由脚本从 `benchmarks/lattice_equilibrium/report.json`
（`run.py` 产出的唯一真值）直接生成，不经手抄；复现命令见 §7。

## 1. 问题

SPH 的和式密度是 `rho_i = sum_j m_j W_ij`。在规则格点上取「晶格质量」`m = rho0 dx^2 = 6.250000e-04 kg`
时，离散核和并不等于核积分，于是内部粒子一开始就带一个**几何偏置**

    b = (晶格质量) * sum_j W_ij - 1 。

Tait 状态方程把它折算成虚假初始压强 `p = B[(1+b)^gamma - 1]`，`B = rho0 c0^2 / gamma`。
`backlog_update_m2971.md` 的 P1 断言这个 2.4 kPa 是**普适**的（"any wcSPH case at c0=20"）。
本单把常数变成曲线：偏置只取决于格点类型与 `h/dx`，与 `c0` 无关，而**生产格点（正方形）在默认
`h/dx = 1.3` 上恰好接近精确**；2.4 kPa 属于六角格点（`benchmarks/laplace_pressure_floor` 的液滴）。

## 2. 方法

1. L1：在 `h/dx = 1.00…2.00`（步长 0.05）上分别求正方形格点与六角格点的 `sum_j W`，得偏置曲线。
   辅助函数 `tensorsph.lattice_kernel_sum` 用 float64 在整数偏移模板上求和，支撑半径 `2h` 全覆蓋。
2. L1 交叉验证：把预测的 `b` 与**真实粒子**（`make_particles` + `wall_lattice`）的和式密度对比，
   不用辅助函数验证自己。另与本仓独立测得的六角 `+5.88e-3`（`test_hex_lattice_sum_density_bias_is_systematic`）互校。
3. L2：`b > 0` 时折算成 Tait 虚假压强（`b < 0` 被自由面钳位吃掉），与 20 mm 水滴的 `sigma/R = 360 Pa` 对照。
4. L3：生产格点 t=0 内区相对密度与 `p_max/(rho0 c0^2)`，校准关/开；验收按 m2971 P1 的 `1e-4`。
5. L4：**静止水池 + 零重力 + 无表面张力**，从零速度走 100 步。此配置下唯一可能的
   驱动力就是偏置造成的压强梯度，因此任何速度都是伪流；这回答了「偏置要紧吗」，t=0 快照回答不了。
6. L5：`hydrostatic_init` 的解析质量剖面若不乘校准因子，就会与校准后的格点变成两套格点。

修复（`src/`）：`calibrated_particle_mass = rho0 / sum_j W`；`lattice_mass_unit` 统一给流体与壁面
粒子用同一质量单位（壁面参与流体密度求和，单位不一致会在壁面处留下一个 `b` 的密度台阶）；
`Config.density_calibration`（默认 False，需显式开启）用于对此做 A/B。

## 5. 注意点与适用范围

- **结论有边界**：本单证明的是「偏置与 `h/dx`、格点类型有关，校准把它对任意 `h/dx` 清零」。
  它**不**声称解决了自由面压强闭合（`laplace_pressure_floor` 的 C3/P0），后者与偏置正交（C2 只贡献 ±9 pt 稳态）。
- 校准是**几何**修正，不改变物理：默认 `h/dx = 1.3` 下质量只变 `5.3e-05`（相对），
  故本仓既有算例与门限无需重定基线；只有把 `h_factor` 调离 1.3 的配置才会看到实质差别。
- `dam_break.py::make_column` 仍用未校准质量（其 B2 实验门限已按现质量标定，本单不动），
  同一行修改可用，留作后续单，避免在本单里重定已验收的 dam-break 基线。
- L4 的 `density_err ≈ 0.24` 是自由面密度亏缺（全粒子最大值），与偏置无关，校准前后几乎不变；
  它不是本单的判据。
- 偏置为**负**时 Tait 钳位把它抹掉，但底下的 `rho/rho0 - 1 < 0` 仍是真实的密度误差，
  会在表面张力/绝对压强类判据里以别的形式出现，所以仍应校准而不是依赖钳位。

## 6. 误差判定（对标基准：离散和式密度的解析定义 `rho0`）

| 关键量 | 基准 | 校准前 | 校准后 | 是否 <3% |
|---|---|---|---|---|
| 内区相对密度（h/dx=1.3） | 0 | -5.326e-05 | -1.632e-07 | 是（5.33e-03% → 1.63e-05%）|
| 内区相对密度（h/dx=1.5） | 0 | +3.440e-03 | +1.562e-07 | 是（0.344% → 1.56e-05%）|
| `p_max/(rho0 c0^2)`（h/dx=1.5, c0=20） | 0（<1e-4 验收） | 3.48e-03 | 9.54e-07 | 是 |
| 静止水池 v_max（h/dx=1.5） | 0 | 0.0956 m/s | 0.00006 m/s | 是 |
| hydrostatic 剖面 RMS | 0 | 5.387e-05 | 6.705e-07 | 是 |

结论：校准后所有关键量相对解析定义的误差均 **<3%**（实际 <1e-5），m2971 P1 的
`p_max/(rho0 c0^2) < 1e-4` 验收在 8 个算例上全部通过；未校准侧如实记录
`h/dx = 1.5` 的 3.48e-3（1.39 kPa）与自生流速 0.096 m/s 作为反例。
