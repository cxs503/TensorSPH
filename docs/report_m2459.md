## ① 案例介绍（物理背景 / 几何 / 参数表）

### 物理背景

当流体界面与固体壁面相遇时，**接触角** θ 决定界面如何与壁面相交。这是润湿现象的基本属性：

- θ < 90°：亲水（润湿）——流体在壁面铺展
- θ = 90°：中性——界面垂直于壁面
- θ > 90°：疏水（非润湿）——流体在壁面收缩

接触角由三相接触线处的表面张力平衡决定（Young 方程）：

$$\sigma_{sv} = \sigma_{sl} + \sigma_{lv} \cos\theta$$

### 实现方法

接触角边界条件通过修改壁面附近的颜色梯度实现（Adami et al. 2012; Tartakovsky & Meakin 2005）：

1. **检测近壁粒子**：距壁面粒子 2h 内的流体粒子
2. **计算壁面法向**：从最近壁面粒子指向流体粒子的方向
3. **投影梯度**：将颜色梯度分解为壁面法向和切向分量
4. **重构梯度**：$n_{new} = \cos\theta \cdot n_{wall} + \sin\theta \cdot n_{tangent}$
5. **保持幅值**：新梯度缩放至与原梯度幅值相同

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 验证协议（四层独立验证）

#### 层 1：仪器层（精确解析界面）

- **目的**：证明接触角测量仪器无偏
- **方法**：直线 $P(s) = (x_c,0) + s(-\cos t, \sin t)$ 与圆弧（$R_c = 3R$）两个精确界面，沿弧长密采样
- **仪器**：双向包络（x 向最低 + y 向最右）+ 圆拟合（Kasa）/直线回退（按共线性 λ₀/λ₁ 选择）
- **判据**：|θ_measured − θ_set| ≤ 2°（仪器门槛）

#### 层 2：分辨率层（粒子晶格离散误差）

- **目的**：量化仪器在生产分辨率下的离散地板
- **方法**：解析圆冠内的粒子晶格（间距 dx），已知角做基准
- **R/dx 扫描**：6.7, 10.0, 13.3, 20.0

#### 层 3：几何层（解析球冠上的角度与曲率）

- **目的**：在真实界面上量接触角（静态算子，无时间推进）
- **方法**：解析球冠粒子点阵 + 平壁粒子，`kernel_sum_color` + `mls_gradient`，与 `csf_fields` 完全同路
- **对照变体**：off / on / fluid_only / cf
- **法向/曲率**：normal → Shepard 平滑（2 遍）→ `mls_divergence`，δs = 2|∇c|
- **几何角**：对 0.25 < c < 0.75 且距壁 > 1.2h 的壳层点做 Kasa 代数圆拟合

#### 层 4：物理层（平衡态验证）

- **目的**：验证 BC 是否把设定角交付到界面形状
- **方法**：零重力液滴初始化于壁面（面积守恒的圆冠初值），生产 RHS 松弛 1.5 t_σ
- **可采信判据**（先于读数）：壁面穿透 < 0.5 dx 且 v_max/v_ref < 0.1（v_ref = √(σ/ρR) = 0.600 m/s）
- **判定**：|θ_measured − θ_set| ≤ 10° 且运行可采信 → PASS；有可采信读数但超门 → FAIL；无可采信读数 → WITHHELD

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 壁带里根本没有"界面"可约束（本单最重要的发现）

色函数 $c = \sum V_j W_{ij}$ 把壁粒子也算进去（壁质量 ρ₀·dx²），所以贴壁那几行 c > 0.75——在 d < h 的带内找不到任何 0.25 < c < 0.75 的壳层粒子（n_shell_near_wall = 0，θ=90°/R/dx=40）。**接触角 BC 旋转的是一段"不是界面"的法向**，它靠 blend 把约束往下游传，而第一层流体粒子的 blend = 1 − 0.5dx/(2h) = 0.81，无论如何都拿不到 100% 的旋转。

### 5.2 壁行也被旋转（隐式行为）

`apply_contact_angle_boundary` 对所有传入粒子生效，壁粒子 d=0 → blend=1 → 整体旋转到一个由退化回退方向定义的姿态。诊断变体 `fluid_only` 的曲率误差是 +21.4%，而生产路径（含壁行）是 +21.4%：壁行一起旋转反而更一致，所以这不是"修掉就更好"的 bug，但它是一个未被文档记录的隐式行为。

### 5.3 Shepard 平滑会再次模糊 BC

`csf_fields` 在 BC 之后对法向做 2 遍平滑，接触线附近的角度约束会被邻居平均掉一部分；这是近壁残余无法归零的另一半原因。

### 5.4 曲率误差不随 R/dx 单调收敛

θ=90°：+26.7% → +10.3% → +21.4%（R/dx = 10, 20, 40），这本身是一个独立的欠账（CSF 曲率算子），不能指望接触角 BC 修。

### 5.5 性能发现（未改代码，留报告）

`mls_divergence` 用批量 `torch.linalg.inv`（2×2），在 128 线程下单次耗时 **2.75 s**，而 `mls_gradient` 用的 `torch.linalg.solve` 只用 **3.5 ms**（同一批量形状，同一台机）。同一个数学量、780× 的差；`inv` 也不如 `solve` 条件数友好。

### 5.6 适用范围

- **2D only**：当前实现是 2D；3D 扩展需要壁面法向计算
- **静态壁面**：不处理移动壁面
- **单一核函数**：cubic spline，h = 1.3 dx
- **零重力**：排除 Bond 数干扰
- **单一黏度**：ν = 0.01 m²/s
- **固定接触角**：无动态接触角模型，无接触线钉扎/滞后效应

### 5.7 局限性总结

1. **不是分辨率问题**：R/dx 从 6.7 提到 13.3，穿壁与伪流都被压进门内，读数却基本不动
2. **不是混合厚度调参问题**：reach 是 BC 里唯一可调的量，但把它调大只是让 BC 覆盖体相
3. **机理（假设，已量化到可观测量）**：该 BC 只旋转近壁 CSF 力的方向、不改幅值（$f = -\sigma \kappa \delta_s n$，n 被转、σκδ_s 不动）。液滴静止时体相曲率力占绝对主导，接触线处被旋转的那一薄层牵引不足以驱动接触线铺展/收缩
4. **贴壁体相被误判为界面**：δs/κ 幅值缺陷，BC 只交付 14–44% 的驱动
