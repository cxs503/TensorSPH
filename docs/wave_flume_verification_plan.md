### 1.3 失败根因分析

**分辨率不足**：H/dx=2.6 意味着波峰只被 2-3 个粒子分辨。SPH 的核光滑需要至少 3-5 个邻居才能准确估计梯度，波面曲率估计需要更高密度。

**无启停瞬态处理**：原运行 `settle_time=0`、`viscosity_settle=0`、`xsph_settle=0`。静水初始条件在粒子格点上存在 O(dx) 的不平衡力，直接启动造波会激发高频数值噪声。

**无反射控制**：`active_absorption=0.0`，仅靠被动海绵层。对于 T=1.0s 的波，海绵长度 0.98m ≈ 0.75λ，吸收不充分。

**时间步长过紧**：dt=7.5e-5s 导致 21268 步仅模拟 2.86s，未达到测试要求的 3.0s。

## 2. 改进方案

### 2.1 参数推荐

| 参数 | 原值 | 推荐值 | 理由 |
|------|------|--------|------|
| depth-cells | 16 | 40-50 | H/dx 从 2.6 提升到 6.4-8.0 |
| settle_time | 0.0 | 1.0s | 让静水不平衡力衰减 |
| viscosity_settle | 0.0 | 0.02 | 短波耗散器（∝k²），压粒子尺度抖动 |
| xsph_settle | 0.0 | 0.1 | 速度场平滑，抑制启动瞬态 |
| active_absorption | 0.0 | 0.5 | 造波板主动吸收反射波 |
| simulate-time | 2.86s | 6.0s | 覆盖 6 个波周期，充分稳态 |
| sponge_strength | 4.0 | 4.0 | 保持（已足够） |
| density_diffusion | 0.1 | 0.1 | 保持（δ-SPH 标准值） |

### 2.2 预期效果

- H/dx=8 时，波面分辨率足够，波高误差应 <5%
- 主动吸收 + 海绵层 → 反射系数 <0.1
- 启停瞬态处理 → 逃逸粒子 = 0，密度压缩 <0.05
- 6s 模拟 → 充分稳态窗口用于谐波拟合
