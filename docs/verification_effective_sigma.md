# 有效表面张力复核：CSF 算子的全局力 vs 解析 2σ（验证欠账）

**仓库**: TensorSPH ｜ **工件**: `benchmarks/effective_sigma/` ｜ **测试**: `tests/test_effective_sigma.py`

## 背景（为什么这张单存在）

`tests/test_laplace_pressure.py::test_effective_surface_tension_at_the_documented_resolution` 在 m2447 钉住 0.79±0.06（当时默认曲率算子为 `mls`）。m2979 把默认曲率算子改为 `fit_quadratic`（点态曲率误差 +25 % → <6 %），实测比值移到 ~0.71，钉死测试变红。本单把「有效表面张力」作为独立验证量做分辨率阶梯，回答两个问题：

1. 0.71 是离散误差（h→0 时回到 1.0）还是系统性算子偏差？
2. m2979 的算子切换对**全局力**（Young–Laplace 平衡真正看到的量）是改善还是恶化？

## 解析基准

圆滴上 CSF 面力 `f = -σ κ δ_s n`，κ = 1/R、n 为外法向。右半部积分（单位深度）：

    F_x = σ ∫ (1/R) n_x dA = σ ∫_{-π/2}^{π/2} cos t dt = 2σ

故 `|F_right| / (2σ) → 1.0`（h→0，一致离散化）。任何低于 1.0 的平台值都是系统性偏差。

## 判定

- **0.71 不是分辨率误差**：`fit_quadratic` 随细化**单调远离** 1.0（0.7106 → 0.6818 → 0.6500），`mls` 在 0.77–0.79 走平——两者在测试范围内都不收敛到 1.0。
- m2979 的切换改善了**点态曲率**误差，但**全局力**从 0.79 掉到 0.71：点态精度与积分精度发生了反向交换。
- 有效表面张力误差 21–29 %（`fit_quadratic` 最细档 35 %），**>15 % 平台门槛，判 WITHHELD**；是否 <3 %：**否**。
- 这是 Young–Laplace 压差欠账（m2971 P0 自由面闭合之外）的**第二个独立门槛项**：即使自由面压强闭合做完，σ_eff 偏低仍会把压差读数整体压低。

## 后续（P0 候选）

CSF 力装配需要一次**积分一致性**校准：在圆滴上要求 `|F_right|/(2σ) → 1.0`（或按 R/h 外推），而不是只盯点态 κ 误差。候选做法：δ_s 归一化（∫δ_s dV = A_s）或 κ·δ_s 乘子的圆滴标定。属 `src/` 改动，需单独派单（本单只验证、不改模型）。
