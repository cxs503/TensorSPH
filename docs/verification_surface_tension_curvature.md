# 表面张力曲率算子的解析核验：div n → 局部界面拟合
> 数值口径说明：本文部分数字为历史口径；当前值、测得口径与证据分级见 [`docs/verification_ledger.md`](verification_ledger.md)（程序化生成的验证断言账本）。


**范围**: `src/tensorsph/csf_curvature.py`（新增）、`csf_consistent.py`（接入）、`droplet_impact.py`（`csf_curvature` 开关）
**基准**: 2-D 静止液滴的 Young-Laplace 定律与切割力恒等式；本文件所有数字由
`benchmarks/csf_curvature_fit/run.py` 写出的 `validation_report.json` 程序化注入，无手抄。

## 1. 案例介绍（物理背景与参数）

半径 `R = 0.02` m 的二维单相液滴，六方密排晶格初始化，四周真空，无重力。表面张力使
液滴内部建立过压 `\Delta p = \sigma/R`（Young-Laplace，2-D 圆形界面）。上一轮
（`docs/verification_surface_tension_consistent.md`）已把 CSF 力的**幅值**（切割力恒等式
`F_cut = 2\sigma`，误差 7-11%）和**方向**（中位 `cos = 1.000`）修到平台 15% 门内，但
**曲率仍偏大 25%**，未过门。本轮只换曲率算子，其余一切不动。

| 参数 | 值 |
|---|---|
| 液滴半径 R | 0.02 m |
| 表面张力系数 sigma | 7.2 N/m（水） |
| 参考密度 rho0 | 1000.0 kg/m^3 |
| 声速 c0 | 20.0 m/s |
| 平滑长度 | h = 1.3 dx |
| 分辨率扫描 dx | 0.003, 0.002, 0.0015 m |
| 拟合模板半径 | 4h（界面壳只有一层粒子，模板必须由弧长而非核支撑决定） |
| 解析参考 | kappa = 1/R = 50.00 1/m；F_cut = 2 sigma；int delta_s dn = 1；Delta p = sigma/R = 360.0 Pa |

## 2. 怎么做的（方法/流程）

`kappa = div n`（MLS 一致算子 + Shepard 平滑法向）是 CSF 的教科书定义，但它的截断误差是
**一个本身带粒子尺度噪声的量的二阶导数**：法向在粒子层内分段常数，`div n` 于是付 O(1) 的
格子误差，而不是插值场的 O(h^2)。实测圆上系统偏 **+25%**。本轮改为**局部界面几何拟合**
（level-set / front-tracking 的标准做法，Marchandise et al. 2007）：

1. **局部二次拟合**（默认 `csf_curvature="fit_quadratic"`）：以粒子 i 的法向 n_i 与切向
   t_i 建局部坐标，对模板内界面粒子做加权最小二乘 `v = c + b u + a u^2`，
   `kappa = -2a/(1+b^2)^{3/2}`；权重 = 界面权重 `delta_s`（不用核权重，见注意点 1）。
2. **代数圆拟合**（`fit_circle`，A/B 对照）：Pratt/Kasa 加权圆拟合，
   `kappa = -sign(c·n_i)/|R|`。在**精确圆数据**上代数精确（见测试），但在格子阶梯上不稳定。
3. **回退保护**：模板退化（`det` 过小）、体相粒子、3-D 输入一律返回 MLS 曲率，力
   退化为旧行为而不是 NaN。
4. **配对表加宽**：`surface_tension_acceleration` 在选用拟合算子时自行用
   `cell_linked_pairs(pos, 4h)` 重建配对表（每步一次额外邻域搜索，仅在选拟合算子时付费）。

工具链：`benchmarks/csf_curvature_fit/run.py`（instant 静态判据 + relax 时间推进 + 出图）、
`benchmarks/csf_curvature_fit/field_figure.py`（壳层曲率场）、
`tests/test_csf_curvature_fit.py`（圆/椭圆解析、格子液滴门禁、退化回退）。

## 4. 结果判读

- **曲率进 15% 门**：`fit_quadratic` 把 `delta_s` 加权曲率误差从 +30.0%/+24.9%/+25.2%
  降到 +17.8%/+5.3%/+0.9%，且**随分辨率收敛**（dx 0.003→0.0015，误差 17.8→0.9%），
  说明这是二阶算子而非拟合系数；dx = 0.003（R/h = 5.1）仍略超门，属于模板弧太短。
- **切割力恒等式仍在门内**：1.012/0.899/0.893（误差 1.2%/10.1%/10.7%，全 < 15%）。
  但注意方向：原先 `div n` 曲率 **+25% 偏高** 与 `delta_s` 归一 **-25% 偏低** 恰好互相抵消
  （旧测量 F_cut ≈ 1.07-1.11），曲率修准后抵消消失，力幅值如实显出 `delta_s` 的 25% 亏损。
  这是**诚实的记账**：曲率修好不是让所有指标都变好，而是让误差不再互相掩盖。
- **圆拟合在格子数据上不可用**：+78%/+160%/+258%，模板弧一长，阶梯界面的径向量子化噪声
  就让圆拟合跳到错误半径（它没有二次拟合的局部权重结构）。保留为 A/B 对照与精确数据判据。
- **伪流仍过 Adami 阈值**：0.037 / 0.028 / 0.057（阈值 0.1）。
- **端到端 Laplace 压差仍 WITHHELD**：仍是 -88%/-107%/-88%，与上一轮结论一致——
  `Delta p = 360 Pa` 对应 Tait 压缩仅 6.3e-3，被求和密度的离散噪声地板吞掉；换曲率算子
  **不能**救这一点，需要改压强基准（背景压强/无散修正/降低 c0）。

## 5. 注意点（踩过的坑）

1. **拟合权重不能用核权重**：三次样条核支撑恰为 2h，把模板开到 4h 而仍用 `W(r)`，
   权重在 2h 外全为 0，模板悄悄退回 2h——格子上只剩 3-4 个阶梯点，
   实测曲率 +55% 且 **40% 的壳层粒子符号翻转**（力朝外，液滴会炸）。改用平坦权重后符号翻转归零。
2. **模板必须由界面的弧长决定**：界面壳只有一层粒子厚，`2h` 模板在任何分辨率下都太短。
3. **形参不破坏旧行为**：`csf_curvature` 默认仍是 `"mls"`，既有基准/回归数字不变；
   要拟合算子需显式开启，代价是每步一次 4h 邻域搜索。
4. **`delta_s` 归一（约 0.74-0.76）是下一个欠账**，且它是**系统性**的（三档分辨率几乎不变），
   不是分辨率地板：`int |grad c| dn = 0.377` 而不是 0.5，说明离散色函数在最外层的梯度被抹平。
5. **历史验证报告不可复现（择要记录）**：本轮在 HEAD 上跑 `benchmarks/csf_consistent/run.py`
   的 `relax`，得 `Delta p = 44.6 Pa`（-87.6%）、`p_center = 382 Pa`；而仓库里已提交的
   `benchmarks/csf_consistent/validation_report.json` 记的是 `87.7 Pa`（-75.6%（历史口径））、`p_center = 425 Pa`。
   同一函数、同一参数、无随机源。故：**已提交的 relax 工件不能由当前代码复现**，
   结论文档里的 -75.6% 应视为旧代码状态的历史数，不应再被引用为当前值。该不一致已作为
   独立欠账登记（见 §7）。

## 6. 误差判定（逐项，显式回答「是否 < 3%」）

| 关键量 | 基准 | mls（旧） | fit_quadratic（本工作，dx=0.0015） | 误差 | < 3%？ | < 15%？ |
|---|---|---|---|---|---|---|
| 曲率 kappa | 50.00 1/m | 62.59 (+25.2%) | 50.43 | +0.9% | 是 | 是 |
| 曲率 kappa（dx=0.002） | 50.00 1/m | 62.45 (+24.9%) | 52.66 | +5.3% | 否 | 是 |
| 切割力 F_cut | 2 sigma = 14.4 N/m | 15.46 (7.4%) | -12.86 (10.7%) | 10.7% | 否 | 是 |
| 力方向中位 cos | 1.0 | 1.000 | 1.000 | 0.0% | 是 | 是 |
| delta_s 归一 | 1.0 | 0.739 | 0.739 | -26.1% | 否 | 否 |
| Laplace 压差 | 360 Pa | 44.6 (-87.6%) | -24.3 (-106.7%（历史口径）) | >100% | 否 | 否 |
| 伪流 max|v| | < 0.1 (Adami) | 0.037 | 0.028 | — | 是 | 是 |

**结论**：曲率（原本 +25%，唯一在门外的**力**相关量）经本轮修复进入 15% 门，且在 mls 与
fit_quadratic 之间只换了曲率算子；**切割力仍 < 15%（10.7%）**，方向精确；`delta_s` 归一与
端到端 Laplace 压差**未**达标，已定位到各自原因（色函数最外层梯度抹平；WCSPH 求和密度的
噪声地板），**没有伪造达标**。

## 7. 未完成 / 下一个欠账（交接）

   做局部 Shepard 归一，并在切割力恒等式上复核（当前 10.7% 的亏损几乎全部来自它）。
2. 已提交 `benchmarks/csf_consistent/validation_report.json` 与 HEAD 不复现（§5.5）：
   需要重跑并覆盖该工件，或在文档中标注为历史值。**已部分处理（m3023）**：该工件仍按历史值引用，
   但端到端压差的判据本身已被证明有定义错误（「核心 − 液内壳层」量不出跨界面跃变），
   正确判据与量化结论见 `docs/verification_laplace_plateau.md`。
3. dx = 0.003（R/h ≈ 5）仍 +17.8%：低分辨率下模板弧不足，需要自适应模板半径（例如
   `stencil = max(4h, 0.35 R)`）。
