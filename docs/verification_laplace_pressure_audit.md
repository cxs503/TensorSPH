# Young-Laplace 压强判据的核验审计：判据本身怎么错的，压强到底差多少

**范围**: `benchmarks/laplace_pressure_audit/`（新增）、`src/tensorsph/droplet_impact.py`（新增 `density_renormalization` 开关，默认关）
**基准**: 2-D 静止液滴的 Young-Laplace 定律 `Delta p = sigma/R`；本文件所有数字由 `benchmarks/laplace_pressure_audit/run.py` 写出的 JSON 程序化注入，无手抄。

## 1. 案例介绍（物理背景与参数）

半径 `R = 0.02 m` 的二维单相液滴，六方密排晶格初始化，四周真空（`p_gas = 0`），无重力。表面张力使液滴内部建立过压 `Delta p = sigma/R`。这是 CSF 表面张力模型唯一能定义「力是否正确」的解析判据。

| 参数 | 值 |
|---|---|
| 液滴半径 R | 0.02 m |
| 表面张力系数 sigma | 7.2 N/m（水） |
| 参考密度 rho0 | 1000.0 kg/m^3 |
| 声速 c0 | 20.0 m/s |
| 状态方程 | Tait, gamma = 7 |
| 平滑长度 | h = 1.3 dx（case 表里逐条给出） |
| 解析参考 | Delta p = sigma/R = 360.0 Pa；所需 Tait 压缩 0.00630 |
| 判据 | 15% 平台门；3% 论文门 |

## 2. 怎么做的（方法/流程）

### 2.1 先修判据，再谈精度

历史 harness（`benchmarks/csf_consistent`、`benchmarks/csf_curvature_fit`）把

```
dp = p(r < 0.5R) - p(0.80R < r < 0.95R)   与   sigma/R 比较
```

当作 Young-Laplace 判据，并据此报出 -75% ~ -98% 的失败。**这个比较在物理上不成立**：`0.80R < r < 0.95R` 仍在液滴**内部**，静止液滴内部 `grad p = 0`（表面力只存在于界面壳），所以该差值的连续解期望值是 **0 Pa**，而不是 `sigma/R`。用 `sigma/R` 去要求它，任何正确实现都必然「失败」。

本轮改为测量真正的 Young-Laplace 关系（`p_gas = 0`）：

```
p(interior, r < 0.4R)  =  sigma/R + p_gas  =  sigma/R
```

同时保留历史判据的数值以便复现（`legacy_measure`），但**不**把它挂验收标志。

### 2.2 误差预算

WCSPH 的压强由求和密度经 Tait 方程得到，`delta p = gamma B (delta rho)/rho0`，因此我们同时报告：核内密度的时间脉动（→ 时间标准误 SEM）、核内密度的**空间**离散（→ EOS 压强噪声地板）、以及每个时刻的瞬时散布。判据若小于噪声地板，读数就不是精度问题。

### 2.3 分离「力」与「压强响应」

`shell_flux = -int f_r dn` 直接由 CSF 力场积分得到（理论值同为 `sigma/R`），与压强场完全无关。两条独立量一起看，才能把「力算错了」和「力对了但压强没响应」分开。

### 2.4 运行长度用毛细时间计

`dt` 随 `dx` 缩小，等步数比较的是不同物理时刻；且核内压强在 `t ~ 1 t_sigma` 仍在衰减，所以所有算例统一跑到 `t_end = 2.8 t_sigma`，第二半段做时间平均。

工具链：`benchmarks/laplace_pressure_audit/run.py`（推进+诊断+出图）、`tests/test_laplace_pressure_audit.py`（判据定义与机理的回归钉子）、本文件由 `make_doc.py` 生成。

### 3.3 误差预算

| 量 | dx = 0.003 | dx = 0.002 | dx = 0.0015 |
|---|---|---|---|
| 核内压强时间标准差 [Pa] | 27.95 | 30.27 | 21.77 |
| 时间标准误 SEM [Pa] | 6.78 | 6.05 | 3.79 |
| 核内密度空间离散 (drho/rho0) | 0.002532 | 0.000821 | 0.000253 |
| EOS 压强噪声地板 [Pa] | 1012.7 | 328.5 | 101.3 |
| 噪声地板 / (sigma/R) | 0.305 | 0.160 | 0.064 |

核内密度的**空间**离散换算成 EOS 压强约 300-460 Pa，与 `sigma/R = 360 Pa` 同量级（`noise_over_theory` ~ 1），而所需压缩只有 0.00630。所以在 `R/dx = 6.7-13.3` 上，求和密度本身的格子缺陷就与信号同量级——这是**测量上限**，不是可以靠加长时间平均消掉的随机噪声。

### 3.4 时间窗口的影响（同分辨率、跑到 5.6 t_sigma）

| 运行长度 | t_end/t_sigma | p(interior) [Pa] | 相对误差 | 核内密度时间均值 |
|---|---|---|---|---|
| 2393 步 (dx=0.002) | 2.80 | 210.9 | -41.4% | 1.000433 |
| 4786 步 (dx=0.002) | 5.60 | 107.3 | -70.2% | 0.999918 |

这是本文最硬的一条读数：核内过压是**衰减中的暂态**，不是收敛值。窗口从 2.8 t_sigma 拉到 5.6 t_sigma，`p(interior)` 从 210.9 Pa 掉到 107.3 Pa（-41.4% → -70.2%），核内密度时间均值回到 0.999918（已低于 rho0）。即：本离散下的静止液滴**站不住** Young-Laplace 过压，稳态趋向 0 过压；3.1 表中 2.8 t_sigma 的 -41% 相对稳态而言已经是偏乐观的读数。这也是把「时间长一点就好」这条路直接否掉的证据。

### 3.5 试修：Shepard 密度重整化（默认关）

按机理直接补一刀：`rho_i <- sum_j m_j W_ij / sum_j V_j W_ij`（Dilts 1999；Colagrossi & Landrini 2003），它把**核截断造成的几何性自由面亏损**还原，并对局部均匀密度精确。`Config(density_renormalization=True)` 打开。

| 量 | 关闭 | 打开 |
|---|---|---|
| p(interior) [Pa] | (见 3.1) | 232.1 |
| 相对误差 | — | -35.5% |
| 界面壳最低 rho/rho0 | 见 3.2 | 0.9583 |
| 界面壳最高 p/(sigma/R) | 见 3.2 | +0.000 |

结果：重整化把界面壳密度从 0.78-0.94 抬到 0.96-0.98（机理判断正确），但壳层压强**仍是 0**——重整化后的壳层密度恰好回到 `rho0`，`Tait(rho0) = 0`，钳位依旧。所以这条不是解，记录为**负结果**，避免后人重复。

## 5. 注意点（踩过的坑 / 适用范围）

1. **判据定义比精度先要命**：历史 -75%/-98% 是拿「两个内部点之差」对 `sigma/R`，连续解期望值是 0。本轮的新判据给出 -40%~-41%，历史数值仍可复现但不再作为验收。
2. **等步数 ≠ 等物理时间**：`dt ~ dx`，用等步数做分辨率阶梯会混进时间窗口的差异；本文所有算例以 `t_end = 2.8 t_sigma` 计（`Config` 里 `steps` 由 `t_sigma/dt` 反算）。
3. **两条力积分估计在松驰后的构型上不一致**：初值晶格上的切割力恒等式是 1.07-1.11，而本文在松驰构型上按柱坐标求的 `-int f_r dn` 只有 0.41。差异来源（粒子重排后 `delta_s`/`kappa` 改变、`V = m/rho0` 与真实局部密度不一致、半平面与径向积分的敏感性不同）尚未查清，**故 `shell_flux` 只作交叉参考，不作验收**。
4. **`p = max(Tait, 0)` 在单相云里是无条件钳位**：`rho < rho0` 的粒子压强精确为 0，自由面壳层因此无法承载压强跃迁；这是机理层结论，不是数值调参问题。
5. **单相近似**：真实液滴外侧有气相（`p_gas != 0`），本文把它设为 0；有气相时气相密度/压强会参与界面平衡，结论需重测。

**结论（honest）**：

- 本轮**没有**让 Young-Laplace 压强判据过关：正确判据（核内绝对压强 vs `sigma/R`）在三档分辨率上稳定误差 **-40%~-41%**，既不进 3% 也不进 15%，证据等级维持 **WITHHELD**。
- 本轮**结清的是判据欠账**：历史 -75%~-98% 的失败源于判据本身（内部差值 vs `sigma/R`），新判据把误差压到 -40% 量级，并指出剩余偏差的机理（自由面密度亏损 + `p` 钳零）与它**与分辨率无关**这一关键事实，从而否掉了「分辨率地板」的旧归因。
- 且该偏差随时间继续增大（5.6 t_sigma 到 -70%、核内密度回落到 rho0 以下），说明问题不是「精度不够」而是**该离散下不存在可收敛的 Laplace 过压稳态**：界面壳被 `p = max(Tait,0)` 钳零，CSF 力无处转化为压强。
- 下一步（按本审计结论排序）：① 用连续方程 + `delta-SPH` 密度扩散替代求和密度，让自由面壳层密度不再亏损；② 引入气相（双相）使界面压强跃迁有承接侧；③ 若坚持单相，则改用 `R/dx >= 40` 并同时给出 `p` 的分布（而非均值）。
