# 闭式水槽静止残差的病因是壁面压力截断；而静止态的**时间推进不成立**

Anchor: **CASE-SPH-LAKE-AT-REST** — 算例池·静水湖面守恒（零速零波动）；
基准 = 解析恒等 `p = rho0 g (H - y)`、`u = 0`、平自由面；
容差 = 机器精度 `1e-09`。

> 本文件由 `benchmarks/lake_at_rest/rest_split.py` 从
> `tests/data/lake_at_rest/rest_split.json` 程序化生成；表中每个数字都是
> 该 JSON 的字段，零手抄。**报告的是实测，包括失败的部分。**

## 0. 结论先行（先说失败）

1. **静止态在 t=0 是精确离散不动点，但按本单的显式格式推进会线性不稳定。**
   `t=0` 残差 `max|a|/g = 1.279e-13 … 1.280e-13`（闭式水槽），过锚点容差约 4 个量级；
   可是从舍入级种子出发，残差在 `t = 0.024 s` 内越出容差，`t_end = 0.50 s` 时已到 `1.087e+12`。
   **因此本单不声称锚点被满足**：`anchor_met = False`、`persists = False`。

2. **病因定位是实的：壁面压力延拓的 `max(p_w, 0)` 截断。** 同一套一阶矩(MLS)算子、
   同一几何、同一条格点，壁面压力取*有符号*线性延拓时 `t=0` 残差 `1.280e-13`，
   换回截断版本就是 `1.085e-01 … 1.085e-01` —— 与历史记录的 0.109 g 一致，
   而两臂的唯一差别就是水面以上干壁面粒子的压力符号。壁面延拓本身与解析水压力
   的一致性 `max|p_w - p_hyd(y_w)|/p_max = 2.181e-16`（R3）。

3. **容差不是恒等式。** 同一算子在受扰静止态上的残差随扰动幅度线性增长
   （`A/dx = 0.25 → 1.00`：`4.004e-01 → 1.599e+00` g），
   而“把压力递给算子”的恒等式臂在同一批幅度上仍是 `1.279e-13 … 1.279e-13` g。
   分辨“看得见非平衡态”与“看不见”，这一项通过（R6/R7/R8）。

4. **动态臂同样 FAIL，不声称波频。** 演化密度形式在自由面行累积密度源，`t = 0.042 s`
   越出 1% 密度包络（实测最大 `2.441e+01`），`omega^2 = g k tanh(kH)` 未检验。

## 1. 案例与闭合式

| 量 | 值 |
|---|---|
| 水槽 | 宽 0.400 m × 静水深 0.300 m |
| `rho0` / `c0` / `gamma` / `g` | 1000.0 / 20.00 / 7.0 / 9.81 |
| 核 / 光滑长度 | 三次样条，`h = 1.30 dx` |
| 壁面粒子 | 3 层，镜像对称，含水面以上干壁面 |
| 分辨率 | 0.050, 0.025 m |
| 时间步 | `dt = 0.3 h / c0`；`t_end = 0.50 s` |

闭合式（`src/tensorsph/lake_rest_split.py`）：

```text
p        = p_hyd(y) + p',   p_hyd(y) = rho0 g (eta0 - y)
p'       = max(B ((rho/rho0)^gamma - 1), 0)      B = rho0 c0^2 / gamma
dv/dt    = -(1/rho) grad_MLS(p_hyd) - g - grad_cons(p')
drho/dt  = -rho div_MLS v
p_wall   = p_f + rho_f (g - a_w).(r_w - r_f)     [有符号，不截断]
```

`grad_MLS` 对任何仿射压力场在*任何*支撑（被壁面或自由面截断）上都精确：差分形式消掉常数部分，
一阶矩矩阵求逆消掉线性部分。静止态 `rho = rho0` ⇒ `p' = 0` 处处为零，
算子看到的正是仿射场 `p_hyd`，于是 `-(1/rho0) grad p_hyd - g` 落到舍入级。
`grad_cons` 是 `p'` 的对称（能量一致）形式，用作连续性方程的对偶，表里两套算子都实测过：
MLS 差分形式承载 `p'` 时是**指数发散**的（下一节），换成对称形式后静止精确性保持不变。

## 2. 静止阶梯：t=0 残差、越界时刻、终态

| dx | arm | max\|a\|/g @ t=0 | 首次越 1e-9 (s) | max\|a\|/g @ t_end | max\|Δx\| (m) |
|---|---|---|---|---|---|
| 0.050 | split/signed | 1.279e-13 | 0.04873294346978557 | 1.125e+11 | 7.634e-01 |
| 0.025 | split/signed | 1.280e-13 | 0.024366471734892786 | 1.087e+12 | 7.375e-01 |
| 0.050 | split/clamped | 1.085e-01 | 0.0 | 5.388e+11 | 7.634e-01 |
| 0.025 | split/clamped | 1.085e-01 | 0.0 | 2.485e+12 | 7.375e-01 |

横向周期水槽（同一闭合式，无水面以上干壁面）t=0 残差：dx = 0.050 → 1.27e-13，dx = 0.025 → 1.27e-13。两个壁面延拓选项在周期水槽里给出*逐位相同*的 t=0 结果 —— 那里不存在
“水面以上的干壁面粒子”，截断无从发生。这是“病因在截断”的独立旁证。

## 3. 剂量-反应：为什么是截断

有符号延拓在*真正与流体交换相互作用*的壁面粒子上与解析水压力一致到 `2.181e-16` 相对量级（52 个粒子）。
截断版本把这些粒子中解析延拓为负（水面以上）者压到 0，最大差值 `9.095e-13 Pa`；离壁第一列因此同时得到虚假的
水平与垂直力（截断臂 `max|a_x|/g = 5.454e-02`）。与 `docs/verification_lake_at_rest_wall_gap.md` 把病灶定位在“壁面列自由面粒子的
邻居项”是同一件事，但给出了可修的那一半：**延拓本身精确，是截断破坏了它。**

### 3.1 正则化阶梯（`dx = 0.050`，`t = 1 ms`）

| moment 正则化 | max|a|/g |
|---|---|
| 1e-06 | 1.279e-06 |
| 1e-09 | 1.279e-09 |
| 1e-12 | 1.279e-12 |
| 1e-14 | 1.286e-14 |

精确性地板由一阶矩求逆的正则化决定；报告而非隐藏。

### 3.2 水面位不变性（`R5`，t=0）

`eta0 → eta0 + 1 mm`：残差 `1.279e-13` → `1.279e-13`，差 `6.187e-19`。
t=0 的精确性来自仿射再现，不是在某一个水位上凑出来的抵消。

## 5. 注意点 / 局限（关键）

1. **时间推进不稳定，这是本单的主要负面结果。** 从 `t=0` 的舍入级残差出发，残差指数增长
   （`dx=0.050` 闭式水槽：1e-13 → 1e-9 → 1e-3 → O(1) g，e-folding 约 10 ms），与历史论文里
   “显式推进的发散密度形式需要额外稳定化”一致。已排除的候选：密度扩散（δ-SPH）、参考体积、
   张拉保护（`p'≥0`）、保守对称压力梯度 —— 四种都在同一时间尺度上发散，说明病灶不在
   自由面张拉分支，而在“独立密度 + 声速刚度”这一层的格式设计（下一步候选：半隐式/
   压力投影、或把密度改回求和式并把平衡态偏置作为源项）。
2. **因此本单不把 t=0 的精确性算作锚点通过。** 锚点要的是“零速零波动”，而守恒必须经得起推进。
3. **有符号壁面延拓的代价**：水面以上干壁面粒子压力为负（张力）。静止态里它是平衡的
   一部分（解析场的线性延拓），动问题里需要额外证据，本单没有。
4. **参考压力解析的前提是参考态常密度**（不可压极限）；层化水体需积分 `p_hyd`。
5. **差分/对称两套算子混用**：参考项走 MLS（精确抵消），扰动项走对称形式（能量一致）。
   这在本单是被迫的工程折中，已在表里分别实测。

## 6. 误差判定（逐项，含“是否 < 3%”）

| 关键量 | 基准 | 实测 | 是否 < 3% |
|---|---|---|---|
| 闭式水槽 t=0 `max|a|/g`（split/signed） | 解析恒等 0 | `1.279e-13 … 1.280e-13` | **是** |
| 闭式水槽 t=0 `max|a|/g`（split/clamped） | 解析恒等 0 | `1.085e-01 … 1.085e-01` | **否**（≈10% g） |
| 壁面延拓 vs 解析水压力 | `rho0 g (H - y_w)` | `2.181e-16` 相对 | **是** |
| 受扰态残差线性度（split/signed） | 线性理论 | 见 `R8` | **是** |
| 静止态维持 `t_end = 0.50 s` | 解析恒等 0 | `7.634e-01 m` | **否**——发散 |
| 重力波频率 `omega` | `sqrt(g k tanh kH)` | **未测** | **无法判定** |

锚点判定：`anchor_met = False`；`equilibrium_exact = True`；`persists = False`；`non_degenerate = True`；`dynamics_certified = False`；门禁 7/9 通过。
