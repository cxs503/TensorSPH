# 验证欠账复核：接触角边界条件（仪器已修好，物理层如实记账）

**仓库**: TensorSPH ｜ **工件**: `benchmarks/contact_angle/` ｜ **测试**: `tests/test_contact_angle_instrument_m6503.py`

**结论（先给判定）**: 仪器层 10 个**精确解析界面**（直线/圆弧 × 30°–150°）最大偏差 0.000°，门槛 2° → **通过**；分辨率层（粒子晶格，R/dx = 6.7）最大偏差 3.7°；物理层 3 个设定角中 0 个在 ±10° 门内、1/3 个算例**可采信**（壁面穿透与伪流门），最大偏差 92.9° → **WITHHELD**。

## ① 案例介绍

半径 R = 0.02 m 的二维液滴静置于平底壁面（Adami 壁粒子 3 层），零重力，sigma = 7.2 N/m，rho0 = 1000.0 kg/m³，Tait gamma = 7.0，dx = 0.003 m（R/dx = 6.7），h = 1.3 dx，c0 = 20 m/s，nu = 0.01 m²/s，观测窗口 1.5 t_sigma（t_sigma = 0.0333 s）。接触角 BC 在壁面 2h 内把界面法向旋转至 n·n_wall = cos(theta)（Adami et al. 2012 的界面法向形式）。

## ② 怎么做的

1. **仪器层**（判据先于物理）：直线 `P(s) = (x_c,0) + s(-cos t, sin t)` 与圆弧（R_c = 3R，圆心 `C = (x_c,0) - R_c(sin t, cos t)`）两个**精确**界面，沿弧长密采样 + 壁面相邻流体行（接触区，y = dx/2），过同一套仪器：双向包络（x 向最低 + y 向最右，故增湿/悬垂都能描）+ 圆拟合（Kasa，对圆界面精确）/直线回退（按共线性 λ0/λ1 选择）+ 「模型与壁面的交点」取接触点 + `theta = atan2(t_y, -t_x)`；
2. **分辨率层**：解析圆帽内的**粒子晶格**（间距 dx），已知角做基准，量出仪器在生产分辨率下的离散误差（这是任何物理读数的误差棒）；
3. **物理层**：圆盘液滴初始化于壁面（最低粒子行 y = dx/2），生产 RHS （`droplet_impact.rhs` + `csf_consistent`，**不改 src/**）松弛 1.5 t_sigma，窗口后 40% 时间平均读接触角；
4. 判据：|theta_phys - theta_set| <= 10°（`within_gate`），另记仪器门槛与分辨率地板供对照。

## ⑤ 注意点（局限与适用范围）

1. 仪器层是**精确界面**上的数学校验，它证明估计器无偏、模型选择不误判；它**不**证明物理层准确 —— 探针与样品要分开记账（这正是本单修的东西：旧版把「仪器层十行全部通过」写死进文档，而同一份 report.json 里 10 行有 8 行是 NaN）；
2. 分辨率层给出仪器在 R/dx = 6.7 的离散地板；物理层偏差若与之同量级，读数只能当**上界**用，不能当「BC 达到 ±10°」的证据；
3. 非增湿（theta > 90°）界面在接触线处**悬垂**，x 向包络在那里是壁面而不是自由面 —— 仪器必须同时取 y 向最右包络，否则 120°/150° 一律测成 ~89°（旧版的实测就是这个症状）；
4. 圆拟合在界面近似直时退化（Kasa 在共线点上是奇异方程），故按共线性（λ0/λ1 <= 1e-9）回退直线拟合；两条模型在直界面上给出同一角，不存在「挑一个好看的」空间；
5. 零重力构型排除 Bond 数干扰，形状由表面张力 + 接触角 BC 决定；壁面 2h 内的法向旋转是 BC 的直接输出，实测的是**松弛后界面**的角，不是中间场。
