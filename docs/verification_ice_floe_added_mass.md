# 浮冰发射降阶模型的附加质量欠账（TensorSPH）

**基准**：`benchmarks/ice_floe_added_mass/run.py` → `benchmarks/ice_floe_added_mass/report.json`
**模块**：`src/tensorsph/added_mass.py`（新增）、`src/tensorsph/ice_splash.py`（修正）
**证据等级**：REAL（闭式解锚定 + 独立势流数值解 + 真实 SPH 冲击冲量）
**生成方式**：本文所有数字由 `benchmarks/ice_floe_added_mass/make_doc.py` 从 `report.json` 注入，无手抄。

---

## 1. 案例介绍：欠账是什么

艏部破冰瞬时自由面算例（`docs/verification_ice_splash.md`）把浮冰做成**降阶模型**：
虚拟测力板积分得到冲量 `J`，再除以浮冰**干质量** `rho_ice pi r^2` 得到抛射速度
（`floe_launch_estimate`）。这个除数漏了一项物理：被抛的浮冰必须把周围的水一起加速，
所以阻力惯性是

    m_eff = rho_ice pi r^2 + C_m rho_w pi r^2,

`C_m` 是附加质量系数。对**无界流体中的二维圆截面**，附加质量等于排开水的质量，
`C_m = 1`（Lamb, *Hydrodynamics*, 6th ed., §71；Landau & Lifshitz, *Fluid Mechanics*, §11），
即 `m_eff = (917 + 1000) pi r^2 = 2.09 m_ice`。干质量口径因此是**上界**，
抛射速度被高估 2.09 倍、抛射高度被高估 4.37 倍。

本单要回答三件事：(a) 闭式值 `C_m = 1` 能否被独立数值解复现（含误差量级）；
(b) 干质量口径对既有算例的偏差有多大；(c) 该修正如何落进代码与 DEM 交接面。

### 参数（`report.json → launch_bias.case`）

| 参数 | 值 |
|---|---|
| 算例 | 艏部破冰瞬时自由面（斜坡 25°、甲板 0.28 m、水柱 0.20×0.28 m） |
| dx / 粒子数 | 0.0125 m / 352 |
| t_end | 0.460 s |
| rho_ice / rho_w | 917 / 1000 kg/m³ |
| 浮冰半径 r | 0.03 m（二维圆截面，单位深度） |
| c0 | 20 m/s |

## 2. 怎么做的

1. **附加质量势流解**（`src/tensorsph/added_mass.py`）：圆柱以单位速度平动，刚体势
   `phi = -(x - x_c)` 施加在体节点上（等价于流侧 Neumann 条件 `dphi/dn = U n_x`），
   远场用衰减偶极子 `-a^2 (x-x_c)/r^2` 闭合，红黑 SOR 松弛求 Laplace 方程，
   由流场动能 `M = 2K/U^2` 得到 `C_m = 2K/(rho pi a^2)`，并解析补上盒外偶极尾迹能量。
   支持三种环境：`unbounded`、`rigid_wall`（Neumann 镜像，甲板）、`free_surface`
   （`phi = 0` 线性化自由面），以及 `x`/`y` 两个平动方向。
   **锚定方式**：`unbounded` 且 `initial="zero"`（静止流场冷启动）时解收敛到闭式值
   `C_m = 1`；若初始化偶极子则只是复算积分，不作为验证。
2. **网格/盒子敏感性**：`cells_per_radius = 8, 12, 16, 24`，
   `box_radii = 6` 与
   `6, 10`。
3. **平面影响**：`gap = 2, 4` 倍半径处
   分别放刚性壁与自由面，报告相对无界解的比值（比值抵消同一网格上的离散偏差）。
4. **落到工程数字**：直接用真实 SPH 冲击算例（一次 `run_case`，45 s）的冲量，
   比较干质量与含附加质量两种口径的速度、抛高、抛距。

工具链：纯 CPU torch（float64），`OMP_NUM_THREADS=4`（128 线程机器上默认线程数会把小张量
算子开销放大两个数量级，见 §5）。

## 3. 计算结果

### 3.1 锚定：无界圆截面 vs 闭式解

| cells/radius | 网格 | C_m（数值） | 相对 Lamb 的误差 | SOR 步数 | 解析尾迹占比 |
|---|---|---|---|---|---|
| 8 | 96x96 | 0.8687 | -13.13 % | 187 | 0.0320 |
| 12 | 144x144 | 0.8662 | -13.38 % | 406 | 0.0321 |
| 16 | 192x192 | 0.9275 | -7.25 % | 677 | 0.0299 |
| 24 | 288x288 | 0.9479 | -5.21 % | 1353 | 0.0293 |

- 盒子敏感性（cells/radius = 12）：box 6 半径 → 0.8662，box 10 半径 → 0.8626，
  两者相差 < 0.5 %，说明尾部解析补正后截断误差已在噪声内。
- x/y 平动各向同性（同一网格）：0.8662 vs 0.8662，
  相对差 2.2e-14 %（离散问题在 90° 旋转下严格对称，故到机器精度）。
- **一阶 Richardson 外推**（12→24 网格一阶假定下的最小二乘式 `(r*C_24 - C_16)/(r-1)`，
  r = 1.50）：`C_m = 0.9886`，即闭式 1 的
  -1.1 %。

### 3.2 平面影响（gap ≥ 2 半径）

| 环境 | 平动方向 | gap [半径] | C_m（数值） | 比值 / 无界值 |
|---|---|---|---|---|
| rigid_wall | x | 2 | 0.8452 | 0.976 |
| rigid_wall | x | 4 | 0.8790 | 1.015 |
| rigid_wall | y | 2 | 0.8828 | 1.019 |
| rigid_wall | y | 4 | 0.8937 | 1.032 |
| free_surface | x | 2 | 0.8972 | 1.036 |
| free_surface | x | 4 | 0.8619 | 0.995 |
| free_surface | y | 2 | 0.9087 | 1.049 |
| free_surface | y | 4 | 0.8653 | 0.999 |

最大偏离 4.9 %，与 §3.1 的离散偏差同量级：
**两种平面在 gap ≥ 2 半径时都回到无界值**，这是本方法能给出的最强结论。
gap < 2 半径（浮冰坐在甲板上、几乎贴自由面的真实工况）在笛卡尔阶梯网格上只有 3–6 个格子，
未收敛，**本单不给数**（见 §5 未完成项）。

### 3.3 工程影响：干质量口径 vs 含附加质量（真实冲击冲量）

闭式比值：`v_wet/v_dry = rho_ice/(rho_ice + C_m rho_w) = 0.4784`
（`C_m = 1`），与上表每行 `speed_ratio` 一致。

| 浮冰 | 冲量 J [N·s/m] | v_dry [m/s] | v_wet [m/s] | 速度比 | 抛高 dry [m] | 抛高 wet [m] |
|---|---|---|---|---|---|---|
| 0 | 2.157 | 0.832 | 0.398 | 0.478 | 0.0353 | 0.0081 |
| 1 | 1.356 | 0.523 | 0.250 | 0.478 | 0.0140 | 0.0032 |
| 2 | 0.969 | 0.374 | 0.179 | 0.478 | 0.0071 | 0.0016 |
| 3 | 0.698 | 0.269 | 0.129 | 0.478 | 0.0037 | 0.0008 |
| 4 | 0.205 | 0.079 | 0.038 | 0.478 | 0.0003 | 0.0001 |

最大抛高的浮冰（floe 0）：0.832 →
0.398 m/s，抛高 0.0353 →
0.0081 m。由于抛高 ∝ v²，附加质量把降阶模型的
抛高整体压低 77 %。这不是"更好的模型"，而是**把原来隐含的乐观上界改成物理中值**。

## 4. 误差判定

基准：Lamb 闭式 `C_m = 1`（无界二维圆截面，精确解）。

| 关键量 | 基准 | 本方法 | 相对误差 | < 3 % ? |
|---|---|---|---|---|
| `C_m`（24 cells/radius，未外推） | 1.0 | 0.9479 | -5.21 % | **否** |
| `C_m`（12→24 一阶外推） | 1.0 | 0.9886 | -1.1 % | **否（约 1–3 %，处在阈值内缘）** |
| 盒子敏感性（6 → 10 半径） | 0（应无依赖） | 差 0.41 % | — | 是 |
| x/y 各向同性 | 0 | 2.2e-14 % | — | 是 |
| 平面极限（gap ≥ 2 半径） | 比值 → 1 | 最大偏离 4.9 % | 4.9 % | 否（与方法噪声同量级） |
| 速度比 `v_wet/v_dry` | 闭式 0.4784（代数恒等式） | 0.4784 | 0 % | 是 |

**诚实结论**：工程修正量（`v_wet/v_dry`、m_eff）走的是一条代数恒等式 + Lamb 闭式解，
不需要数值解；数值解的作用是给出**误差量级**（阶梯边界一阶、24 格/半径仍有 −5 %），
因此平台 3 % 门槛在"数值复现闭式值"这一项上**未达到**，仅外推后接近阈值；
本文不宣称该势流解已达 3 %。

## 5. 注意点与局限

1. **阶梯边界是一阶的**。体面用"格心在圆内"的阶梯近似，动能积分无法覆盖贴着边界的
   半个格子带，系数系统性偏低（−5 % @24 格/半径）；补了湿面积权重与单侧差分后仍如此。
   换代方案：体拟合极坐标/短极-韦勒（Shortley–Weller）鬼点，预期二阶。**未做**。
2. **薄间隙未收敛**：gap < 2 半径时只有 3–6 个格子，数值随 cadence 漂（gap=0.5 与 2 的比值
   在 12→16 格/半径之间变化 > 5 %），本单一律不引用，记为 WITHHELD 待办。
3. **线性化自由面**：用 `phi = 0` 固定平面代替真实变形自由面，只对高频（脉冲）横向加质量成立；
   浮冰穿出水面、飞沫飞越等情形不适用。
4. **二维单位深度**：真实浮冰是有限尺度三维体，`C_m` 会随细长比变化（三维圆盘法向
   `C_m ≈ 0.64`，球 `≈ 0.5`）；本文只支持二维截面，三维值不得由本文外推。
5. **性能坑**：本机 128 核默认线程数下，逐次松弛的小张量算子被调度开销拖慢两个数量级
   （一次 128² 求解 50 步耗时 >100 s）；`OMP_NUM_THREADS=4` 后 0.3 s。批量小算子求解一律钉线程数。
6. DEM 交接面（`build_dem_exchange`）现在交**含附加质量**的速度，并记录
   `source.floe_added_mass_coefficient`；要回到旧的干质量口径用
   `IceSplashConfig(floe_added_mass_coefficient=0.0)`。
