# 方法选择账本里的“随加密变差”：一次可采纳性错配审计（mission 23211）

**锚点**: `XVAL-SPH-METHOD-SELECTION-2026-11-12` ｜ **仓库**: TensorSPH ｜ **技能**: adversarial-review ｜
**产物**: 新守卫脚本 + 13 条测试 + JSON/MD/图 + 扫描驱动 CLI 扩展

## ① 案例介绍（问题从哪来）

平面 Couette 通道：H = 0.1 m、ν = 0.02 m²/s、上壁 U = 0.2 m/s 滑动、下壁静止、x 周期；
解析解 u(y)=U y/H、τ = ρνU/H（Batchelor 1967 §4.2）。H²/ν = 0.5 s、Re = 1、Ma = 0.01。

方法选择账本把 `wcsph_wall_no_slip` 从 Couette 剖面的**严格模式**里排除，唯一依据是记录
`x_couette_viscous_time_top_h16` = 17.076 %（移动壁剪切误差，H/dx=16）。
m22787 的裁定文件同时登记了 `worsens_with_resolution: true`——即“14.20 % → 17.08 %，**随加密变差**”。
本单核对这个结论：这两条读数是不是同一可采纳性类别？

数据源（只读）：`benchmarks/couette/out_design/viscous_time_convergence.json`（viscous-time 扫描，
H/dx = 8/16 × t_end/(H²/ν) = 0.6/1.2/2.4/3.6，每点自带 `steady_drift` 与 `admissible` 标志）。

## ② 怎么做的

1. 新守卫 `benchmarks/method_selection/admissibility_matched_ladder.py`：把扫描按**壁面 × 档位**重排成阶梯，
   对每条“加密趋势”主张要求**同档位、同终端时间、两侧都可采纳**才允许给出趋势；否则显式降级。
   分类词：`matched_trend` / `mixed_admissibility` / `trend_untestable`，外加与类别无关的补强证据
   `time_insensitive_exceedance`（在有可采纳读数的档位上，是否**任何**终端时间都超标准）。
2. 复算而非抄写：每个点的误差都由 `|1 - τ_SPH/τ_exact|` 与产物字段重算，登记值从
   `method_selection_registry.json` 读入；图与表由 JSON 生成，报告数字由本脚本注入。
3. 决策联动按数据匹配：严格界文件里的排除条目按 `worst_accuracy_pct` 与记录登记值比对（不按名称猜）。
4. 为补第三档，给扫描驱动 `benchmarks/couette/viscous_time_convergence.py` 加
   `--resolutions/--viscous-times/--out`（默认值不变，`--check` 新鲜度门不受影响）；
   H/dx=32 全时间档（cj4684）与 H/dx=8 长时档 t=5.4/7.2（cj4685）已递交集群，
   **本文件发布时二者仍在排队，因此不预填任何数字**。

### 3.3 主张裁定

| 项 | 值 |
|---|---|
| 主张 | `moving_wall_worsens_with_resolution` |
| 提出者 | benchmarks/method_selection/adjudicate_over_tolerance.py (field rederived.worsens_with_resolution) |
| 登记记录 | `x_couette_viscous_time_top_h16`（方法 `wcsph_wall_no_slip`），17.076 % |
| 粗档 H/dx=8 的读数 | 14.203 % @ 3.6 H²/ν，可采纳=False，该档可采纳点数 0/4，drift 8.628e-02 |
| 细档 H/dx=16 的读数 | 17.076 % @ 3.6 H²/ν，可采纳=True，该档可采纳点数 1/4 |
| 有可采纳读数的档位 | [16] |
| 配对趋势 | `None` |
| **裁定类别** | **`trend_untestable`** |
| 复算 vs 登记 | 0.00e+00 % |
| 引用该记录的已公布决策 | “planar Couette channel” (strict): worst_accuracy_pct = 17.076 % |

**裁定**：moving_wall_worsens_with_resolution: NOT ESTABLISHED as a resolution trend -- only 1 rung(s) of the sweep have an admissible reading, so a matched-admissibility ladder does not exist; independent evidence H/dx=16: best case over all terminal-time tiers 16.024 % at 0.6 H^2/nu (still above the 15 % standard)。

即：粗档 H/dx=8 **一个可采纳点都没有**（最小 steady_drift 仍远超 1 % 门），驱动脚本
`summarise()` 的“无可用点则取最后一点”回退把一条**启动瞬态读数**（14.203 %, drift 8.628e-02）
和一条**稳态读数**（17.076 %, drift 6.768e-03）放在同一张趋势里比较。
把数据对齐后可说的话只有一句：**分辨率趋势在这份产物里无法测量**（`trend_untestable`），
“随加密变差”不成立，也不被反证。

**与类别无关的补强证据（排除结论本身仍站得住）**：在唯一有可采纳读数的档位 H/dx=16 上，
所有终端时间档的移动壁误差都在 16.024–20.867 % 之间，
最好的情形（t = 0.6 H²/ν）仍是 16.024 % > 15 %。
所以“17.08 % 是启动瞬态”这个解释被否证——该超限读数**不随跑时长消失**，与底壁读数
（0.478–15.052 %，
随跑时长降到 1 % 以下）形成明确对比。这正是 m23146 对底壁做过的时间轴检验在移动壁上的结果：**两壁不对称**。

### 3.4 附带发现：被 SELECTED 的设计点读数也不是稳态读数

| 项 | 值 |
|---|---|
| 记录 | `x_couette_wall_shear_design`，登记 0.478 % |
| 从扫描复算 | 0.478 %（差 0.00e+00 %） |
| 该点 steady_drift / 可采纳 | 1.547e-02 / False |
| 同档位可采纳读数 | 1.811 % @ 3.6 H²/ν（drift 6.768e-03） |
| 类别 | `design_reading_not_admissible` |

登记记录的前置条件写的是“steady-state precondition: t_end = 1.2 H²/ν”。数据说：该点自身
**没有过** 1 % 的 `steady_drift` 门（1.547e-02）；同档位唯一过门的是更长的
终端时间，读数 1.811 %。两条都远在 15 % 标准内，
所以**精度主张不受影响**，受影响的是标签的严格性：`0.478 %` 是“设计点读数”，不是“稳态读数”。

## ⑤ 注意点（踩过的坑 / 局限）

1. **不改变任何已公布决策**：排除 `wcsph_wall_no_slip` 的结论保留（有更干净的证据），
   但被修正的是它旁边那句“随加密变差”。我没有把排除改成推荐——那是业主策略问题。
2. 只有 2 个分辨率档，且粗档 0 个可采纳点 → 趋势**不可测**，不是“不成立的反面”。
   H/dx=32（cj4684）落地后守卫会自动并入（新档位与旧档位共享的标签必须逐位一致，否则抛错），
   届时才能给出配对趋势。
3. 分类器的“配对”是按登记档位与终端时间做的**显式**匹配；它不会自己发现新的粗/细档对。
4. 判据只用 `steady_drift ≤ 1 %` 这一个运行自带门；若该门本身偏松/偏紧，裁定会跟着变——
   但门是产物自带的、写死在 `gates` 里的，不是本审计选的口径。
5. H/dx=8 长时档（cj4685，t = 5.4/7.2 H²/ν）本意是回答“粗档能否被跑成可采纳”，
   发布时仍在排队；结果未知，不作推测。

## ⑥ 误差判定（对解析基准逐项）

| 关键量 | 值 | 基准 | 误差 | <3 % ? |
|---|---|---|---|---|
| 移动壁剪切，H/dx=16，t=3.6（唯一可采纳点） | 17.076 % | 0（解析 u=Uy/H） | 17.076 % | **否** |
| 移动壁剪切，H/dx=16，最好情形 t=0.6 | 16.024 % | 0（解析） | 16.024 % | **否** |
| 移动壁剪切，H/dx=8，t=3.6（非可采纳） | 14.203 % | 0（解析） | 14.203 % | 否 |
| 底壁剪切，H/dx=16，设计点 t=1.2 | 0.478 % | 0（解析） | 0.478 % | **是**（但 drift 未过门） |
| 底壁剪切，H/dx=16，可采纳点 t=3.6 | 1.811 % | 0（解析） | 1.811 % | **是** |
| 登记值 vs 扫描复算（移动壁 H/dx=16） | 17.076468 % | 17.076468 %（登记） | 0.0e+00 % | **是** |

**锚点验收（<15 %）**：本单不新增强度断言，只做裁定。结论是——决策所依赖的超限记录
（17.076 %）**稳健**（在该档位上任何终端时间都超 15 %，最好情形 16.024 %），
但支撑它的“随加密变差”叙述**不被数据支持**；同一档位的底壁读数 1.811 %（可采纳）
则在 3 % 内。移动壁 17 % 量级的系统性偏差仍未解释，是后续可派单的真问题。
