## ① 案例介绍
γ-law Riemann 问题，静止外态，压力比 **1000:1**：ρ,u,p = (1,0,1000) | (1,0,1)，x∈[−1,1]，x_dia=0，t_end=0.02。
解析：左膨胀风扇（ρ 1.0→0.576）、压力平台 p*=461.52、接触密度跳变 10.3×、激波 Mach≈4.6。
与 Sod 族（10:1 / 3.4× / 1.3 Mach）属不同regime。生产设置 N=800、h=2.5Δx、
CFL=0.15、α/β_AV=1.0/2.0；收敛阶梯 [400, 800, 1600]。
可表示性（精确解判定）：waves inside the box and no net boundary mass flux。

## ② 怎么做的
1. 先证伪"直接补 Toro test 4"：该问题精确解靠**边界入流**维持外态，而本族是拉格朗日+反射壁+固定质量盒子；
   新增 `riemann_topology.reflective_box_budget` 由精确解判定（波是否触壁、边界净质量流），Toro 4 净入流
   5.41 vs 盒内质量 6.00（90%）→ 拒绝判级（强行跑 L1(ρ)=39%，是边界条件伪影）。
2. 新增拓扑感知精确数据/判级 `riemann_topology`：按 p* 与 p_k 判每侧 shock/rarefaction；冲击支用 RH 星态与激波速度
   （老助手 `sod.exact_star_state` 在 p*>p_L 时静默给等熵膨胀式，并把左冲击报成 rarefaction 头速）。
3. 新族采用静止外态；测量窗由精确波位置 + max(0.1×平台宽, 3h) 裁剪，装不下即抛错不报数；精确解由独立一阶 HLLC 复算确认。
