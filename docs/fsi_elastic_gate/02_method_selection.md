# 调研②③：方法选型与迁移方案（feature_slug = CASE-SPH-FSI-ELASTIC-GATE）

## 1. 选型决策

| 环节 | 交付前（m16214） | 本轮选择 | 理由（可有据/可复算） |
|---|---|---|---|
| 流→固载荷 | Adami 成对压力项，且用 `load_scale = 1.2558` 把自查失败除出去 | **壁面压力面元法**：对每个闸门粒子用一阶加权最小二乘拟合邻域压力平面，取壁面值 `p_face`，载荷 `p_face·dx` | 面元法对线性压力场精确（拟合对真实线性场零残差、与核支撑被壁面切掉多少无关），因此**没有系统性亏缺**；而 Adami 求和在半空间支撑下丢 O(h) 载荷，只能靠事后标定，标定值还会随 dx 变（−28.4 % / −20.4 % / −8.3 % @12.5/10/7.5 mm） |
| 固端条件 | 只罚相邻段夹角 ⇒ **铰支**（闸门可零弯曲能整体转动） | **固支**：把首段与固定参考切向 (0,1) 的夹角并入弯曲能 | 铰支下闸门是"铰链活门"，m16214 的 354 mm 峰值就是这扇门在转动，不是梁的弯曲 |
| 固体求解 | 离散弹性能 + 自动微分力 + 显式时间推进 | 保留能量式（AD 力与能量自洽），**静力校核改为能量最小化（L-BFGS-B）** | 交付版 V2 用固定 0.995 阻尼时间推进，审计改阻尼即变号 ⇒ 从未收敛；能量最小化与时间推进无关 |
| 大变形参照 | 无（只有小变形 Green 函数） | **Kirchhoff elastica**（Bisshopp–Drucker 问题）以弧长 ODE + 打靶自行求解 | 真实闸门工作在大变形区；elastica 与离散杆共享零代码，且不抄表（不转录任何文献数字） |
| 标定量 | `load_scale = 1.2558` 进生产运行 | **移除**（默认 1.0，仅作诊断字段） | 用标定除自查失败 = 把缺陷藏进结果；本轮把缺陷在源头修掉 |

## 2. 迁移方案（已落地）

1. `ElasticGateCase.load_transfer ∈ {"panel","pairwise"}`：`panel` 为生产默认，`pairwise` 保留为审计基线。
2. `ElasticGateCase.clamped_base: bool = True`：固支为生产默认；`False` 复现交付版铰支（对照用）。
3. `gate_load()` 修正一个潜在缺陷：成对模式下 `m_f` 曾用流体下标去索引 `wall_mass`（只因所有格点质量相同才恰好对）；改为 `rho_f·dx²`。
4. 校核阶梯：`verify_hydrostatic_load`(V1) / `verify_cantilever`(A0 点载小变形, A1 分布载小变形, A2 elastica 大变形) /
   `verify_gate_load_path`(V4 端到端)；`rod_static_equilibrium` 改为能量最小化；`verify_cantilever` 全部 `gravity=0`。
5. `tests/test_fsi_elastic_gate.py` 7 项断言（含"铰支不得回归"与"legacy 亏缺仍在"的护栏）。

它直接决定闸门顶点位移时程是否可信 —— 见 03 报告的失败阶段说明。
