# CSF 表面张力 delta 函数闭合的解析核验：单侧梯度 → 虚空镜像（ghost）

**范围**: `src/tensorsph/csf_consistent.py`（新增 `void_mirror_gradient`、`delta_s_scheme` /
`ghost_colour_max` 形参）、`surface_tension.py`（透传）、`droplet_impact.py`（`Config.csf_delta_s`）。
**基准**: 2-D 静止液滴的 Laplace 定律与切割力恒等式。本文件数字全部来自
`benchmarks/csf_delta_s/validation_report.json`（由 `benchmarks/csf_delta_s/run.py` 程序化写出），无手抄。

## 1. 案例介绍（物理背景与参数）

半径 `R = 0.02` m 的二维单相液滴，六方密排晶格初始化，四周真空，无重力，`t = 0` 静态判据
（不涉及时间推进，因此没有时间步/粘性自由度）。CSF 力的三个因子是 `f = -sigma kappa delta_s n`；
`docs/verification_surface_tension_curvature.md` 已把 `kappa` 修进 15% 门（+0.9%…+5.3%），
并把下一笔欠账登记为 **`int delta_s dn = 0.74`**（应为 1，即力幅值系统性偏低 25%）。

| 参数 | 值 |
|---|---|
| 液滴半径 R | 0.02 m |
| 表面张力系数 sigma | 7.2 N/m |
| 参考密度 rho0 | 1000 kg/m^3 |
| 声速 c0 | 20 m/s（Tait，gamma = 7） |
| 平滑长度 | h = 1.3 dx |
| 分辨率 dx | 0.003 / 0.002 / 0.0015 m（N = 161 / 362 / 642） |
| 解析参考 | kappa = 1/R = 50 1/m；F_cut = 2 sigma = 14.4 N/m；int delta_s dn = 1 |

**债务的物理根源**：色函数 `c = sum_j V_j W_ij`（`V_j = m_j/rho0`）在流体内部为 1，在自由面最外层
只剩约 0.5——它丢掉了半个核支撑，而丢掉的那半个位于**虚空**，虚空里没有粒子。于是最外层的
`grad c` 是单侧的，`|grad c|` 在那里偏低约 25%，`int delta_s dn` 读 0.74。

## 2. 怎么做的（方法/流程）

`delta_s_scheme="ghost"`：把最外层粒子（`c_i < 0.75`，即丢失了至少 1/4 核支撑的那一层）的每个邻居
关于过 `x_i`、法向 `n_i` 的切平面镜像，镜像点取虚空的已知值 `c = 0`、体积 `V_j`，累加其配对贡献

    grad*_i = grad_i c + sum_j V_j (0 - c_i) grad_i W(x_i - x_j'),   x_j' = x_i + (d - 2 (d.n_i) n_i)

一侧单侧 → 两侧。镜像后的构型关于切平面局部对称，MLS 修正矩阵在当地退化为单位阵，故不需要第二次求解。
其余一切不动：法向仍来自单侧梯度（实测力方向中位 cos = +1.000，无符号翻转），`kappa` 仍用
`fit_quadratic`，`delta_s` 仍带 CSF 的因子 2（虚空那半段 `1/2 -> 0`）。

**形参不破坏旧行为**：默认仍是 `"gradient"`，历史基准数字逐位不变；`Config.csf_delta_s` 做合法性校验，
`ghost_colour_max` 默认 0.75（由扫描确定：0.60 太小无粒子进入、0.85 过冲 +10%…+16%、>1 时整域镜像会
把力反向，实测 cos 变 −0.999）。

工具链：`benchmarks/csf_delta_s/run.py`（4 个组合 × 3 档分辨率的静态判据）、
`tests/test_csf_delta_s_ghost.py`（解析门禁 + 局部性 + 旧行为不变 + 已发布 JSON 一致性）。

## 3. 计算结果

### 3.1 delta 函数归一化 `int delta_s dn`（解析值 1.0）

| dx [m] | N | 单侧 `|grad c|` | 误差 | ghost 镜像 | 误差 | <15%? |
|---|---|---|---|---|---|---|
| 0.0030 | 161 | 0.7545 | −24.6% | 1.0587 | +5.9% | 是 |
| 0.0020 | 362 | 0.7510 | −24.9% | 1.0272 | +2.7% | 是 |
| 0.0015 | 642 | 0.7391 | −26.1% | 1.0273 | +2.7% | 是 |

单侧的亏损随分辨率**变差**（−24.6% → −26.1%），说明它是格式性缺陷而非分辨率地板；ghost 把它变成
+5.9% → +2.7% 的收敛序列。

### 3.2 切割力恒等式 `F_cut = 2 sigma`（两种体积约定，均用 `fit_quadratic` 曲率）

| dx [m] | 单侧 · 静止体积 `V=m/rho0` | ghost · 静止体积 | 单侧 · 求和密度（当前出厂路径） | ghost · 求和密度 |
|---|---|---|---|---|
| 0.0030 | 0.786 (−21.4%) | **1.024 (+2.4%)** | 1.012 (+1.2%) | 1.361 (+36.1%) |
| 0.0020 | 0.713 (−28.7%) | **0.936 (−6.4%)** | 0.899 (−10.1%) | 1.221 (+22.1%) |
| 0.0015 | 0.710 (−29.0%) | **0.919 (−8.1%)** | 0.893 (−10.7%) | 1.193 (+19.3%) |

同一 dx、同一曲率下，两种体积约定之比的倒数就是外壳层求和密度 `rho_shell/rho0 = 0.670 / 0.734 / 0.785`
——即出厂路径里 `a = -sigma kappa delta_s n / rho_i` 用的是**有亏欠的求和密度**，比 `rho0` 小 21%…33%，
于是把力放大了 1/0.73 ≈ 1.37 倍。

### 3.4 时间推进 A/B（dx = 0.002，fit_quadratic，900 步，t/t_sigma = 1.05）

| delta_s | p_center [Pa] | p_shell [Pa] | Delta p [Pa] | 对 360 Pa 误差 | 伪流 max|v|/sqrt(sigma/rho R) | <0.1? |
|---|---|---|---|---|---|
| gradient（旧） | 198.19 | 222.45 | -24.25 | -106.7% | 0.0275 | 是 |
| ghost（本轮） | 250.08 | 212.62 | +37.46 | -89.6% | 0.0493 | 是 |

- **方向对了、量级仍不达标**：`Delta p` 由 -24 Pa 修到 +37 Pa（符号由负转正、幅值 +54%），
  但距 360 Pa 仍差 90%。这不是本轮 delta_s 的问题：`Delta p = 360 Pa` 只要求 Tait 压缩
  `Delta p/(rho0 c0^2/gamma) = 6.3e-3`，而自由面求和密度噪声地板本身就是百分数量级，故 **c0 = 20
  m/s 下该判据不可分辨**（核心密度实测 rho_core/rho0 = 1.0005）。要在 15% 内测到它必须降低 c0
  或改压强基准（背景压强/无散修正），属下一笔欠账。
- **稳定性未退化**：伪流由 0.0275 升到 0.0493，仍低于 Adami 阈值 0.1；动能历史单调下降，
  液滴没有膨胀/炸开（力方向 cos 全程 +1.000）。

## 4. 结果判读

- **欠账 1 结清**：`int delta_s dn` 由 0.74–0.75 修到 1.03（误差 +2.7%），三档分辨率全进 15% 门，
  且不再随分辨率恶化。
- **切割力：在约定自洽的度量下进 15% 门**（+2.4% / −6.4% / −8.1%）；在出厂加速度路径下**过冲到
  +19…+36%**。这不是"修好了"而是**误差不再互相掩盖**：旧数字（+1.2% / −10.1% / −10.7%）是
  `kappa` +25% 与 `delta_s` −25% 与密度亏欠 +37% 三者偶然抵消的结果（三处错误各贡献约 25-35%，
  而旧 `mls` 曲率正好偏高 25%）。m2588 修好曲率时已经把这个抵消拆掉一半，本轮拆掉另一半。
- **由此暴露的新欠账（登记，不在本轮修）**：CSF 力的体积约定不一致——色函数/`delta_s` 用静止体积
  `V = m/rho0` 建立，加速度却除以求和密度 `rho_i`。自由面壳层 `rho_i/rho0 = 0.67…0.79` 是求和亏欠
  （真实流体在自由面密度并不低），因此出厂力偏强 1/0.73 ≈ 1.37 倍。统一约定（`a = -sigma kappa
  delta_s n / rho0`，或改用以 `V_j = m_j/rho_j` 建立色函数）会牵动全部表面张力回归数字，
  超出本单范围，**故意不做**；`delta_s_scheme` 因此保持 opt-in、默认不变。
- 结果**没有**说 ghost 应当立刻设为默认：在密度约定统一之前，它会让出厂的力偏强 19-36%。

## 5. 注意点（踩过的坑 / 局限）

1. **镜像掩膜阈值不能拍脑袋**：`c < 0.60` 在该晶格上没有粒子（最外层 `c ≈ 0.67…0.79`），`c < 0.85`
   把次外层也镜像进来 → `int delta_s dn` +10…+16%，切割力过冲到 +1.01…+1.12；`c > 1`（全域镜像）
   使镜像贡献压倒单侧梯度，**力方向整体反向**（中位 cos = −0.999），液滴会膨胀。0.75 是扫描出的平台。
2. **只镜像最外层，不镜像第二层**：整域镜像把同一段弧重复计入两次（实测 `int delta_s dn` = 1.66…3.88）。
3. **镜像构型局部对称 ⇒ MLS 修正矩阵退化为单位阵**，所以直接加配对贡献即可，不必重建/再求逆；
   若将来做曲面二阶镜像（点法向随位置变化），这条就失效，需要把镜像点并入 MLS。
4. **静止体积 vs 求和密度是两套账**：本文件把两者分开列（§3.2 两列），否则「切割力误差」会同时量到
   密度模型；任何引用本表的文档必须写清用的是哪一列。
5. **局限**：主判据是 `t = 0` 静态构型；时间推进只做了 dx = 0.002 一档（§3.4），未做分辨率扫描，
   也未测质量/动量守恒漂移。
6. 本机环境陷阱：`tensorphysics` 的 editable 安装把 `tensorsph` 指向另一 worktree
   （`/usr/lib/python3.11/site-packages/__editable__.tensorphysics-0.1.0.pth` → `/root/tp-agent/work/m2420/src`），
   不带 `PYTHONPATH=src` 跑测试会**测到别的 worktree 的代码**（`ModuleNotFoundError: tensorsph.csf_consistent`
   即是此症状）。本单所有数字均在 `PYTHONPATH=$PWD/src` 下取得。

+22%**，因为密度约定不一致被暴露出来，未修，已登记。没有把不达标项粉饰成达标。

## 7. 未完成 / 下一个欠账（交接）

1. **体积约定统一**（P0）：`a = -sigma kappa delta_s n / rho_i` 与 `delta_s` 的 `V = m/rho0` 冲突；
   建议在 `csf_scheme="consistent"` 下用 `rho0` 归一（或把色函数改为 `V_j = m_j/rho_j`），
   并重跑 `benchmarks/csf_curvature_fit`、`laplace_*`、`csf_consistent` 全部回归与
   `tests/test_csf_consistent.py` 的门限（预期多处数字要重新基线化）。
2. **Laplace 压差仍不可分辨**：见 §3.4，需降 c0 或改压强基准；本轮只证明 ghost 不炸、伪流仍过门。
3. `ghost_colour_max` 目前是常数 0.75；对非密排/非均匀粒子分布应改为按支撑亏欠自适应
   （例如 `A_i / A_bulk < 0.75`）。
