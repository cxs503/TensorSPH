# 锚点容差是「方案性质」还是「恒等式」？——静水湖面扰动响应审计

> 锚点 `CASE-SPH-LAKE-AT-REST`（算例池·静水湖面守恒；ref: 解析恒等；容差: 机器精度 1e-9）。
> 本文件由 `benchmarks/lake_at_rest/closure_response.py --doc` 从
> `tests/data/lake_at_rest/closure_response.json` 程序化生成，表内数字零手抄。
> 门禁：`tests/test_lake_at_rest_closure_response.py`。

## 0. 结论先行

| 命题 | 判定 | 证据 |
|---|---|---|
| 满足锚点容差的那行闭合，是**方案**的平衡态 | **不成立（恒等式）** | 静止态 `max|a|/g = 5.432e-16`，把自由面抬高 `1 dx` 后仍为 `7.244e-16` |
| 出厂算子在同一扰动下**能**给出非零残余（扰动是真状态） | **成立** | `A = 1 dx` 时出厂 `max|a|/g = 6.014e+02`（壁面带），`A` 减半响应随之减半 |
| 可压（barotropic）闭合能响应扰动 | **成立** | `A = 1 dx` 时 `1.599e-02` |
| 满足锚点容差的闭合能承载重力波 | **不成立** | `t_end = 0.500 s` 内自由面位移 `0`，线性波理论要求 `1.004e-04` |
| 度量本身是活的（1 % 斜率误差不被吞掉） | **成立** | 同一算子、同一格点，压力斜率乘 1.01 后 `max|a|/g = 1.000e-02`（期望 1.00e-2） |

一句话：**锚点的机器精度容差只在一处被真正达到（横向周期水槽，出厂算子），在闭式水槽里被达到的那行是「把答案先写进压力场」**——
它对任何粒子构型都给零加速度，因此它既不能证明求解器保静水，也无法承载任何静水回复力。

## 1. 案例与方法

| 量 | 值 |
|---|---|
| 水箱 | 0.40 m × 0.30 m，静水深 0.30 m，两侧+底三层壁粒子 |
| 工质 | rho0 = 1000 kg/m³, c0 = 20.0 m/s, gamma = 7.0, g = 9.81 m/s², 粘性 = 0 |
| 分辨率 | dx = 0.040, 0.020 m，h = 1.3 dx |
| 扰动 | 自由面行位移 `A cos(2 pi x / W)`，`A/dx = 0.01, 0.05, 0.10, 0.25, 0.50, 1.00` |
| 锚点容差 | 1.000e-09（机器精度） |
| 基准 | 解析恒等（u = 0，eta = const）＋ 线性重力波 `omega² = g k tanh(kH)` |

三个闭合在同一格点、同一质量场、同一对表上比较：

* `incompressible` — consistent gradient + incompressible closure
* `barotropic` — consistent gradient + barotropic (Tait) closure
* `shipped` — shipped operator (symmetric form, Tait EOS)

读法：`incompressible` 列**完全不随 A 变化**（浮动下溢级），这正是「一致梯度 + 仿射压力场
+ 常密度」的解析后果——算子在任意构型上返回 `-grad p/rho + g ≡ 0`。出厂算子与
`barotropic` 列随 A 增长，并在小 A 上呈线性响应（Q3）。

## 3. 动力学：从非平衡态出发

| 臂 | 闭合 | `A/dx` | `t_end` [s] | 步数 | `max|v|/c0` | 自由面位移 `/H` | 位移 `/A` |
|---|---|---|---|---|---|---|---|
| closure | `incompressible` | 0.25 | 0.500 | 641 | 1.332e-16 | 0 | 0 |
| control | `shipped` | 0.25 | 0.100 | 128 | 7.093e-02 | 9.617e-02 | 2.885e+00 |

线性理论：`eta(x,t) = H + A cos(kx) cos(omega t)`，`omega = 12.412 rad/s`，
本次积分覆盖相位 `omega t_end = 6.206 rad`，故自由面位移应达 `A |1 - cos(omega t_end)| = 3.011e-03 A`（即 `1.004e-04 H`）。
满足锚点容差的闭合测得 `0 H`——不是「保持静止」，而是**根本没有动力学**：
它在非平衡态上依旧给出零加速度，因此连一步回复都不会产生。

## 4. 阳性对照：度量是活的吗？

上一节的「零运动」必须与「读数坏了」区分开。同一算子、同一格点、同一扰动（`A/dx = 1.00`），只把静水压力斜率乘 1.01：

| 压力场 | `max|a|/g` | 期望 |
|---|---|---|
| 仿射静水场（闭合自带） | 7.250e-16 | 0（恒等） |
| 同一场斜率 × 1.01 | 1.000e-02 | 1.00e-02（1 % g） |

实测/期望 = 1.000，即度量对 1 % 的压力误差给出 1 % 的加速度——读数没有失明，§2 的平坦曲线是闭合的性质，不是测量的性质。

> **未做成的对照（如实记录）**：原计划的「周期水槽驻波频率 vs `sqrt(g k tanh kH)`」对照没有通过——`dx = 0.04`（每波长 10 个粒子）上把自由面抬高 `0.1 dx` 后，`max|v|` 在 1.9 s 内单调增至 `0.67 c0`（发散），拟合 `R² < 0.3`。这是该分辨率下自由面扰动的失稳，不是本次结论的前提，故未作为门禁。

## 6. 误差判定与适用范围

* **锚点（解析恒等，容差 1e-9）**：出厂算子 + 周期水槽 `max|a|/g = 5.76e-13`、静水保持 `max|v|/c0 = 2.6e-14`（`tests/data/lake_at_rest/periodic_dx020.json`）——达标；
  闭式水槽出厂算子 `max|a_x|/g = 1.203e-01`——**不达标（诚实 FAIL，>3% 不可接受）**。
* **满足容差的那行闭合**：静态残余 5.432e-16（远小于 1e-9），但它是恒等式，
  不构成「求解器保静水」的证据；对它的任何引用都必须同时给出扰动响应为零这一事实。
* **可压闭合的地板**：`barotropic` 在 `A = 1 dx` 上 `1.599e-02`，与前一单测得的 `1e-4 g` 量级下限一致——这是 Tait 状态方程的非线性造成的，不是算子造成的。
* 适用范围：二维、`rho0/c0/gamma` 如 §1、`dx = 0.040, 0.020`；三维与更细网格未测。

## 7. 注意点（踩过的坑）

* `build_state` 用 `pool_lattice` 造格点，而后者读 **torch 全局默认 dtype**；
  不设置 `torch.set_default_dtype(torch.float64)` 时格点以 float32 生成，
  镜像配对误差 ~1.5e-8 直接触发 `_columns` 的对称性断言（本单修了这个隐式依赖）。
* 扰动必须重建对表（`fresh_pairs`）：案例默认冻结 t=0 的对表，那是静止态的性质，
  扰动前后用同一张表会把两种构型混在一起。
* 位移读数只取自由面行：闭式水槽里的壁面行几乎不动，用全域最大值会掩盖响应。
* 周期水槽驻波对照在本分辨率上失稳（见 §4 末），说明「扰动型对照」在粗网格上本身就是一道独立课题；本单改用斜率误差对照来证明度量活着。
