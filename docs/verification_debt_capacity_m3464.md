## 5. 注意点（踩坑 / 局限 / 适用范围）

1. **F1（新，平台级）：集群节点当前跑不了 torch 求解器。** n330 默认 python3 无 torch、
   无 conda env（探针 job `c1793786016_279` / `c1793786072_380`）。bootstrap 宣称的
   「重计算一律上集群」对 TensorSPH 及一切 torch 系求解器**当前不成立**。
   按控仓令只报告不改码；建议平台侧给节点装 CPU torch 或提供 env 挂载。
2. **F2（新，流程级）：worktree 清理会丢后台跑产物。** m3420 的毛细波阶梯
   （dx=0.01/0.005/0.0025 × 5.5–6.5 s）后台启动后 worktree 被清理，`convergence/dx_*.json`
   全部丢失，欠账重开。建议：后台跑产物一律落 `/root/tp-agent/artifacts/<mission>/`
   持久路径，worktree 只放代码。
3. **F3（调度建议）：表面张力线 5 条未合并分支 + 2 条在飞单饱和。** m3428 已把旧 P0
   （自由面压强闭合）证伪为「非唯一门槛项」并给出新 P0（CSF 力幅值 ~0.56 σ/R，
   径向积分口径）。建议 merge-governor 优先合 m3428，避免后续单继续在旧 P0 上重复劳动。
4. 本单未跑任何 SPH 时间积分（容量纪律）；表中数字均为既有工件的转录，指针见
   `benchmarks/capillary_wave/convergence/STATUS.json` 的 `evidence` 字段。
