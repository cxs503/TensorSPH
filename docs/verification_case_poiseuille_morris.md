## ① 问题与参考出处

二维槽道（壁面 `y = 0, H`，无滑移，`x` 周期），常体力 `g` 沿流向驱动，低 Reynolds 数下为稳态抛物线；从静止启动是经典 Boussinesq 级数。这正是 Morris, Fox & Zhu 用来标定 SPH 黏性算子的槽道问题。

- 文献: Morris, J. P.; Fox, P. J.; Zhu, Y. *Modeling Low Reynolds Number Incompressible Flows Using SPH*, Journal of Computational Physics **136**(1): 214-226 (1997), DOI `10.1006/jcph.1997.5776`（Crossref 元数据核对）。
- **参考值零手抄**: 表里的 ref 全部由程序在运行时从解析解算出——`u_s(y)=g(H-y)y/(2ν)`、`u_max=gH²/(8ν)`、`τ_w=ρgH/2`、`Q=gH³/(12ν)`、启动级数 `u(y,t)=u_s-(4gH²/νπ³)Σ_{n odd} sin(nπy/H)e^{-νn²π²t/H²}/n³`。
- 符号自证（sympy，残差必须恒 0）: ODE 残差 `0` → `True`；两端 BC = 0 → `True`；`u_max` 与 `gH²/8ν` 一致 → `True`；`τ_w` 与 `ρgH/2` 一致 → `True`；`Q` 与 `gH³/12ν` 一致 → `True`。
- 级数自证（数值）: IC 残差 `6.438e-09`、PDE 残差 `1.746e-05`（归一化）、10τ 稳态极限残差 `4.685e-05`（= `e^-10`，即首模仍存活）、截断敏感性 `0.0e+00` → `True`。
- 参数出处如实声明: the case is defined by dimensionless groups (Re_mean, h/H, L/H); the drive is derived from Re, not tabulated. The Morris et al. paper's own tabulated parameters were not re-read offline, so no literal table values are claimed (WITHHELD); the exact solution used for grading holds for any parameter set.

## ② 方法与实现

生产 WCSPH 路径，不改求解器，只设几何/驱动/判据：

1. `tensorsph.droplet_impact.rhs`：Tait EOS、求和密度、Morris/Brookshaw 黏性 Laplacian（库常数 2 的标准标定），`gravity=0`，体力 `g` 手工加到流向加速度上。
2. 无滑移边界用 `tensorsph.wall_mirror.plane_walls` 的镜像（ghost）粒子：近壁流体跨平面镜像、速度取反，作为**运动壁**交给 `rhs`；`wall_friction=1.0` 是必要条件——取 0 时 ghost 只进密度/压力，流体整体刚性加速（实测 `u = g t`、剖面完全平、壁剪 0，本任务踩过这个坑）。
3. `x` 周期用两幅镜像云（支撑 2h ≪ L/2，精确）。
4. 固定步长 `dt = min(0.3h/c0, 0.125h²/ν)`；运行 `8τ`（`τ=H²/π²ν`），在最后 25 % 窗口（`[6τ,8τ]`）时间平均，参考量用**同一窗口**的解析平均（`averaged_profile`，级数逐模解析积分），避免把残余瞬态算进离散误差。
5. 启动历史在 `t/τ = 0.1, 0.2, 0.4` 取样与级数对照（取更新前状态，避免一个时间步的错位）。

## ⑥ 失败模式、局限与工件

踩过的坑（全部保留在代码注释里，作为后来者的路标）：

1. **`wall_friction = 0` 时镜像壁完全不起作用**：ghost 只进密度/压力，流体整体刚性加速（剖面完全平、`u = g t`、τ_w = 0、slip = 100 %）——第一版就是这么错的，实测 u_max 偏低 29 %。修法：`wall_friction = 1.0`。
2. **拿稳态解析解去比时间平均剖面**：窗口里残余瞬态被记成离散误差（`t_end = 1τ` 时 u_max 偏低 43 %）。修法：参考量按同一窗口解析平均。
3. **一个时间步的取样错位**：更新后再取样却按步首时刻标注，`t/τ = 0.1` 处虚报 21 % 误差。修法：状态在时间 t 时取样。
4. **行峰值 vs 连续峰值**：最细排位于 `y = H/2 ± dx/2`，`u` 比连续峰值低 `(dx/H)²`（H/dx = 8 时 1.6 %），用 `gH²/8ν` 做 ref 会把这个采样偏差算作误差。修法：ref 取同一排上的解析值。

局限：
- 每排一个粒子的壁面层使**最靠壁的一排**系统性偏高（H/dx = 8 时 +10.5 %，16 时 +5.1 %），内部区间 RMS 已 <3 %，但壁面层本身只有一阶有效分辨率；
- 判据是**离散误差 vs 解析解**，不是与实验的物理验证；本算例的物理内容（低 Re 层流）本身已被解析解穷尽；
- 参数集由无量纲群定义（Re = 0.1、ν = 1e-3 m²/s、H = 1 mm），Morris 原文表格值未能离线复核，故未声称任何原文表值（WITHHELD）。

工件：`benchmarks/case_poiseuille_morris/out/results.json`（全量：配置、符号/级数自证、逐排剖面、启动历史、敏感性）、`out/summary.md`、`out/figures/*.png`、`docs/verification_case_poiseuille_morris.md`（本文）。

### 误差判定（显式回答）

- 最细一级 `H/dx = 16`: u_max +0.51 %、剖面 RMS 0.72 %、τ_w 0.12 %、Q +0.77 %、slip 1.07 % → **全部 < 3 %**。
