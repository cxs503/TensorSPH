# CSF 表面张力曲率 / delta_s 的误差账（Young-Laplace 解析基准复核）

**范围**: `src/tensorsph/csf_consistent.py`、`src/tensorsph/surface_tension.py` ｜ **工件**: `benchmarks/csf_audit/{run.py, error_budget.json, error_budget.png}`、`tests/test_csf_error_budget.py` ｜ **上一轮**: `docs/verification_surface_tension_consistent.md`（m2447）

本文所有数字由 `benchmarks/csf_audit/run.py` 写入 JSON 后经 `benchmarks/csf_audit/make_doc.py` 程序化注入，无手抄。

## 1. 案例介绍

2-D 单相静止液滴，半径 `R = 0.02 m`，六方密排晶格，四周真空，无重力。解析基准三条（互相独立）：曲率 `kappa = 1/R = 50.0 1/m`；切割力 `F_cut = -2 sigma = -14.4 N/m`；delta 函数归一 `int delta_s dn = 1`。端到端另有 Young-Laplace 压差 `Delta p = sigma/R = 360 Pa`。

| 参数 | 值 |
|---|---|
| 半径 R | 0.02 m |
| 表面张力系数 sigma | 7.2 N/m |
| 参考密度 rho0 | 1000 kg/m^3 |
| 分辨率 dx | 1.5, 2, 3 mm（h = 1.3 dx） |
| 接受判据 | 15% (kappa) / 15% (delta_s) / 15% (F_cut) |

## 2. 怎么做的

上一轮（m2447）把 CSF 离散换成核和色函数 + MLS 一阶完备算子后，留下了三条未结清的读数：曲率 +25%、`int delta_s dn = 0.74`、而切割力恒等式却"通过"（1.07-1.11）。本轮把这三条拆开逐项归因，手段是三组对照：

1. **算子一致性对照**（把"算子写错"与"被积的场不是我们以为的场"分开）：把 MLS 散度作用在精确线性场 `x/R` 上，解析值 `div(x/R) = 2/R`。
2. **权重落点剖面**：把 `delta_s * V` 按 `r/R` 分层统计，看表面张力到底加在哪些粒子上。
3. **切割力恒等式的因式分解**：`F_cut/(2 sigma) = kappa_bar * int delta_s dn`，分别给两个因子打分，再验证乘积恒等式成立——用以区分"力模型对"与"两个误差抵消"。

在此基础上实现并打分一个修复候选 `cfg.csf_scheme = "consistent_jump"`：色函数先做 1 遍 Shepard 平滑再差分（去掉晶格尺度的折角），delta_s 的归一因子由硬编码 2 改为实测跳变 `1/(c_max - c_min)`。

## 4. 结果判读

1. **算子无罪**：MLS 散度在精确线性场上误差 1e-16，+0%量级；`docs/verification_surface_tension_consistent.md` 第 4 节把 +25% 曲率归因为"div n 在两层壳内偏高"，本轮进一步定位：偏高的部分是**色函数在体相已饱和（c≈0.99）处仍有 34-36% 的 delta_s 权重**，那些粒子上的 kappa 是 1/R 的 1.5-6 倍（见 3.3 表首行），既是评分伪影也是真实的体相伪力。
2. **切割力的"通过"是两个误差相乘的结果**：`F_cut/(2 sigma)` 的乘积恒等式闭合在 1.2% 内，而 kappa 与 delta_s 各自都在 15% 带外。因此 m2447 中"切割力已进入判据"的说法需要下调：它证明的是**力的方向与量纲**，不是幅值精度。
3. **修复候选有效但有分辨率门槛**：`consistent_jump` 把体相权重从 34-36% 压到 0%，曲率误差 +13.5%（dx = 1.5 mm，是进 15% 带），delta_s 0.919、F_cut 1.134 同时达标；但 dx = 3 mm 上曲率仍 +30.6%，**未过门**。
4. **伪流一致下降**：三档分辨率上 `max|v|/v_ref` 均由 0.038/0.044/0.041 降到 0.030/0.040/0.030，全部低于 Adami (2012) 的 0.1 阈值——这是 `consistent_jump` 的稳定收益，与体相伪力被消除的机理一致。
5. **端到端压差仍 WITHHELD，且本轮的读数比上一轮更不稳定**：同一模型在三档分辨率上给出 -124.6% … -6.0%，且推进到同一物理时间需不同步数。这说明 `p_core - p_shell` 的读数被求和密度噪声/状态方程地板主导，**任何单点"通过"都不能当作 Laplace 定律已解决的证据**（上一轮 4 mm/380 步的 xpass 即属此类）。

## 5. 注意点（踩过的坑）

1. **邻居表是无向的**：`cell_linked_pairs` 每对只出现一次；任何"逐粒子求和"的统计（曲率拟合、权重剖面）必须同时把 `(i,j)` 与 `(j,i)` 记入，否则一半邻居被丢掉，局部拟合退化成病态解。本轮第一版圆拟合曲率因此给出 ±60% 的乱跳。
2. **`shepard_smooth` 只接受 (N, 2) 向量场**：对色函数（标量）要传入 `(N, 1)` 再用 `[:, 0]` 取回。
3. **不要在 `on-the-fly` 里用未归一坐标做二次拟合**：`x^2 ~ 1e-6` 与 `x ~ 1e-3` 的列尺度差 1e3，直接解正规方程得到的是数值垃圾（实测曲率误差 +4000%/8e5%）。必须按 `h` 无量纲化。
4. **`c` 的 `max - min` 当跳变**：单相云里体相 `c = 1`，最外层粒子 `c ≈ 0.62-0.65`（`h = 1.3 dx` 的六方晶格只保留约半个核），所以硬编码的因子 2 恰好偏低 30%——这就是 delta_s 只有 0.74 的来源。
5. **压差判据对推进时间敏感**：不同 dx 的 `stable_dt` 不同，固定步数并不对应固定 `t/t_sigma`（本轮 1.05/0.70/0.53）。跨分辨率比较必须先对齐物理时间。

## 6. 误差判定（逐项，显式回答"是否 < 3%"）

| 关键量 | 基准 | 原方案（dx=1.5mm） | 误差 | <3%？ | <15%？ | 修复后（dx=1.5mm） | 误差 | <3%？ | <15%？ |
|---|---|---|---|---|---|---|---|---|---|
| 曲率 kappa [1/m] | 50.00 | 62.591 | +25.2% | 否 | 否 | 56.751 | +13.5% | 否 | 是 |
| delta_s 归一 | 1 | 0.739 | -26.1% | 否 | 否 | 0.919 | -8.1% | 否 | 是 |
| 切割力 F_cut/(2 sigma) | 1 | 1.074 | +7.4% | 否 | 是 | 1.134 | +13.4% | 否 | 是 |
| Laplace 压差 [Pa] | 360 | 249.2 | -30.8% | 否 | 否 | -88.4 | -124.6% | 否 | 否 |

**结论（honest）**：

* 曲率、delta_s 归一、切割力三条静态解析判据在 `dx = 1.5 mm`（R/h ≈ 10）上**全部进入 15% 平台标准**，但**没有一条进入 3%**；dx ≥ 2 mm 时曲率仍越界，`consistent_jump` 不是全分辨率解。
* 端到端 Laplace 压差**仍是 WITHHELD**：三档分辨率读数发散（-6% … -125%），被压强场分辨地板主导，本轮未改压强基准，因此不主张解决。
* 上一轮"切割力通过即力幅值达标"的推论本轮**收回**：乘积恒等式显示它是 kappa(+25%) 与 delta_s(-25%) 的抵消。
* 建议（P1，写进 backlog）：把 `consistent_jump` 作为 `csf_scheme` 的推荐选项而非默认；曲率要进 3% 需要更高阶（二阶完备 MLS 或界面几何拟合）+ 更高 R/h，超出本轮单干范围。
