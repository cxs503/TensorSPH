# 单相液滴 Young-Laplace 压差复核：判据定义错误与真实残差

**范围**：TensorSPH `csf_scheme="consistent"`（`src/tensorsph/csf_consistent.py`，m2588 合入）
**工件**：`benchmarks/laplace_pressure_jump/`（生成于 2026-11-03T21:34:01，总墙钟 246 s）

## 1. 案例介绍

二维静止液滴，半径 `R = 20 mm`，表面张力 `sigma = 7.2 N/m`（10 倍水值，为把毛细时间压进步数预算），`rho0 = 1000 kg/m^3`，声速 `c0 = 20 m/s`（Mach ~ 0.03），运动黏度 `1e-2 m^2/s`，重力 0（排除静水压干扰），三角格子排布。

物理定律（二维 Young-Laplace）：单相液滴在真空中内部压强均匀，

    p(r) = sigma / R   (r < R),      p = 0   (r > R)。

判据是一个**阶跃**：内部压强 vs **环境（真空）压强**。关键在于「环境」在 R 之外，而不是 R 之内。

## 2. 怎么做的

1. **纠正判据定义**。m2174 / m2588 把压差记作
   `Delta p = p(r<0.5R) - p(0.80R<r<0.95R)`。但 `0.80–0.95 R` 仍在液体内部，按定律其压强   **等于**核心压强，因此该式测的是「内部压强的径向非均匀度」（即压强噪声），**不是**跳变。   本次改为 `Delta p = p(r<0.7 R_eff) - p_amb`，其中 `p_amb = 0` 是单相模型里自由面   `clamp_min(0)` 强加的环境压强条件；`R_eff = sqrt(N·(√3/2)dx²/π)` 由粒子面积反算，   液滴胀缩时基准取 `sigma/R_eff` 而非标称 `sigma/R`。
2. **按毛细周期做时间平均**。液滴是极欠阻尼振子：黏性时间 `rho R²/mu = 40 s` 约 `10³ t_sigma`，而历史判据取 `t = 0.7 t_sigma` 的**单帧**——那不是平衡态。本工作推进到 `2.2 t_sigma`，并对最后一整个毛细周期做时间平均。
3. **竞争假设检验**（历史结论把残差归因为「EOS 分辨率地板」，本工作直接检验它）：
   - *EOS 地板*：若成立，误差应随 `c0²` 放大 → 用声速阶梯 `c0 = 20/10/5` 检验；
   - *自由面欠密*：密度求和在前两层自由面把 `rho/rho0` 压到 ~0.90，Tait 钳位后在**跳变必须形成的那层**压强恒为 0 → 用已有的 δ-SPH 密度扩散（`cfg.density_diffusion`，Antuono et al. 2010，默认关闭）检验。
4. **给出时间平均的径向压强剖面**，把残差定位到「内部平台高度不足」与「自由面壳层压强被钳到 0」两处，而不是只给一个标量差。
5. 判据门槛用平台标准：关键量 15%（目标 3%）。

## 4. 结果判读

- **判据定义错误是被记为 −75.6% 的主因**：同一时刻同一场，legacy 判据给 -93.7%，corrected 判据给 -37.4%。两者之差完全来自把「液滴内部」当成了「环境」。
- **残差的*均值*与 c0 无关**（c0 阶梯的 corrected 误差极差 1.9 个百分点）：EOS 分辨率地板只放大**噪声**（见下一组要点），**不能**解释稳定的 37% 均值缺口，因此历史文档「端到端压差被 EOS 分辨率地板吞掉」这一归因**只对噪声成立、对均值不成立**。
- **压强只在最外层被清零**：时间平均剖面显示 `r/R_eff>0.9` 的一层压强只有 51.3 Pa（该层 `rho/rho0 = 0.874`，Tait 钳位把它抹平），而内部平台 `r<0.7 R_eff` 平均 225.4 Pa = 0.63·`sigma/R_eff`。跳变必须在这一层里从 0 升到 `sigma/R_eff`，而它被钳位吃掉了。
- **噪声与偏置必须分开记账**（这是历史归因出错的地方）：内部压强**均值**与 c0 无关（-37.6% … -35.8%），但内部压强的**粒子级相对噪声** `std/mean` 随 c0 强烈下降（c0=20 → 80%、c0=10 → 59%、c0=5 → 25%），这正是「EOS 放大器」的表现（`dp/d(rho/rho0) = rho0 c0^2`，密度求和噪声 ~1e-3 在 c0=20 时折成 ~400 Pa）。因此：**EOS 地板解释噪声、不解释 37% 的均值偏置**；历史文档用噪声主导的「核心 vs 内圈带」差值当判据，才把它误记成均值误差。
- **缺陷在力的分布而非总幅值**：同一势函数的静态切割力恒等式 `F_cut/(2 sigma)` 已在 1.07–1.11（`docs/verification_surface_tension_consistent.md`），即**总幅值 < 15%**；而端到端跳变差 −37%，两者并存说明力被摊在 ~2 层的宽带里、并且自由面钳位吃掉了该带中的压强，属分布/边界条件问题，而非 `sigma` 被写错。
- **时间平均不可省**：单帧读数在 170–470 Pa 之间摆动（液滴以 ~4% 毛细速度振荡），任何基于单帧的判定都不可复现。

## 5. 注意点（踩过的坑 / 局限）

1. 判据必须先几何校核：单相液滴的「环境」只能在 R 之外；把内圈带当环境，等于用自己的噪声当基准，误差符号都不可信。
2. `R_eff` 必须由粒子面积反算。液滴在振荡中面积守恒但半径会偏离标称值，用标称 R 会引入与振荡同相位的系统误差。
3. 时间平均窗口取**一整个**毛细周期：窗口太短会把 n=2 振荡模态的相位差留在残差里，本工作实测单帧 vs 周期平均可差 40% 以上。
4. 局限：单相 CSF，无多相颜色函数；σ 取 10 倍水值、c0 = 20 m/s 是为步数预算的无量纲选择，判据形式（`sigma/R`、`sigma/R_eff`）与之无关，但绝对压强不可直接对水算例。
5. 局限：δ-SPH 扩散系数扫描只在 dx=2 mm、c0=20 上做；未做 δ 与 dx 的联合收敛，因此不能宣称 δ 的最优值。

## 6. 误差判定（逐项，显式回答「是否 < 3%」）

| 关键量 | 基准 | 实测 | 相对误差 | < 3%? | < 15%? |
|---|---|---|---|---|---|
| Laplace 压差（corrected 判据, 基线） | 360.378 | 225.431 | -37.4% | **否** | **否** |
| Laplace 压差（legacy 判据, 基线） | 360.378 | 22.633 | -93.7% | **否** | **否** |
| 内部平台压强（基线, r<0.7 R_eff） | 360.378 | 225.431 | -37.4% | **否** | **否** |
| 伪流 max|v|/sqrt(sigma/(rho R))（基线） | 0.100 | 0.071 | -29.2% | **否** | **否** |

**结论（honest）**：判据定义纠正后，基线的 Laplace 压差误差为 -37.4%，15% 门**未通过**；本工作把账从「−75.6%、归因 EOS 地板」改写为「几何判据错误（把液滴内部当环境）+ 自由面壳层钳位导致的跳变无法建立」，并把可复现的判据、时间平均协议与回归测试固化下来。诚实的部分失败点：压差仍未进 15%，属实现缺陷，不是验证缺陷。
