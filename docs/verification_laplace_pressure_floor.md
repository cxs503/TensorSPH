# 表面张力验证补记：曲率算子方案消融与 Young–Laplace 压差的测量地板

**仓**: TensorSPH ｜ **算例**: `benchmarks/laplace_law` ｜ **工件**: `instant_report.json`, `validation_report.json`, `laplace_law.png`, `curvature_scheme_ablation.png` ｜ **生成**: `benchmarks/laplace_law/make_doc_scheme.py`（数字全部由 JSON 注入）

## 1. 案例介绍

静止二维液滴（R = 20 mm，σ = 7.2 N/m，ρ0 = 1000 kg/m³，c0 = 20 m/s，γ = 7，六角格点排布，重力为零）在 CSF 表面张力下的平衡态。三条解析判据：

| 判据 | 解析基准 | 说明 |
|---|---|---|
| 曲率 κ | 1/R = 50 1/m | 圆上的 CSF 曲率算子 |
| 切割面力 F_cut | 2σ = 14.4 N/m | 表面张力＝单位长度力，跨过直径的合力 |
| 压差 Δp | σ/R = 360.0 Pa | Young–Laplace 定律 |

参数表（`validation_report.json` → setup）：dx = 0.002 m，h = 0.0026 m，N = 362，dt = 3.900e-05 s，steps = 900，t = 35.1 ms = 1.05 τ_σ。

## 2. 怎么做的

1. **修一次混合流水线缺陷**：`benchmarks/laplace_law/run.py` 原来自己抄了一份*legacy* 的 CSF 场构造函数（邻居计数色函数 + 0.7×均值阈值 + `κ = div n` + 无 2 倍因子的 δ_s），而力却由生产路径 `compute_surface_tension_force` 给出。两者只在 `csf_scheme="legacy"` 下才是同一算法；出厂默认 `consistent` 下，报告里的 κ / δ_s **不描述真正施加的力**。新增 `production_fields()`：一致性方案下力与场来自同一次 `surface_tension_acceleration` 调用（内部会把邻接表扩到拟合模板 4h；直接拿 2h 邻接表去 `csf_fields` 会把 κ 抬高 3–10 倍，这两条路不可互换）。
2. **方案消融**：`scheme ∈ {legacy, consistent:mls, consistent:fit_quadratic, consistent:fit_circle}` × dx ∈ {1, 1.5, 2, 3} mm，16 个静态评估，全部记录在 `instant_report.json → scheme_ablation`。
3. **δ_s 归一判据换成积分式**：Brackbill 给出 ∫δ_s dn = 1；二维下 S = Σ_i δ_s,i·V_i /(2πR) 必须为 1。此前用「带内均值 × 2h」作代理，随带宽漂移；S 不漂移，且直接等于 2(1 − c_surface)。
4. **压差判据的测量地板**：`tait_pressure` 在 ρ<ρ0 处钳到 0（标准自由面处理），所以 p_shell 永远报 0；真正被钳掉的量是未钳值的 Tait 压强。新增 `pressure_floor()`，报告壳层密度亏损、未钳压强、信号/地板比 `signal_to_floor = Δp_理论 / |p_shell_unclamped|`，并给出有效性判据。
5. **时间推进消融**：dx = 4 mm、380 步（一次毛细时间量级）在四个方案下各跑一遍，同时给出「直接探压」与「切割力代理 Δp = F_cut/(2R)」两条互不依赖的读数。

## 5. 注意点（踩过的坑）

1. **力与场必须同源**：此前的 κ / δ_s 来自 legacy 副本，与生产力不一致；任何「κ 误差」结论都必须说明用的是哪条流水线。
2. **拟合曲率要自己的模板**：`surface_tension_acceleration` 内部把邻接表扩到 4h 再拟合；把 2h 表塞给 `csf_fields` 会让二次拟合 κ 从 −0.4 % 恶化到 +196 %，这不是算子的问题，是模板的问题。
3. **圆拟合（fit_circle）在本算例上是坏的**：κ +77 %…+477 %，力 1.5…5.1 倍，且随加密**变差**。单测（理想圆点集）通过不等于晶格液滴上可用——此前文档把它写成可选方案，本文件据实修正为**不建议**。
4. **δ_s 的 2 倍因子不够**：S = 0.66…0.70（应为 1），且几乎不随 dx 收敛（0.702 → 0.660），因为自由面层看到的核支撑比例是几何常数。这解释了「κ 精确（fit）时切割力反而偏低到 0.85–0.90」：幅值缺口出在 δ_s 归一，不在曲率。
5. **压差不能靠钳零后的差值**：`p_shell` 恒为 0，Δp 探压实际只测到「核心过压」。dx = 4 mm 那次 +5.6 % 的「通过」是巧合：该分辨率壳层亏损 18.7 %，未钳压强被吃掉几十 kPa，远超 360 Pa 信号。旧判据把它记成 pass（**假通过**）。
6. **伪流已经达标**：一致化方案下 max|v|/√(σ/ρR) = 0.037 < 0.1（Adami 2012），此前记录为 FAIL 的老数字来自 legacy 流水线。

| 伪流 max|v|/√(σ/ρR) | < 0.1 | 0.037 | — | 是 | 是 |

**结论**：

1. 曲率算子的验证欠账**部分结清**：二次曲面拟合在 dx ≤ 2 mm 内把 κ 误差压到 -0.4 % … +5.3 %（dx = 1 mm 时 −0.4 %，**< 3 %**）；出厂默认 `div n` 仍是 +25 %，**未达标**。
2. 曲率达标**没有**带来力达标：二次拟合下切割力恒等式降到 0.845–0.899，甚至略出 15 % 带；原因定位到 δ_s 归一 S = 0.66–0.70（应为 1，且不随加密收敛）。两种方案都没让切割力收敛到 2σ，这一项**仍是未结清**。
3. 端到端压差**判据被证伪而非达标**：所有测试分辨率的 `signal_to_floor` 都远小于 1，探压测的是 Tait 零钳压的地板而不是 Laplace 压差。历史上「dx = 4 mm 通过」被本文件改判为**假通过**（对应回归测试已改为 strict xfail 并附地板证据）。
4. 下一轮的可执行修法（需改 `src/`，本轮只给诊断）：
   - δ_s 归一到积分 1（S 的实测值可直接当归一因子），或改成 δ-SPH 式的密度/界面归一；
   - 压差改用对密度欠采样不敏感的读数（δ-SPH 密度扩散，或 Adami 2012 的背景压强式 Tait `p = p0 + B[(ρ/ρ0)^γ − 1]`），否则 Δp 判据在 R/h ≲ 10 时不可用；
   - `fit_circle` 在晶格液滴上失效，建议加 `NotImplementedError`/告警，或先修「邻域点不足时回退」的判定。
