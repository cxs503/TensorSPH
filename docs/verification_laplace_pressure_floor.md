# 端到端 Young–Laplace 压差为什么一直测不到：误差源分解
> 数值口径说明：本文部分数字为历史口径；当前值、测得口径与证据分级见 [`docs/verification_ledger.md`](verification_ledger.md)（程序化生成的验证断言账本）。


**仓库**: TensorSPH ｜ **工件**: `benchmarks/laplace_pressure_floor/` ｜ **测试**: `tests/test_laplace_pressure_floor.py`

**结论（先给判定）**: 连续三轮验证（legacy CSF → consistent CSF → 拟合曲率）都把端到端
Young–Laplace 压差判为 WITHHELD（-93.6% / -75.6%（历史口径） / -87.6%），并把原因归给「表面张力离散/压强基准」。本单把它拆开实测，
发现原来的失败里有 **48 个百分点是测量口径造成的**（把自由面密度亏缺带当成流体压强来读），
剩下一段 **37% 的残差与 c0、与分辨率、与曲率算子都无关**（34%…38%），
它是一个**压强闭合**问题：Tait 压强钳在 p≥0，而自由面壳层密度亏缺 −6%（0.85–0.95R）到
−31%（0.95–1.05R），壳层粒子全部落在 p=0 上，界面区无法承载 `sigma/R`，液滴内部只压到
解析所需的 **0.57** 倍。**换曲率算子/换 c0/提分辨率都救不了它**——这是本单最硬的结论。
故 Laplace 压差仍为 **WITHHELD**，但欠账已从「不知道错在哪」变成「只差一个自由面压强边界」，
验收判据和下一步验收门槛都在 §⑥/§⑦ 落定。

## ① 案例介绍（物理背景/几何/参数）

半径 `R = 0.02 m` 的二维单相液滴，六方密排格子初始化，四周真空，无重力，静止平衡。
Young–Laplace 定律给出唯一可量化的整体判据

$$\Delta p = p_{in} - p_{out} = \sigma/R = 360.0\ \mathrm{Pa} .$$

Tait 状态方程以 `rho0` 为压强零点（`p(rho0) = 0`），真空就是 `p_out = 0`，故物理量就是
**液滴内部绝对压强** `p_core`，不需要、也不允许再减一个「壳层压强」。

| 参数 | 值 | 说明 |
|---|---|---|
| 液滴半径 R | 0.02 m | 静止自由液滴 |
| 表面张力系数 sigma | 7.2 N/m | 10× 水，压缩毛细时间 |
| 参考密度 rho0 | 1000 kg/m³ | 弱可压 Tait，gamma = 7 |
| 状态方程 | `p = B[(rho/rho0)^gamma - 1]`，`B = rho0 c0^2/gamma`，钳 p>=0 | `droplet_impact.tait_pressure` |
| 平滑长度 | h = 1.3 dx | 三次样条核 |
| 分辨率 | dx = 0.0015 / 0.002 m（N = 642/362） | 六方密排圆盘 |
| 声速阶梯 | c0 = 20, 10, 5 m/s | 本单的判别器 |
| 粘度 | 0.01 m²/s | 层流正则化 Laplacian |
| 毛细时间 t_sigma | 0.0333 s | 观测窗口 1.5 t_sigma |
| 解析压差 sigma/R | **360.0 Pa** | 待比对基准 |
| 所需压缩 (rho/rho0-1) | c0=20: 8.98e-04；c0=5: 1.38e-02 | 由 Tait 反解 |

## ② 怎么做的（方法/流程）

同一物理量用**四种口径**同时读，从而把误差按来源分开：

| 口径 | 定义 | 它在测什么 |
|---|---|---|
| bandA（历史口径） | `p(r<0.5R) - p(0.80–0.95R)` | 前三轮验证用的口径；上带落在自由面密度亏缺区 |
| bandB | `p(r<0.5R) - p(0.60–0.80R)` | 亏缺区内侧边缘 |
| absolute | `p(r<0.5R) - 0` | Tait 归一化下的物理压差 |
| tail-avg | absolute 在窗口后 40% 的时间平均 | 去掉呼吸模态（周期 ~ t_sigma）的快照噪声 |

四个候选误差源，逐个用可观测量证伪/证成：

- **C1 测量口径**：同一份流场，bandA 与 absolute 之差即口径代价；
- **C2 初始化偏置**：六方格子 `h = 1.3dx` 下离散核和不为 1，实测 `rho/rho0 - 1 = +0.00588`
  （逐粒子 std ~1e-16，是**系统**偏置不是噪声），对应初始虚假压强 `B[(1+b)^gamma-1]`
  = c0=20 时 **2395 Pa**（信号的 6.7 倍）。用一次质量校准
  `m -> m/(1+b)` 把它压到归一化值 1.0（残差 < 1e-15），并保留未校准算例作 A/B 对照；
- **C3 自由面压强闭合**：Tait 钳 p>=0 + 表面密度亏缺 → 壳层压强恒为 0，界面无法承载 `sigma/R`。
  判据是「内部实际压缩 / 定律所需压缩」的比值及其对 c0、dx 的不变性；
- **C4 状态方程分辨率地板**：`sigma/R` 需要的压缩只有 9.0e-04（c0=20），若动力学密度噪声
  `sigma_rho` 与它同量级，压差读数就被吞掉。用**实测**动力学噪声算 `p_noise = rho0 c0^2 sigma_rho`
  （不用初始格子的 0，那是系统偏置而非噪声）。

判别逻辑：C4 预测残差随 c0 下降而下降（`~rho0 c0^2 sigma_rho`），C3 预测残差不随 c0 变。

工具链：`benchmarks/laplace_pressure_floor/run.py`（自带 relax 循环，复用生产 RHS `droplet_impact.rhs`、
`csf_consistent` 表面张力，**不改 src/**）、matplotlib、pytest；本文所有数字由 `make_doc.py`
从 `report.json` 注入。

| dx [m] | c0 [m/s] | C1 口径代价 | **残差（C1 之后）** | C4 预测噪声占比 | 压缩比（实际/所需） | 残差可否由 C4 解释？ |

| 0.0015 | 20 | -47 pt | -38.1% | 28% | 0.56 | 部分 |
| 0.0015 | 10 | -49 pt | -36.2% | 10% | 0.68 | 否（残差 >> 噪声） |

| 0.002 | 10 | -51 pt | -37.2% | 23% | 0.50 | 部分 |
| 0.002 | 5 | -44 pt | -34.0% | 7% | 0.57 | 否（残差 >> 噪声） |

- **C1（口径）均值 48 个百分点**：前三轮的「-76%…-107%」里，一半以上是减掉了一个
  位于密度亏缺带的压强。这是**测量定义错误**，不是模型错误。
- **C4 被证伪**：c0 从 20 降到 5，C4 预测的噪声占比从 34% 掉到 5%，
  而实测残差只从 38% 变到 36%（4 个百分点的波动，无单调趋势）。
- **C3 被证成**：压缩比在全部 6 个算例上为 **0.57 ± 0.06**，
  对 c0（20, 10, 5）与 dx（0.0015/0.002）都不敏感——这正是「界面区压强恒为 0、
  内部只能靠渐变承载一部分 `sigma/R`」的几何/闭合特征。

### 3.4 A/B 对照（隔离 C2 与曲率算子）

| 对照 | 设置 | absolute 误差 | tail-avg 误差 |
|---|---|---|---|
| C2：未校准质量 | dx=0.002, c0=20 | -44.4% | -37.8% |
| C2：质量已校准 | dx=0.002, c0=20 | -42.1% | -37.9% |
| 曲率：`mls` | dx=0.002, c0=5 | -38.7% | -25.1% |
| 曲率：`fit_quadratic` | dx=0.002, c0=5 | -43.6% | -34.0% |

- **C2（初始化偏置）在稳态读数上只有 -0.1 个百分点**：它是**瞬态**问题（初始虚假压强
  2395 Pa 会激发呼吸模态），不是稳态偏差。**诚实记录**：不能拿它当失败的主因。
- **曲率算子只值 -8.9 个百分点**：`mls` 与 `fit_quadratic` 的稳态残差只差这么多，
  远小于 C1/C3 的量级。这解释了为什么前两轮换算子（曲率 +25%→+0.9%）救不了端到端压差。
  注意 `mls` 的稳态残差反而**更小**（-25.1% vs -34.0%）：`mls` 的曲率高估 25%
  与内部压缩亏损互相抵消，属于**误差掩盖**而不是精度更好——口径统一后用 tail-avg 读数比较才不会上当。

## ④ 结果判读

1. **压差没测到，不是表面张力模型错**：切割力恒等式（力的幅值 `2 sigma`）在前两轮已进 15% 门
   （7–11%），法向中位 `cos = 1.000`；本单进一步说明端到端压差的失败**不随曲率算子/声速/分辨率
   移动**，属于压强闭合，不属于表面张力离散。
2. **历史的 -76%…-107% 不可再引用**：其中 48 个百分点来自 bandA 口径（把
   `0.80–0.95R` 的密度亏缺区压强当流体压强）。用 absolute/tail-avg 口径后残差是 37%。
   这条对之前三份验证文档都适用，应视为口径勘误。
3. **C2 是真实缺陷但不是主因**：`rho/rho0` 系统偏置 +0.006% 会让**任何** wcSPH 算例
   （不限表面张力）在 c0=20 时带 2395 Pa 的初始虚假压强，量级可与液滴撞池的惯性压强
   相比。已登记为独立 P1（§⑦）。
4. **C3 是当前唯一的门槛项**：需要自由面/壳层压强边界（Adami 2012 §3.3 的 shell-pressure
   extrapolation，或 δ-SPH 归一化密度），本单只做定位与判据，不擅自改 `src/` 的 RHS。

## ⑤ 注意点（踩过的坑）

1. **不要把「p_core - p_shell」当成 Laplace 压差**：单相粒子云在真空中，`p_out` 由 Tait 归一化
   （`p(rho0)=0`）决定而不是由某个壳层粒子给出；壳层位于密度亏缺带，读到的不是流体压强。
2. **时间平均是必须的**：呼吸模态周期 ~ t_sigma，单快照的 absolute 读数在 -51%…-33% 之间摆，
   时间平均把散布压到 4 个百分点以内。
3. **初始格子的 std 是 1e-16 而不是「噪声地板」**：`rho/rho0-1 = +0.00588` 是核和归一化的系统偏置；
   真正的 C4 噪声来自动力学（粒子离开格子后的求和密度抖动，实测 2.6e-04…9.9e-04）。
   用前者当噪声会得出「C4 不存在」的错误结论。
4. **钳 p>=0 是有代价的**：它压掉了拉伸不稳定，但同时在自由面制造「p=0 墙」，压强梯度无法跨过亏缺带，
   这就是 C3。任何「加 Laplace 偏置 p0 = sigma/R」的补丁等于把答案塞进 EOS，本单不采用。
5. **质量校准必须用核心区测偏置**：0.70R 以外核被自然截断，用那里测出的偏置会把亏缺一起校准进去。
6. `/tmp` 里放探针脚本会被同机其它 agent 覆盖（本单实际踩到：`/tmp/probe.py` 被换成别人的脚本），
   临时件请放工作树或带 mission id 前缀。

## ⑦ 下一步（欠账登记，需改 src/，不在本单）

1. **P0｜自由面压强闭合（C3，唯一门槛项）**：在 `rhs` 的压强装配处加 shell-pressure 外推
   （Adami, Ihmsen & Adams 2012, JCP 231:7057, §3.3）：对自由面粒子（`rho/rho0 < 0.99` 或
   色函数 `c < 0.99`）用内部邻域外推
   `p_i = max(0, sum_j (p_j + rho_j g·r_ji) W_ij / sum_j W_ij)`。
   验收判据（机器可裁）：本benchmark的 `absolute_time_average_tail` 在 c0=20 与
   c0=5、dx=0.0015/0.002 四点上全部 **< 15%**，且 `tests/test_laplace_pressure_floor.py`
   里 `xfail(strict=True)` 的 15% 用例自动转 xpass。
2. **P1｜初始化质量校准（C2）**：`make_particles`/密度初始化按核心区实测核和做一次
   `m -> m/(1+b)`；验收：初始 `p_max` 相对 `rho0 c0^2` 的偏置 < 1e-4。
3. **P2｜验证口径统一**：后续所有 Laplace/表面张力验证一律用「绝对压强 + 时间平均」，禁止
   `p_core - p_shell` 口径；本文件 §③.2 的 bandA 列只作历史对照保留。
