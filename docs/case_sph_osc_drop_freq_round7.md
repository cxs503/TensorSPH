# CASE-SPH-OSC-DROP-FREQ · 第 7 轮 — 第 4 轮"通过"的收敛阶是假设的，不是测出来的

锚点：`CASE-SPH-OSC-DROP-FREQ`（ref: Rayleigh 1879；容差 <6 %）。第 4 轮用两条独立通道（A 色场等值线
模态幅值、B 表面能）在 `R/dx ≥ 24` 上判"进 6 % 门限"，但其判决式 `g = 1 − c/(R/dx)` **假定了一阶收敛**
（`transfer_law()` 只有两个参数：截距 + 系数，基函数固定在 `h = 1/(R/dx)`）。本轮的净增量就是把这个假设
换掉：**用实测收敛阶 + 保守 GCI + ASME V&V 20 验证不确定度**重判同一批数据。

结论（honest）：**门限在 `R/dx = 24` 的 10/10 行上复现，但"渐近性"没有通过验证**——10 行里只有 3 行
的 Richardson 外推极限 `Q∞` 与精确值 1 在 `U_V` 内相容；`l = 3` 的实测阶稳定在 **p ≈ 1.93**（不是 1），
外推极限落在 **−2.5 %**，即该估计器的渐近值本身带 −2.5 % 偏差，不是 0。第 4 轮"两条通道在 24 一致
⇒ 通过"的表述因此必须**收窄**：它成立，但其中 route A 的 `l = 2` 行**非单调**（12→0.9886、16→0.9166、
24→0.9689），那一行的"通过"是格点上的巧合，不是收敛序列上的点。

## ① 案例介绍

半径 $R$、密度 $\rho_0$、表面张力 $\sigma$ 的无粘液滴，形变 $r(\theta)=R[1+\varepsilon P_l(\cos\theta)]$
的自由振荡，Rayleigh (1879) / Lamb (1932) Art. 275：

$$\omega_l^2=l(l-1)(l+2)\frac{\sigma}{\rho_0R^3},\qquad l=2:\ \omega=\sqrt{8\sigma/(\rho_0R^3)}=2.8284\ (R=\rho_0=\sigma=1)$$

被审计的量是**无量纲频率比** $Q=\omega_{\rm meas}/\omega_{\rm Rayleigh}=\sqrt{g}$（模态刚度对重构幅值
线性 ⇒ 频率取平方根，沿用第 4 轮约定），精确值 `Q = 1`。门限：`|Q − 1| < 6 %`。

| 参数 | 值 | 说明 |
|---|---|---|
| 阶梯 `R/dx` | 12 / 16 / 24（本轮实测）；32 / 40（已递交 `cj4101`，收尾时 queued） | 等值线网格 4 点/dx |
| 模态 `l` | 2, 3 | `l = 1` 是平移 |
| 幅值 $\varepsilon$ | 0.02, 0.05（route A）；0, ±0.02, ±0.04（route B 中心差分） | 线性区 |
| 安全因子 `Fs` | 1.25 | Roache 保守取值 |
| 精化比 `r` | 24/16 = 1.5 | 本轮最细一对 |

## ② 怎么做的

1. **不重写测量**：直接复用第 4 轮的两条独立通道（`benchmarks/oscillating_drop_freq/round4_energy_contour.py`
   中的 `transfer_ladder()` / `estimator_control()`），保证本轮判的是**同一批数字**，只换判据。
2. **实测收敛阶**：拟合 `Q(h) = Q∞ + C h^p`，`h = 1/(R/dx)`；对每个 `p`（0.2–4.0 网格搜索 761 点）用
   线性最小二乘解 `(Q∞, C)`，取残差最小的 `p`；并给出残差在最小值的 1.05 倍以内的 `p` 区间（`
   p_band`）——因为三点定三参数时"阶"本来就不该报成一个数字。单调性是硬约束，非单调行显式标注。
3. **保守 GCI**（Roache）：`GCI_fine = Fs·|ε|/(r^p − 1)`，`ε = |(Q_coarse − Q_fine)/Q_fine|`。
4. **ASME V&V 20-2009**：`U_V = sqrt(U_num² + U_input²)`，`U_num = GCI`，
   `U_input` = **同一网格上解析水平集对照行**的偏差（估计器自身的数值偏置，不随 SPH 分辨率下降）；
   判定 `|Q_fine − 1| ≤ U_V`。
5. **可否证性**：判据代码本身有 10 项回归（`tests/test_oscillating_drop_freq_round7.py`），其中两项是
   **植入缺陷必须被检出**：合成 `Q∞ = 0.96` 的阶梯必须判 validation FAIL；二阶阶梯在 `h¹` 基下必须
   给出错误截距。工具链：`round7_convergence.py --part i --parts n`（可集群分片）+ `--merge`（出
   `out/round7.json` + 图 + verdict）。

|---|---|---|---|

## ⑤ 注意点 / 局限

1. **只有三个网格**：`p` 由 3 点定 3 参数，`l = 2` route A 的两行因此退化（p 顶到边界/区间宽）。
   `l = 3` 的两行残差 `1.4e-6`、`p` 稳定 1.93–1.94，是**唯一可以当阶来读**的通道。32/40 两档已递交
   集群（`cj4101`，5 分片），本轮收尾时仍在 queued，**未取回**，所以本报告不写 4/5 网格的 `p`。
2. **`l = 3` 的 −2.5 % 渐近偏差是真的**：GCI 只有 2.2–2.5 %，`U_input` 0.005 %，`|Q∞ − 1| ≈ 2.5 %`
   大于 `U_V` ⇒ validation FAIL。含义：该估计器**收敛到 −2.5 %，不是 0**。这与第 3/4 轮"`R/dx ≥ 24`
   进 6 %"不矛盾（门限比偏差宽），但把结论从"随分辨率趋于精确"改成"停在 −2.5 %"。
3. **第 4 轮 `transfer_law` 的系数歧义被解释**：一阶基下 `l = 2` 拟合 1.91、`l = 3` 拟合 2.20，两者不一致
   正是因为真实阶 ≈ 1.9，`h¹` 基把阶的失配塞进了系数与截距。**不要再用那个系数推"门限分辨率 16.4/18.9"。**
4. **单取向**（`ψ = 0`）与第 4 轮相同，未做取向系综；`l = 2` 的非单调有可能是特定取向的格点效应，
   需要系综才能定论（下一单候选）。
5. `ε = 0.02` 与 `0.05` 的 `Q(24)` 差异 ≤ 0.7 %（`l = 3` 两行完全相同），线性区成立。

## ⑥ 误差判定（逐项，明确回答"是否 <6 %"）

| 关键量 | 结果 | 基准 | 误差 | <6 %？ |
|---|---|---|---|---|
| `Q(24)`，`l = 2`，A / A′ / B | 0.9689 / 0.9582 / 0.9598 | 1（Rayleigh） | −3.11 / −4.18 / −4.02 % | **是** |
| `Q(24)`，`l = 3`，A / A′ / B | 0.9573 / 0.9572 / 0.9595 | 1 | −4.27 / −4.28 / −4.05 % | **是** |
| 外推极限 `Q∞`，`l = 3`（p = 1.93） | 0.9745 | 1 | **−2.55 %**，`U_V = 2.3 %` | **否（V&V 20 FAIL）** |
| 外推极限 `Q∞`，`l = 2`，A′（p = 1.05） | 0.9985 | 1 | −0.15 %，`U_V = 5.3 %` | 是（但 GCI 5.3 % 本身已接近门限） |
| 实测收敛阶 `p`（`l = 3`） | 1.93 ± 0.01 | 第 4 轮假定 1 | 93 % | **否（第 4 轮假设被证伪）** |
| 实测收敛阶 `p`（`l = 2`，A） | 未建立（非单调） | — | — | **未测（不得声称）** |
| 估计器自身偏置（解析水平集对照） | ≤ 0.048 % | 0 | — | 是 |
| `R/dx = 32 / 40` 外推 | **not_run**（`cj4101` queued） | — | — | **未测** |

**总账锚点结论（honest）**：6 % 门限在 `R/dx = 24` 上 **10/10 行复现**（与第 4 轮一致），但本轮把判决依据
从"假定一阶"升级为"实测阶 + GCI + V&V 20"后，**渐近性只在 3/10 行通过**：`l = 3` 的极限带 −2.5 %
偏差（超出 `U_V`），`l = 2` route A 的 24 档"通过"依赖一个非单调下陷。因此
`CASE-SPH-OSC-DROP-FREQ` 应保持 **open**，且账上应把第 4 轮的"独立复核通过"改写为
"**6 % 门限在 24 通过、渐近偏差 −2.5 % 未消除、`l = 2` 收敛序列未建立**"。
