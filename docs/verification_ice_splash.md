## 1. 案例介绍：物理背景、几何与参数

### 1.1 物理背景

船艏破冰时，艏柱与浮冰之间的水被瞬时挤出：一道涌波沿冰/艏斜坡爬升，越过甲板缘后抛射为水舌与飞沫；同一冲击把已破碎的冰块抛掷出去。事件持续 O(0.1–0.5) s，由惯性与重力主导（Froude 相似），黏性与表面张力在量级上可忽略——这正是弱可压 SPH（WCSPH）+ 刚体床面的最小工具区间。

本节点只立**最小已验证能力面**（定性谱事件 → 定量工程量留给后续波），因此刻意不解析：

* 真实船艏/冰缘的几何（用斜坡 + 平台作为几何抽象）；
* 浮冰刚体动力学（用"虚拟测力板 + 冲量传递"降阶模型，见 §2.5）；
* 液滴破碎/飞沫谱（碎裂段只作为**模型失效边界**被明确标出，见 §3.4）。

### 1.2 几何（2-D，单位宽度，与平台其余算例一致）

```
 y
 ↑            ┌──────────── deck (冰面上表面 / 甲板)  y = 0.28 m
 │        ╱    │
 │  ramp ╱     │  ← 冰斜坡 sheet_angle = 25°
 │      ╱      │
 │ water│      │
 │ column      │
 └──┬───┬──────┴─────────────────────────────→ x
   0  0.20  0.80 (deck_start)              1.00 m
```

* 水柱 `[0, 0.20] × [0, 0.28] m`，t = 0 静止释放（溃坝式释放，得到高度已知的涌波）；
* `x ≥ sheet_start = 0.20 m` 起为刚性冰面：25° 斜坡升至 `deck_height = 0.28 m`，随后为水平平台（甲板）直到远壁 `x = 1.00 m`；
* 左右端壁 + 全宽地板 + 斜坡/甲板，全部用 Adami (2012) 壁面粒子表示，壁粒子置于流体域外半格处（与 `wall_lattice` 同一约定）；端壁是必需的：否则溃坝的背向波与远壁冲击会被 `apply_boundary` 的夹持静默吃掉动量（踩坑见 §5.1）。

## 2. 方法：怎么做的

### 2.1 求解内核（复用，不复制）

积分器与物理内核直接复用平台已验证实现：`tensorsph.droplet_impact.rhs`（成对核、密度求和、Tait 压力含零点钳制、Adami 壁压外插）、`PairListCache`、`apply_boundary`；`make_column` 提供静水压初始化的水柱。新模块只增加几何、量测与后处理，**不改内核行为**。

时间推进为半隐式（symplectic）Euler：`v ← v + dt a`，`x ← x + dt v`，与 `dam_break.run_case` 完全一致。

### 2.2 新增的边界接触条件（本模块唯一的新增数值处理）

`apply_boundary` 只在粒子**越界**时把法向速度清零；被压到恰好贴面的粒子落在容差内，法向动量会无界累积（实测 0.2 s 出现 15 m/s 的非物理速度，全部来自地板角落）。模块在每步 `apply_boundary` 之后，对**贴面**粒子把向内法向分量清零（`v_y ← max(v_y, 0)` 等），这正是该夹持本应施加的边界条件。修正后 `escaped = 0`、最大速度回到物理量级。

### 2.3 量测（gauges）

| 量 | 定义 |
|---|---|
| 首波前沿 | `max x`（水粒子） |
| 甲板上浪量 | `x > deck_start` 且 `y > deck_height − dx/2` 的水粒子数 × dx²，单位 m³/m（即 L/m） |
| 飞溅顶点 / 抛距 | `max y`；`max x − deck_start` |
| **弹道自洽** | 越过甲板高度、且 `v_y > 0` 的每个水粒子：记录穿越点的 `y₀, v_y`，与它此后实际达到的顶点比对，`预测 = y₀ + v_y²/(2g)` |
| 到达时刻 | 第一滴水上到甲板（`deck_arrival`）、第一滴水越过甲板缘（`crest_arrival`） |
| 首次边界接触 / 首次碎片 | 夹持触发时刻；第一个"悬空且流体邻居 ≤ 1"的粒子出现时刻 |

### 2.4 能量核算（本节点的一个实质发现）

WCSPH 的机械能 `KE + PE` 不是守恒量：压力做功有一部分变成可压缩弹性能。要闭合收支必须用**正确的 Tait 内能**：

```
e(ρ) = B/ρ0 · [ ((ρ/ρ0)^(γ-1) − 1)/(γ−1) + ρ0/ρ − 1 ],   B = ρ0 c0²/γ
```

它是 `∫_{ρ0}^{ρ} p dρ/ρ²`，在 `ρ = ρ0` 处为 `O(δ²)`（`δ = ρ/ρ0 − 1`），**而不是**教科书写法的 `p/((γ−1)ρ)`（那是 `O(δ)`，在 δ ≤ 5% 时比正确值大 30 倍，见 `tests/test_ice_splash.py::test_eos_internal_energy_is_second_order_in_compression`）。并且必须**只积分压缩侧**：内核的压力律 `tait_pressure` 在 `ρ < ρ0` 处被钳到 0（液体不能受拉），自由面密度亏损是截断伪影而非储能；对未钳制的抛物线积分会注入一个比真实储能大一个量级的虚假水库（实测把总能量漂移从 1.27% 变成 636%）。这两个错误都是本节点踩过并修正的。

### 2.5 碎冰抛掷：降阶模型（明确标注）

浮冰不作为刚体解析。在浮冰位置放一块**虚拟测力板**，用已解析的场测动量通量：

```
F_k = Σ_{i∈板} m_i·u_x,i² / dx        （二维单位深度，→ ρ u² h_wet）
J_k = ∫ F_k dt,   v_k = J_k / (ρ_ice π r²)
```

甲板以上的飞溅动能给出严格上界 `v ≤ sqrt(2 KE_splash / m_floe)`。两条线夹出区间；刚体耦合、阻力、旋转均缺席，故结论只作**量级估计**（§3.5）。测力板公式本身有独立验证：均匀射流下必须复现 `ρ u² h`（`test_force_plate_reproduces_the_momentum_flux_of_a_uniform_jet`，实测偏差 < 2%）。

### 2.6 与 DEM 航道场景的接口（粒子初始化交换格式）

`build_dem_exchange / validate_dem_exchange / write_dem_exchange / read_dem_exchange`，schema `tensorsph.dem-exchange/1.0`：

```json
{"schema": "tensorsph.dem-exchange/1.0",
 "source": {"solver": "tensorsph", "case": "ice_splash", "spacing_m": 0.0125,
            "rho0_kg_m3": 1000, "rho_ice_kg_m3": 917, "gravity_m_s2": 9.81, "seed": 7},
 "domain": {"x_min": 0, "x_max": 1.0, "y_min": 0, "y_max": 0.75},
 "particles": {"position_m": [[x,y],…], "velocity_m_s": [[vx,vy],…],
               "mass_kg_per_m": […], "radius_m": […], "material": ["water"|"ice",…]},
 "counts": {"water": 140, "ice": 5, "total": 145}}
```

校验器**拒收**：`spacing ≤ 0` 或非有限（负粒子间距负例）、`mass ≤ 0`（零质量负例）、`radius ≤ 0`、非有限坐标/速度、材料不在白名单、`counts` 与粒子表不一致、schema 不匹配。全部有 pytest 负例（§4）。

### 3.3 首波前沿时序锚（图 2）

| 量 | 平台已审计基线 | 本模块复现 | 相对偏差 |
|---|---|---|---|

**为什么用 `c` 而不是直接与实验曲线比**：平台此前的审计（`docs/benchmarks/dam-break-reference-audit.md` §6–7）已证明随附的 Martin & Moyce 表在无量纲化上不一致（`Z/a = 2τ` 与 `Z/a = τ` 混用、lab-frame 前沿与自相似坐标混用），物理对照判为 WITHHELD；审计因此改用参量无关的 `c`。本节点沿用该已被验证的口径，并在同一配置下**逐位复现**其基线数字（0.58% 差），这就是"溃坝类标准 benchmark 锚"的具体落点。Ritter 偏差 39% 也被诚实记录：WCSPH 自由面前沿在粗网格上系统性偏慢，与该审计"table slope well below Ritter"的结论一致。

### 3.4 能量收支（图 3、判据 FAIL 的完整披露）

| dx (m) | 机械 `KE+PE` 峰漂移 | 总能量 `KE+PE+弹性能` 峰漂移 | 事件窗 (s) |
|---|---|---|---|
| 0.02 | 1.77% | 1.14% | 0.378 |
| **0.0125** | **1.13%** | **1.18%** | **0.367** |
| 0.01 | 1.10% | 1.18% | 0.325 |

声速研究（dx = 0.0125，其余不变）：

| c₀ (m/s) | 总能量峰漂移 | δ_max | 甲板到达 (s) |
|---|---|---|---|
| 20 | 1.18% | 4.7% | 0.367 |
| 25 | 0.93% | 3.5% | 0.352 |
| 30 | 2.37% | 3.6% | 0.329 |

**结论（不粉饰）**：总能量漂移在 1.1–1.2% 处**收敛到平台**，不随网格细化下降，因此在生产分辨率上**未达到 < 1% 的判据**。机制可定位：

1. 时间序列（图 3 左）显示漂移在 t ≤ 0.224 s（首个悬空碎片出现，`fragmentation_time = 0.2235 s`）的**连续介质段**始终落在 ±0.65% 内（净耗散为负），此后转为**正的累积**（0.23 s → 0.46 s 由 +0.1% 涨到 +2.5%），即能量被*注入*而非耗散；
2. 注入源于内核压力律的自由面零点钳制：水面薄化/碎裂时粒子 `ρ < ρ0` 只得到 `p = 0`，膨胀功无从付出，膨胀不付费、压缩照收费的单向性正是净增能量的来源。这与平台已记录的"自由面密度亏损"缺陷同源（`docs/benchmarks/free-surface-treatment.md`、`docs/verification_laplace_pressure_floor.md`）；
3. 针对该缺陷的 `surface_pressure_closure=True`（Adami 2012 自由面压力外插）在本仓内核里**目前会崩溃**：`free_surface_pressure` 用壁面粒子下标去索引只覆盖流体的 `known` 数组，抛 `IndexError`（复现：任何带 `wall` 且 `surface_pressure_closure=True` 的算例）。本节点未修该内核缺陷（属另一条修复波），但如实记录；
4. 声速研究表明漂移并**不单调**随压缩减小（20/25/30 m/s → 1.18%/0.93%/2.37%），说明另有与 dt/分辨率耦合的相位项，**因此不采用 c₀ = 25 去"通过"判据**（那是参数挑选，不是物理）。

关于窗口口径：能量判据在"释放 → 首滴水上甲板"的事件窗上取值（0.367 s），这是本次事件被建模的全部时段；同时给出更严/更宽的三个数（连续介质段 0.65%、纯机械 1.13%、全程 2.56%），不隐藏任何一个。若把窗口收窄到"连续介质段"可以过线，但那会把判据变成选窗口，故**不据此宣称通过**。

## 5. 注意点、局限与适用范围（踩坑记录）

1. **端壁不可省**：只给地板/斜坡时，溃坝背向波与远壁冲击落到 `apply_boundary` 的夹持上，动量与能量被静默吃掉（早期版本能量窗被压到 0.17 s、漂移 5.3%）。端壁 + 全宽地板（封住斜坡趾部楔形）后 `escaped = 0`。
2. **贴面速度累积**：`apply_boundary` 的容差判定会漏掉"恰好贴面"的粒子，法向速度累积到 15 m/s。§2.2 的接触条件修正后消失；这是本模块与内核交互唯一的数值增补，已写入模块文档串。
3. **弹性能必须"钳制 + 只算压缩侧 + 二阶积分"**：三个错误各自会把结论毁掉（636% 的虚假水库；30 倍量级偏差）。
4. **`surface_pressure_closure=True` 目前在内核中 `IndexError`**（壁面下标索引流体数组）。未在本节点修复，但已定位，可作为后续"自由面缺陷修复波"的入口；修复后应重跑本节的能量梯。
5. **前沿量测的固有偏差**：`max x` 是"尖端"定义，SPH 尖端在粗网格上滞后（ν = 0 时 τ≲1 存在 ~0.5τ 的启动延迟），这也是平台审计放弃直接对比实验曲线、改用 `c` 的原因。任何用本模块做"到达时刻"工程量的后续波，都应以 `c`（或体积分数前沿）而非尖端为准。
6. **适用范围**：单相、二维、单位宽度、Mach ≤ 0.15、无量纲时间 ≤ 0.5 s、无表面张力、无冰-水相变、浮冰不解析。**不适用**：真实船艏三维绕流、冰-结构碰撞载荷谱、飞沫粒径分布、结冰/冻结。
7. **降阶模型的诚实边界**：浮冰发射速度只是"已解析水动力冲量"→"弹道"的两步传递，没有反作用力、没有旋转、没有冰块间碰撞；给出的是量级与区间，不是工程量。

## 6. 误差判定（逐项回答"是否 < 3%"）

| 关键量 | 基准 | 实测误差 | <3% ? |
|---|---|---|---|
| 首波前沿系数 `c` | 平台已验证基线 1.2016（同配置） | **0.58%** | ✅ 是 |
| 平底前沿速度 vs Ritter | `2√(g h₀)` 解析 | 39.3%（SPH 偏慢，平台审计同向结论） | ❌ 否（已知系统性偏差，非本模块引入；且 Ritter 对深水溃坝本就高估） |
| 飞溅顶点（26 个越缘粒子，中位） | 弹道解析 `y₀ + v_y²/2g` | **1.94%** | ✅ 是 |
| 飞溅顶点 P90 | 同上 | 9.9% | ❌ 否（少数粒子在空气中与邻居碰撞/支撑截断，物理上与解析弹道不等价） |
| 测力板动量通量 | `ρ u² h` 解析 | < 2%（合成射流用例） | ✅ 是 |
| 总能量漂移 | 0（守恒） | **1.18%**（判据 <1%） | ❌ 否（见 §3.4；连续介质段 0.65%） |
| 质量守恒 | 逐位 | 0（机器精度） | ✅ 是 |
| 甲板上浪量 / 抛距 / 浮冰发射速度 | **无独立基准** | — | 无法判定：本节点只建立"可复算的量测面"，绝对精度需等实验/高保真对照（后续波）。声明原因：无同工况实验数据，且浮冰为降阶模型。 |

## 7. 后续修正：浮冰发射降阶模型的附加质量欠账（本单）

本节由 m6446 追加。§2.5/§3 的浮冰发射估算用的是**干质量** `rho_ice pi r^2` 作除数，
它隐含"水被推开不要代价"，因此是**上界**。真实惯性为
`rho_ice pi r^2 + C_m rho_w pi r^2`，二维圆截面 `C_m = 1`（Lamb §71），
即 `m_eff = 2.09 m_ice`：速度被高估 2.09 倍、抛高被高估 4.37 倍。
修正后的读数见 `docs/verification_ice_floe_added_mass.md`（`floe_launch_estimate`
已同时输出 `launch_speed_m_s`（干质量上界）与 `launch_speed_with_added_mass_m_s`（推荐读数），
DEM 交接面改为交后者，`IceSplashConfig(floe_added_mass_coefficient=0.0)` 可回到旧口径）。
