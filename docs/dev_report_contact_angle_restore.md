## 1. 背景与案例

m2090 合入的接触角边界条件（Young 关系 `σ_sv = σ_sl + σ_lv cos θ`）实现文件被合并门禁滤除，但 `src/tensorsph/__init__.py` 与 `droplet_impact.rhs()` 都保留了对 `apply_contact_angle_boundary` 的引用，导致**整个包无法导入**、24 个测试文件全部 collection error（`rhs` 传 `wall=` 时还会 TypeError）。本单按 `docs/contact_angle_boundary.md` 的规范把算子补回并做解析验证。

## 2. 方法

边界条件作用于色函数梯度：对壁面 2h 内的流体粒子，把 `grad c` 分解为壁法向分量 `n_w`（由最近壁粒子指向流体）与切向分量，保留切向方向 `t̂`，按 Young 关系重建方向并保持模长：

```
g_new = |g| · ( -cos(theta)·n_w + sin(theta)·t̂ )
```

等价于 `g_new = -|g| n_out` 且 `angle(n_out, n_w) = theta`。该式对 `theta` 可逆、对已有倾角为恒等映射、对 `contact_angle=None` 为严格空操作。
CSF 力链 `compute_surface_tension_force(..., wall=)` 在该梯度上继续算法向/曲率/δ_s，未改动物理模型本身。

接触线外推指标 = 壁带内界面粒子上 `Δa·sign(x)` 的平均，`壁带内右半 Δa_x 和` 是原始和。**注意：绝对指标并非 θ 的单调函数**——该帽几何自身的自然接触角约 60°，θ 越接近该值 BC 的改动越小，响应在 θ≈60° 附近过零并反向，因此单看绝对符号会误判。干净的符号判据是湿润-疏水的**差分**：

- θ=30° 减 θ=150°：外推投影 = `+0.026118`，右半带 Δa_x 和 = `+0.251847`，左半带 Δa_x 和 = `-0.194291` → 湿润把接触线向外推、疏水向内收，两侧反对称。

若 BC 的符号写反，上述差分整体反号——而仓库原有的 shape/模长断言无法发现。

## 5. 注意点与局限

1. **只做几何/算子级验证**：壁面为静态粒子层，未做动态接触角、接触线钉扎、滞后；未验证真实毛细时间尺度上的液滴铺展动力学（需时程积分，属重算力，本机 load15 ≥ 100 未启动）。
2. **单相 CSF 模型**：色函数仍是邻居数比启发式，曲率仍为 `div(n)` 的离散近似；`docs/verification_surface_tension_laplace.md` 记录的 3 项Laplace 判据未通过（曲率、切割面力、伪流），本次未改动该模型，只在其上加边界条件。
3. **最近壁粒子法**：壁法向取最近壁粒子方向，平壁精确；曲壁（凹凸壁面）处为 O(h) 近似，需用壁面法向拟合替代。
4. **reach=2h**：与文档一致，但对 c=20 m/s、dx 很小的雾化算例可能偏窄。
