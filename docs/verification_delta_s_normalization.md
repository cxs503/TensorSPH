# 表面 delta 函数与 CSF 力密度的解析核验：`2|∇c|_MLS` → 精确梯度

**仓库**: TensorSPH ｜ **工件**: `benchmarks/delta_s_normalization/` ｜ **测试**: `tests/test_delta_s_normalization.py` ｜ **改动**: `src/tensorsph/csf_consistent.py`, `droplet_impact.py`, `surface_tension.py`

**结论（先给判定）**: 上一轮交接（`docs/verification_surface_tension_curvature.md` §7.1）留下的 `delta_s` 归一欠账已定位并修好——它**不是**「色函数最外层被抹平」这么简单，而是两个独立误差互相抵消：

1. `delta_s = 2|∇c|` 用的是 MLS 一致梯度，而 c 是宽度 2h 的台阶，在最外层单侧模板上截断误差是 O(1)：实测 `Σ_{x>0} δ_s n_x dV / 2R = 0.659–0.683`（**-32%**，三档分辨率系统性同号）；改用**同一离散色函数的解析导数** `δ_s = 2|Σ_j V_j ∇_i W_ij|` 后为 0.960–0.982（-2%…-4%）。
2. 切割力恒等式原先「通过」（0.89–1.01）是**假通过**：`δ_s` 少 32% 与「加速度除以自由面被截断的求和密度（低 15–27%）」放大 35% 恰好抵消。把 CSF 加速度改为除以 `rho0` 后，两个误差各自显形，修正 `δ_s` 才真正把`F_cut/(2σ)` 落到 1.06–1.07（dx ≤ 2 mm）。

**未通过的部分如实保留**：dx = 3 mm（R/h ≈ 5）下曲率拟合模板过短，`κ` +23.6%、`F_cut/(2σ)` 1.202 仍超 15% 门；端到端 Young–Laplace 压差仍是 WITHHELD（见 §5）。

## 1. 案例介绍（物理背景与参数）

半径 `R` 的二维单相静止液滴，六方密排晶格，四周真空，无重力。CSF 力为

$$f = \sigma\,\kappa\,\delta_s\,n,\qquad a = f/\rho$$

`delta_s` 是**表面 delta 函数**，它必须满足 `∫δ_s dn = 1`（等价地，穿过液滴切一刀，
`Σ_{x>0} δ_s n_x dV = ∫_{半圆} n_x ds = 2R`）。因为力幅值正比于 `δ_s`，它与曲率 `κ` 的误差
**相乘**进入动量方程，所以必须单独核对，不能靠切割力恒等式「一起过」。

| 参数 | 值 |
|---|---|
| 液滴半径 R | 0.02 m |
| 表面张力系数 σ | 7.2 N/m（10× 水，压缩毛细时间） |
| 参考密度 ρ0 | 1000.0 kg/m³ |
| 声速 c0 | 20.0 m/s（Mach ≪ 0.1） |
| 状态方程 | Tait，γ = 7.0 |
| 平滑长度 | h = 1.3 dx |
| 分辨率扫描 dx | 1.5 mm, 2.0 mm, 3.0 mm |
| 解析参考 | κ = 1/R = 50.00 1/m；∫δ_s dn = 1.0；F_cut = 2σ = 14.40 N/m；Δp = σ/R = 360.0 Pa |

## 2. 怎么做的（方法/流程）

| 环节 | 上一轮（`2|∇c|_MLS`） | 本轮（可选，默认不变） |
|---|---|---|
| 表面 delta 函数 | `δ_s = 2|grad_mls c|`，单侧模板上梯度被低估 | `δ_s = 2|Σ_j V_j ∇_i W_ij|`（`csf_delta_s="kernel_sum"`）：同一离散色函数 `c_i = Σ_j V_j W_ij` 的**解析导数**，无自由参数 |
| 加速度分母 | `ρ_i`（自由面求和密度，实测 ρ/ρ0 = 0.73–0.73`） | `rho0`（`csf_force_density="reference"`）：界面携带的是流体密度，不是被核截断的求和密度 |
| 法向 / 曲率 | MLS 法向 + `fit_quadratic` 曲率拟合 | **不动**（方向 cos = 1.000，曲率已入 15% 门） |

力的装配与其归一不变：`a = -σ κ δ_s n / ρ`。两个新开关默认取历史值，
所以既有基准/回归数字不变；本轮的推荐组合在验证记录里显式给出。

工具链：`benchmarks/delta_s_normalization/run.py`（instant 诊断 + relax 时间推进 + 出图）、
`tests/test_delta_s_normalization.py`（`kernel_sum_gradient` 对有限差分逐点核验、
配置校验、体内零力不变量、以及提交工件的一致性锁）。

## 4. 注意点（踩过的坑）

1. **两个误差会互相抵消，验收必须逐环节**。`δ_s` 偏低 32% 与 `1/ρ` 偏高 35% 相乘后恰好落在 1.0 附近，单看切割力恒等式会得出「已通过」的错误结论。
2. **`δ_s` 要用「离散色函数的解析导数」，不是「更好的插值梯度」**。MLS 一致梯度对线性场
   精确，但 c 是 2h 台阶，单侧模板上它返 O(1) 误差；核和导数 `Σ_j V_j ∇_i W_ij` 是同一
   离散色函数的真导数，因此 `∫δ_s dn` 自动守恒。
3. **不要用 ghost 色函数补真空**：在真空侧 `x_i + dx n_i` 放 `c = 0` 的虚粒子会把
   `∫δ_s dn` 顶到 1.65–2.26（真值在 1 附近），因为那里的真实平滑指示函数不是 0。
4. **`δ_s` 同时是曲率拟合的界面权重**：修好力幅值会让拟合权重变尖，粗分辨率曲率反而略差；
   两者耦合已写入 §3.3，不能只报有利的那一列。
5. **加速度分母只能改一处**：`csf_force_density` 同时影响压力场与伪流，旧默认保持 `local`，
   历史工件（droplet impact、dam break）因此不受影响。

## 5. 误差判定（逐项，显式回答「是否 < 3%」）

以 dx = 1.5 mm（R/h ≈ 10）为主判据档，dx = 2 mm 同列：
| 关键量 | 基准 | `2|dc/dx|`+ρ0 (dx=1.5 mm) | 误差 | < 3%？ | < 15%？ |
|---|---|---|---|---|---|
| Σδ_s n_x dV/2R | 1 | 0.960 | -4.0% | 否 | 是 |
| F_cut | 2σ | 1.202 | +20.2% | 否 | 是 |
| κ | 1/R | 61.78 1/m | +23.6% | 否 | 是 |
| 力方向中位 cos | 1 | 0.999 | 0.0% | 是 | 是 |
| Δp | σ/R = 360.0 Pa | 见 §3.4 | +119.0% | 否 | 否 |

dx = 2 mm 档：Σδ_s n_x dV/2R -2.8%、F_cut 1.069（+6.9%）、κ +9.7%，三项均 < 15%。

**结论**：力层面的三个解析判据（delta 函数归一、切割力恒等式、曲率）在 dx ≤ 2 mm 全部进 15% 门，
其中 delta 函数归一在 dx ≤ 2 mm 已进 **3%**；端到端 Young–Laplace 压差**未**达标，
原因与上一轮一致且更明确：dx = 4 mm、t = 0.7 t_σ 的 `p_core − p_shell` 读数在四个
解析行为几乎相同的组合之间散布 0.1%…+119%（§3.4），这个量在当前分辨率下不可用作判据，
需要改压强基准（背景压强 / 无散修正 / 降低 c0），不是继续调 δ_s。**未伪造达标。**
