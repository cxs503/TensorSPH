# 验证欠账复核：Young-Laplace 压差判据的定义修正与分辨率地板量化

**仓库**: TensorSPH ｜ **工件**: `benchmarks/laplace_plateau/` ｜ **测试**: `tests/test_laplace_plateau.py` ｜ **证据等级**: **WITHHELD**

**结论（先给判定）**: 表面张力 CSF 模型的**力路径**在 15% 门内（切割力恒等式比值 1.077，径向积分给出的压差上界 343.2 Pa，-4.7%）；但**端到端压差仍 WITHHELD**：平台压差在三档分辨率下都稳定在 199.0 Pa 附近，即 55% 的解析值，误差**47.3% 且不随分辨率收敛**。本轮同时纠正了一个**判据定义错误**：以往把「核心压强 − 液内 0.8–0.95 R 壳层压强」当作 Laplace 压差，而液滴平衡时整个内部处在同一压强平台上，这个差值按定义就接近 0；正确判据是「平台 − 环境（真空 0 Pa）」。

## 1. 案例介绍（物理背景与参数）

半径 `R = 0.02 m` 的二维单相液滴，六方密排晶格初始化，四周真空，无重力。表面张力使液滴内部建立过压 `Delta p = sigma/R`（Young-Laplace，2-D 圆形界面）。

| 参数 | 值 |
|---|---|
| 液滴半径 R | 0.02 m |
| 表面张力系数 sigma | 7.2 N/m（水） |
| 参考密度 rho0 | 1000.0 kg/m^3 |
| 声速 c0 | 20.0 m/s |
| 状态方程 | Tait, gamma = 7.0 |
| 粘度 | 0.01 Pa s |
| 平滑长度 | h = 1.3 dx |
| 分辨率扫描 dx | 0.004, 0.002, 0.0015 m |
| 推进时长 | 2.0 t_sigma |
| 解析参考 | Delta p = sigma/R = 360.0 Pa |

## 2. 怎么做的（方法/流程）

1. **判据定义修正**：Laplace 压差是**跨界面**的跃变，`Delta p = p_plateau(r<0.6R) − p_ambient(r>1.0R)`，环境压强由真空侧粒子给出（应≈0）。旧判据用的是`p_center − p(0.80–0.95R)`，两个量都在同一压强平台上，按构造量不出跃变。
2. **三条独立上界**（全部静态、不依赖时间推进）：①切割力恒等式 `F_cut/(2 sigma)`（全局力幅值）；②径向积分 `sigma * int kappa delta_s dn`（界面动量平衡真正需要的量）；③核和密度偏置导致的虚假压强 `B[(1+bias)^gamma − 1]`。
3. **分辨率阶梯**：dx = 0.004, 0.002, 0.0015 m，均推进到 2.0 t_sigma，取最后 1 t_sigma 的时间平均作为平台压强。
4. **初值敏感性**：把粒子质量按内部核和密度偏置归一（使 t=0 的内部求和密度恰为 rho0），对照「偏置晶格初值」。

工具链：`benchmarks/laplace_plateau/run.py`（静态诊断 + 时间推进 + 出图）、`benchmarks/laplace_plateau/make_doc.py`（本文件，数字全部由 JSON 注入）、`tests/test_laplace_plateau.py`（判据定义、上界与诚实判定回归）。

**读数**：`h = 1.3 dx` 的核和求和密度在均匀晶格上饱和到 1.005884（偏置 0.588%），而 `Delta p = sigma/R` 只要求密度变化 8.976e-04——偏置是信号的 **6.6 倍**，折算成虚假压强 2395 Pa ≈ 6.7 倍 sigma/R。若要求 15% 的压差精度，密度场精度需达到 1.3e-04，比求和密度能给的高一个数量级以上。

**读数**：
1. 环境侧压强 0.00 Pa（真空，符合），平台 199.0 Pa，压差误差 -44.7%。

## 4. 注意点（踩过的坑 / 局限）

1. **判据定义错了整整两轮**：`p_center − p(0.8–0.95R)` 量的是同一平台上的差值，任何正确实现都会给出 ~0，从而把「模型对」误判成「模型错」。本轮把它改成跨界面判据，并把旧数（-88%/-75%）标注为**判据伪影**。
2. **t=0 的压力是最容易踩的坑**：核和密度偏置让初始核心压强就有 2395 Pa，比要测的 360 Pa 还大 6.6 倍；任何「一开始就看压差」的跑法都会先测到瞬态。
3. **平台是时间平均量**：单帧读数在 4–2395 Pa 之间摆动，只看末帧会得到随机结论。
4. **适用范围**：本结论针对 `h = 1.3 dx`、`c0 = 20 m/s`、`gamma = 7` 的 WCSPH 配置。要真正过 15% 门必须改压强路径（如密度求和的自洽归一 / Shepard 归一、或大幅降低 c0 使同一压差对应更大的密度变化），**不是**改表面张力力模型。
5. 旧的 `benchmarks/csf_consistent/validation_report.json` 在 HEAD 不可复现（本单未重跑该工件，仍按历史值引用；本判据下的数见 §3.3）。

## 5. 误差判定（逐项，显式回答「是否 < 3%」）

| 关键量 | 基准 | 实测（dx=0.002） | 误差 | < 3%？ | < 15%？ |
|---|---|---|---|---|---|
| 切割力 F_cut（mls 曲率） | 2 sigma = 14.4 N/m | -15.50 N/m | 7.7% | 否 | 是 |
| 切割力 F_cut（fit_quadratic） | 2 sigma = 14.4 N/m | -12.95 N/m | 10.1% | 否 | 是 |
| 径向压差上界（mls） | 360.0 Pa | 343.2 Pa | -4.7% | 否 | 是 |
| 径向压差上界（fit_quadratic） | 360.0 Pa | 287.9 Pa | -20.0% | 否 | 否 |
| 端到端 Laplace 压差 | 360.0 Pa | 199.0 Pa | -44.7% | 否 | 否 |
| delta_s 归一 int delta_s dn | 1.0 | 0.751 | 24.9% | 否 | 否 |

**诚实结论**：端到端 Laplace 压差**未过** 15% 门，误差 47.3%，且三档分辨率不收敛；力路径（切割力/径向积分）已接近或进入 15% 门，`delta_s` 归一与压强路径仍是欠账。本轮的净增量是**判据定义修正 + 系统性质因量化**，不是「把数调绿」。

## 6. 下一个欠账（交接）

1. `delta_s` 归一 0.74–0.76 → 1.0（见 `docs/verification_surface_tension_curvature.md` §7）；注意**不能**简单按积分标定：本仓库实测把积分标到 1 会让 `F_cut/(2 sigma)` 涨到 1.20，即积分归一与力恒等式不是同一个约束。
2. 压强路径：把求和密度改成自洽归一（Shepard/MLS 归一核和），先在静水基准上复核，再回到本判据；只有它能把 6.6 倍的偏置降到 9e-4 以下。
3. 更长的物理时间（≥ 5 t_sigma）与更高分辨率（dx ≤ 1 mm）复核平台漂移。
