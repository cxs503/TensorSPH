# 接触角（Young 方程）壁面牵引：审计仪器与三个模型的判决

锚点 `XVAL-SPH-PROJECTION-SPH-YOUNG-LAPLACE`（Young 半边）。工件：`benchmarks/contact_angle/adhesion/`、`src/tensorsph/contact_angle_isph.py`；测试：`tests/test_contact_angle_adhesion_m22237.py`（12 项全绿）。本页数字全部由 `make_adhesion_doc.py` 从 JSON 注入。

## ① 案例：为什么还要碰接触角

`docs/verification_contact_angle_bc.md` 已把出厂接触角 BC 关账为物理 FAIL：在有效性门全过的一档（`R/dx = 13.3`，穿壁 `0.00 dx`，伪流 `0.03`），设定 60/90/120° 松弛到 151.4/152.6/154.1°，响应斜率 `-0.025`。该文档给的机理是**力幅**问题：`apply_contact_angle_boundary` 只旋转近壁 CSF 力的方向、保持 `|grad c|`，因此从不施加单位接触线长度的牵引——而 Young 方程 `γ_sv − γ_sl = σ cos θ` 恰恰是一个单位长度牵引。本单把这条机理当成可判定的假设，做了两件事：(i) 造一台能直接测「候选 BC 的壁面牵引」的审计仪器；(ii) 按 Young 牵引实现壁面黏附力并送进生产求解器复核。

## ② 怎么做的

1. **审计仪器**（`traction_audit`）：在解析接触线补丁上（半径 `R_c = 40 dx` 的液冠、圆心 `C = (0, R_c cos θ)`，故接触角按构造成立）放一维格点液体 + 三层壁粒子；法向 `n = (r − C)/|r − C|` 与面 delta `δ_s = |∇c|` 都是解析场，因此该仪器只测**力装配**，不含任何色函数/曲率算子的误差。被判据的量是壁切向合力 `T = Σ_i f_i·t·dx`（2-D 单接触线即单位长度值）。
   补丁的 `∫ δ_s dn = {"0.003": 0.4734414403939793, "0.0015": 0.4734414403939793}` 之外还需记的常数：`δ_s` 剖面（0.75 dx 宽）给出 `∫|∇c| dn = 1.970`——与仓库 legacy CSF delta（`2|∇c|`）同一约定，牵引标定 `C` 与之绑定，故一并公布。
2. **壁面 delta 与权重**：`δ_w,i = Σ_k∈wall W(|r_ik|,h) A_k/(1/2)`（半平面核积分 `1/2` 由各向同性精确给出），平壁参考值 `δ_w^ref = 0.4734`（测得，非假设），权重 `w = clip(δ_w/δ_w^ref, 0, 1)`；黏附力只作用在**近壁界面粒子**上（`δ_s` 提供单位长度归一，故牵引与分辨率无关）。
3. **两个力幅模型**：`young` = `C σ cos θ · ŝ · δ_s w`（`ŝ` = 外法向的壁切向分量，指向远离液体一侧）；`brackbill` = `C σ (n_wall − cos θ n) δ_s w`（同文献的力幅形式，作对照）。`C` 由解析审计一次性标定，**不在它随后要预测的松弛里调**。
4. **生产求解器复核**：同一 `droplet_impact.rhs`、同一量具 `run.py::measure_contact_angle`（仪器层误差 1e-5°）、同一有效性门（穿壁 < 0.5 dx、伪流 < 0.1 `√(σ/ρR)`）。三臂 `rotate`(出厂)/`young`/`brackbill`。

## ③ 计算结果

### 3.1 牵引审计（解析几何，逐角度）

| 模型 | θ_set [deg] | `T` 实测 [N/m] | `σ cos θ` | `T/(σ cos θ)` | 是否在 [0.85, 1.20] |
|---|---|---|---|---|---|
| `young` | 30 | +0.9273 | +0.8660 | +1.0708 | 是 |
| `young` | 60 | +0.5023 | +0.5000 | +1.0046 | 是 |
| `young` | 90 | +0.0000 | +0.0000 | +1.0404 | 是 |
| `young` | 120 | -0.5242 | -0.5000 | +1.0484 | 是 |
| `brackbill` | 30 | -0.4847 | +0.8660 | -0.5597 | **否** |
| `brackbill` | 60 | -0.4385 | +0.5000 | -0.8770 | **否** |
| `brackbill` | 90 | -0.0000 | +0.0000 | -1.0403 | **否** |
| `brackbill` | 120 | +0.4498 | -0.5000 | -0.8995 | **否** |

* `young` 臂：四档角度上 `T/(σcosθ)` = +1.0708 / +1.0046 / +1.0404 / +1.0484，标定均值 `C = 0.9611`，角度间散布 `6.40%`（门 20 %）——**一个 O(1) 振幅就够，说明离散牵引确实跟随 `σ cos θ`**，且 90° 处精确为零、湿/非湿两侧变号。
* `brackbill` 对照臂：`T/(σcosθ)` = -0.5597 / -0.8770 / -1.0403 / -0.8995，散布 `50%`——其切向合成为 `−σ cos θ sin θ`（45° 最大、两端为零、且湿壁侧指向液内），**单一振幅无法拟合，也不可能在两端极限给出正确的润湿/去湿方向**。这是把「文献力幅形式」与「Young 牵引」分开的定量证据。

### 3.2 出厂 BC 为什么失败（可测量化）

同一液滴、同一 `R/dx = 6.7` 构型上直接测三臂注入的流向（沿壁）动量：

| 臂 | 流向动量 `Σ m a_x` [N·s] | 说明 |
|---|---|---|
| `rotate`（出厂） | 0.4871 | 只有离散不对称，**没有牵引** |
| `young`（黏附牵引） | 0.1552 | 牵引本身的方向正确、量级 `σ cos θ` |

> 关键事实：**牵引比既有的离散不对称还小 3 倍**（0.155 vs 0.487 N·s）。这就是松弛里接触线不动的直接原因——不是符号错，是被伪流淹没。两项数字由 `tests/test_contact_angle_adhesion_m22237.py::test_rotate_arm_applies_no_wall_traction` 断言。

### 3.3 松弛复核（生产求解器）

**NOT_RUN**：预注册的松弛阶梯（`rotate`/`young`/`brackbill` × `dx ∈ {3.0, 1.5} mm` × `θ ∈ {30, 60, 90, 120}°`，`t_end = 4 t_σ`）已递交集群（`cj3976` coarse、`cj3977` fine），收单时仍在排队（队列深度 20+、在飞 47 作业），**本页不把未跑的判据写成通过**。

已在本机跑过的三条探针（单档、`< 120 s`，仅供方向判断，不入门）：

| 臂 | dx [m] | θ_set | t_end | θ_meas(tail) | 结论 |
|---|---|---|---|---|---|
| `rotate` | 0.003 | 60° / 120° | 1.5 t_σ | 152.0 / 166.1 | 复现 FAIL |
| `young` | 0.003 | 60° / 120° | 1.5 t_σ | 155.4 / 155.6 | 仍贴壁 |
| `young` | 0.003 | 60° | 4.0 t_σ | 167.3（伪流 0.150 > 门） | 仍贴壁且不可采信 |

方向判断（**假设，非结论**）：在 `R/dx ≤ 13.3` 上，`σ cos θ` 量级的壁牵引（实测 0.155 N·s）小于离散曲率力不平衡造成的伪流（0.487 N·s），因此单纯「补上牵引」不足以交付接触角；要吗把 `R/dx` 推到 20–40，要吗改用**几何**方式把角度写进色函数边界（wall colour BC），而不是靠力去赢过噪声。这是下一张单的入口。

## ⑤ 注意点与局限

1. **审计仪器只测力装配**。解析法向/解析 `δ_s` 把色函数与曲率算子全部旁路，所以它证明的是「牵引律对不对」，**不证明**「这套力能在 SPH 里把界面弯到设定角」——后者是 3.3 的松弛，本单没跑完。
2. **`C` 与 `δ_s` 约定绑定**。审计补丁的 `∫|∇c| dn = 1.97`（legacy `2|∇c|` 约定），标定 `C = 0.9611` 只在这个约定下有意义；换 delta 归一化必须重标，不能沿用。
3. **`young` 模型的力作用在近壁一层界面粒子上**（`δ_w` 在 `1.5 dx` 内衰减到 0），这是壁面牵引的物理位置，但也意味着它对接触线处的局部噪声最敏感。
4. **`brackbill` 臂的结论限于本实现的符号约定与 `n` 取外法向**；文献里的同类公式常配不同的 `n`/镜面化定义，本页只声明「这一形式在本实现下不满足 Young 牵引」，不宣称文献有误。
5. **2-D、零重力、单一核（cubic spline, h = 1.3 dx）**；3-D 与不同 `h/dx` 未测。

## ⑥ 误差判定（逐项回答是否 < 3 %）

| 关键量 | 基准 | 实测 | 误差 | < 3 % ? |
|---|---|---|---|---|
| 牵引 `T`（θ = 30°） | `σ cos θ` = +0.8660 | +0.9273 | +7.08% | 否 |
| 牵引 `T`（θ = 60°） | `σ cos θ` = +0.5000 | +0.5023 | +0.46% | 是 |
| 牵引 `T`（θ = 90°） | `σ cos θ` = +0.0000 | +0.0000 | +4.04% | 否 |
| 牵引 `T`（θ = 120°） | `σ cos θ` = -0.5000 | -0.5242 | +4.84% | 否 |
| 牵引标定 `C` 的角度散布 | 0（理想） | 6.40% | 6.40% | 否 |
| 松弛接触角 | 设定角 | 见 3.3 | **NOT_RUN**（队列未回） | **未判定** |

**结论**：`young` 壁牵引的**力律**对标解析 Young 方程为 +1.0708 / +1.0046 / +1.0404 / +1.0484（60° 一档 +0.46 %，四档最大 +7.08 %，均 < 15 %；60° 一档 < 3 %，30°/90°/120° 三档 > 3 % 但 < 8 %）；**松弛接触角一个数都没有判定**，按纪律记 NOT_RUN，不当通过。
