# m22388 — 可压 SPH 第二个基准族（强激波/接触间断）+ 可表示性闸门

**锚点**: `XVAL-SPH-METHOD-SELECTION-2026-11-12`（`feature_ledger` status=in_progress）
**前序**: m21797 的「留给下次」明确点名：`compressible_riemann` 等格式的上界**只来自单一基准族**，
建议补 Toro 3/4 的压力平台/接触间断直到把 9/10 降到 5/10。

## 做了什么

1. **先证伪了"直接补 Toro test 4"这条路线**（前置分析，非猜测）：本 1-D 族是
   *拉格朗日 + 反射壁 + 固定粒子质量* 的盒子。Toro test 4 外态 u_L=+19.60、u_R=−6.20，
   精确解靠**边界入流**维持外态；固定质量盒装不下。`reflective_box_budget` 算出边界净入流
   5.41 vs 盒内质量 6.00（90%）；强行跑得到 L1(ρ)=39%、星区压力 461→（测得平台 p 仅 ~1/3.7 精确值），
   且 400/800/1600 三档都不收敛 —— 这是**边界条件伪影**，不是格式误差。故 Toro 2–5 一律不入账。
2. **新增可表示性闸门** `riemann_topology.reflective_box_budget`：仅由精确解判定
   (a) 波是否在 t 前触壁、(b) 边界净质量流是否可忽略；不可表示即拒绝判级（机器判定，非文字约定）。
3. **新增第二基准族** `CASE-SPH-STRONG-SHOCK-CONTACT`：静止外态、压力比 1000:1、
   10.3× 接触密度跳变、激波 Mach≈4.6（Sod 是 10:1/3.4×/1.3 Mach —— 不同regime，不是重跑）。
4. **新增拓扑感知精确数据与判级** `riemann_topology`（`WaveSide`/`WaveTopology`/`plateau_windows`/
   `grade_riemann`）：每侧按 p* 与 p_k 判定 shock/rarefaction，冲击支用 Rankine-Hugoniot 星态与激波速度。
   意义：`sod.exact_star_state` 对 p*>p_L 的数据**静默给错**（无条件用等熵膨胀式；且把左波报成
   rarefaction 头速 u_L−c_L，而该侧其实是 +0.79 m/s 的右行激波）。判级若走老助手，第二族会被污染。

## 注意点 / 局限（不许含糊）

- **不门控风扇内部**：x(u*/2) 偏置 +3.0%（N=800）且**不收敛**（2.47→3.05→3.44% for N=400/800/1600），
  因 SPH 风扇收敛到 S 形速度剖面（x=−0.5 处 11.23/11.52/11.67/11.74 vs 精确 10.35）。列为诊断量。
- 风扇尾部 kink 位置不可解析（−32.9%，不收敛），同样只作诊断。
- **接触区伪压力尖峰 = 2.11 p***（星区包络内），诊断记录、不门控。
- 外态流动的黎曼数据（Toro 2–5）在本族**不可表示**；要覆盖它们需入流/出流鬼粒子 BC（未做）。
- 入流 BC 的**一次原型尝试**（用固定外态鬼粒子格点替代镜像壁）在 Toro 4 上失败：星区速度 17.2 vs 精确 8.69、
  密度峰值 142，故未入库——记录为负面结果，避免下次重复。
