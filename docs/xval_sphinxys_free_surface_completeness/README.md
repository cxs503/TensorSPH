## 1. What was open

The two-phase reading of the ported model passes the ledger gate
(`docs/xval_sphinxys_mixture_laplace/README.md`: −4.7 / −5.8 / −6.2 % at R/Δx = 16/32/64).
The **free-surface (single-phase) reduction** did not: the stress-flux sum runs over the
present half-support only, and the Laplace reading was short by ≈ 30 % at every resolution
(−29.74 / −30.01 / −29.88 %, `benchmarks/surface_tension/out_single_phase_completion/gate.json`).

The previous round closed that gap with a **fitted coefficient**: the specular mirror of the
present neighbours (`completion="mirror"`) has to be multiplied by `alpha* = 0.4263`, fitted at
R/Δx = 32 and then applied to the other rungs. Fitted values at +40 % full weight and a
calibrated 0.43 in between are a calibration, not a derivation: they say *the closure is
needed* but not *how much of it*.

## 2. What was done

**The missing amount is measurable per particle.** The first-moment (completeness) condition
of the kernel is

    M_i = sum_j V_j (x_j - x_i) (x) grad_i W_ij ,      s_i = trace(M_i)/2

`s_i` is a *measured* statement about how much of the kernel a particle actually sees: `s = 1`
for a complete support, `s = 1/2` for an exact half-space (the half-ball integral is exactly
`I/2` in any dimension), and it interpolates smoothly with the inward distance from the
interface. Hence the parameter-free closure

    grad_ij  ->  c_ij grad_ij ,   c_ij = 1 / [(s_i + s_j)/2] ,   c = 1/SUPPORT_FRACTION_FLOOR
                                                                     (0.25) as a floor

**Why per pair and not per particle.** Scaling the `i` end by `1/s_i` and the `j` end by
`1/s_j` breaks the antisymmetry of the symmetric flux: neighbouring particles differ by ~30 %
in `s` near the interface, so the pair contributions no longer cancel and the force explodes
(measured: `dp ~ 1e4 Pa`, i.e. 5 orders of magnitude wrong). With **one factor per pair** both
ends are scaled identically, the pair contributions stay equal and opposite, and momentum
conservation is preserved to round-off (`~1e-17`).

**Measured support (R/Δx = 32, Wendland C2, h/dx = 1.3):** `s = 0.745` in the interface band
(δ > 5 % of max), rising to `s = 0.973` in the bulk. The bulk deficit is lattice quadrature
(the upstream `h/dp = 1.3` gives only ~20 neighbours in 2-D), not truncation; the same
renormalisation removes it, which is the textbook Bonet–Lok/Randles–Libersky behaviour.

**Scope of the closure.** It belongs to the *vacuum-reduced* (free-surface) path. In two-phase
mode the second phase supplies the far side of the kernel through the contact flux, so the
closure must not be applied there; `mode="single_phase"` is the switch that carries it.

## 3. Results

Laplace reading `Δp = sum rho (-a.n) dx^2 / (2 pi R)`, exact reference `sigma/R = 0.7200 Pa`.

| R/Δx | one-sided (shipped) | mirror, α = 1 | mirror, fitted α\* = 0.4263 | **completeness (this work)** |
|---|---|---|---|---|
| 16 | −29.74 % | +41.74 % | +0.73 % | **+4.05 %** |
| 32 | −30.01 % | +40.38 % | +0.00 % (fit rung) | **+3.17 %** |
| 64 | −29.88 % | +39.78 % | −0.18 % | **+3.15 %** |

* closure gain over the shipped one-sided sum: **7.4×** (worst rung 30.0 % → 4.05 %);
* momentum residual with the closure: `≤ 4.4e-17` (exactly conserved, same as the open path);
* **cross-parameter sweep** (R/Δx = 32, nothing re-tuned): Wendland h/dx 1.3/1.5/2.0 →
  +3.17 / +6.41 / +7.59 %; cubic spline h/dx 1.3/1.5/2.0 → +7.40 / +7.73 / +7.89 %.
  Worst case **+7.9 %**, i.e. inside the 15 % gate for every kernel and support width tried;
* the closure adds **zero free parameters**: the only constant in the code is the numerical
  floor `SUPPORT_FRACTION_FLOOR = 0.25`, which is never active in a resolved body.

## 4. Honest answer to "is it < 3 %?"

**No.** The gated ladder is +4.05 / +3.17 / +3.15 % — inside the 15 % ledger criterion at every
rung and 7.4× better than the shipped free-surface path, but **not inside 3 %**. The residual is
a small systematic *over*-restoration (~3 %): the isotropic support fraction `trace(M)/2`
assumes the missing solid angle is a half-space, whereas the δ-band particles sit at graded
depths (0.5 ≤ s ≤ 0.97), and the true anisotropic inverse does not help — the 2×2 inverse
`[(M_i+M_j)/2]^{-1}` was measured on the same ladder and gives −7.7 / −8.8 / −9.0 %, i.e. it
*under*-restores. The fitted α\* reaches 0 % at the fit rung and is not a defence: it is one
number tuned on the answer, and its physical justification (`"1 - f_in"` of the delta mass) was
already falsified in the same JSON (`delta_mass.air_over_water = 0.001`).

## 5. Pitfalls and limits

1. **Per-particle vs per-pair factor.** Per-particle inverse completeness is not a small
   perturbation of a momentum-conserving flux; it destroys the pair cancellation and produces
   `dp ~ 1e4 Pa`. Do not "improve" the closure that way.
2. **The bulk factor is not 1.** With `h/dx = 1.3` the lattice gauge is `s ≈ 0.973`; a closure
   that only corrects `s < 0.9` leaves a 3 % bias in the interface band.
3. **Do not apply the closure in two-phase mode** — the contact flux already supplies the far
   side; doing so would double-count: the water-side flux alone is already −30 % of the
   full-support value, so scaling it by ≈1.5 on top of the air-side contribution would put the
   reading far outside the gate (not measured in this round; the closure is therefore wired to
   the single-phase path only).
4. **The hourglass penalty stays off** in the free-surface configuration: it is unstable there
   (documented in `docs/xval_sphinxys_mixture_laplace`, −375 %/+215 % at 32/64).
5. Scope unchanged from the port: 2-D, static, inviscid, no gravity, no wall contact, no dynamic
   multiphase Riemann coupling.
