# 3-D 静水逐层压力：欧拉分箱伪影的诊断与拉格朗日行估计器（m16720）

**范围**: TensorSPH ｜ **性质**: 验证欠账（对已合并能力 / 已登记 FAIL 的独立复核） ｜
**改动**: `src/tensorsph/threed/solver.py`（新增晶格行标签 + 拉格朗日行剖面 + 分箱诊断）、
`benchmarks/threed_hydrostatic/run.py`（payload 增列 + 一条并列门）、
`benchmarks/threed_hydrostatic/cases/*.json` / `report.json` / `figures/threed_hydrostatic.png`（用 HEAD+本改动重跑 7 例、

## 1. 案例介绍（问题是什么）

3-D 静水池：`nx=ny=8, nz∈{12,16,24}`，`dx=0.01 m`，柱高 `H=nz·dx`，四侧+底面各 2 层静止壁面粒子（同一晶格），
自由面在上方。解析基准 `p(z)=ρ0 g (H−z)`，ρ0=1000 kg/m³，g=9.81 m/s²，Tait 状态方程 γ=7，
壁面模型 `adami`（能力门）/`tait`（对照组），声速扫描 c0 = 5/10/20/40 m/s（c0=40 才落在 `c0 ≥ 10√(gH)` 包络内）。

本单要复核的是**验证账本里的一条 FAIL**：
`threed_hydrostatic.profile.max_rel_error_core.adami_best = +43.17 %`（内区逐层最差相对误差），
以及 m14908 留下的未解释项「odd-even 模态不随 nz 收敛」。
这两个数字都是**同一个估计器**产生的，而估计器的输入几何存在一个未声明的冲突：

* 流体粒子由 `cubic_lattice(..., origin=(walls,walls,walls))` 生成，其 z 恰为 `z = walls + k·dx`，
  即**正好落在欧拉分箱的边界上**（分箱为 `floor((z−walls)/dx)`）；
* 解析值却在**箱中心** `walls + (i+½)dx` 取值。

也就是标签比质量所在的位置偏半格，且浮点使若干行掉进下一格。伪影量级 ≈ `(Δz)/depth`，
在自由面附近被 `1/depth` 放大——这正好解释「误差在近自由面最大、且不随 nz 收敛」的观测。

## 2. 怎么做的

1. **不改动力学**，只改**测量**：在 `run_hydrostatic` 里用初始 z 的唯一值给每个流体粒子一个晶格行标签
   （`row_index`），`build_pressure_profile` 因此可以同时产出两套剖面：
   * `rows`（欧拉箱，保留，账本与历史工件引用的就是它）；
   * `rows_by_lattice`（拉格朗日行：按行取时间平均，与解析值在**该行自己的实测深度**比较）。
2. **把伪影量化成可复算的量**（`pressure.binning`）：`mean_offset_over_dx`（质量相对箱中心的平均偏移）、
   `rms_offset_over_dx`、`misplaced_fraction`（落入非自己行的粒子样本占比）。
3. **用合成场做判据**（`tests/test_threed_profile_binning.py`）：喂一个**精确等于** `ρ0 g (H−z)` 的场，
   合格估计器必须回报 0 误差。结果：欧拉估计器在精确场上回报 `max_rel_error_core = 9.09 %`（近自由面 33 %），
   拉格朗日估计器回报 `0`（<1e-12）。这是「伪影属于测量而非 SPH 场」的判定性证据。
4. 重跑 7 个算例（全算例同一时间窗），`--merge --figure` 重生成工件与图。

## 5. 注意点 / 局限（必须与上面一起读）

1. **odd-even 模态不是纯伪影**：拉格朗日口径下相邻行仍然交替（`adami-c0_40-nz16` 交替幅度 0.096·ρ0 g H，
   `c0_10-nz12` 0.143），所以「晶格压力棋盘模态」是**真实存在**的次格尺度模态，本单只把它的量级
   从「欧拉箱混合 + 半格偏移」里分离出来，**没有消除它**（消除需要密度扩散项或改变梯度算子，属后续单）。
2. **协议窗口偏差（诚实申报）**：本次重跑用的是 `run.py` 的默认 `T_END = 0.60 s`，而 m14908 的工件用的是
   `--t-end 0.30`。门内算例结论不变（`c0=40` 底部误差 −1.21 % 对旧工件 −1.81 %；拉格朗日均值 −1.83 %），
   但**探针/对照组在更长窗口里进一步崩塌**（`adami-c0_5-nz16` 底部 −95 %、`tait-c0_10-nz16` −100 %、
   `adami-c0_10-nz24` −33.6 %，旧工件同算例为 −8.74 / −25.2 / −5.28 %）。因此**不得**把这几个探针数字与
   账本旧条目逐字对比；恢复 0.30 窗口做同口径对照是明确的后续项（见 §6）。
3. 分箱诊断表里 `tait` 算例的 `mean_offset_over_dx = −15.95`：那一列已经塌了，偏移量本身失去意义，
   只作为「该算例异常」的指示器。
4. 欧拉口径的 `odd_even_amplitude_over_scale` **压低**了真实模态（0.024 vs 拉格朗日 0.096），
   因为箱混合把相邻行平均掉了。账本若继续引用欧拉口径的 odd-even，会低估模态。

## 6. 误差判定（逐项，是否 < 3 %）

| 关键量 | 基准 | 实测 | 误差 | < 3 % |
|---|---|---|---|---|
| 底部压力（门内最好，`adami-c0_40-nz16`） | 1520.55 Pa | 1502.11 Pa | -1.21 % | **是** |
| 内区逐层最差（拉格朗日，同一算例） | 0 % | +11.6 % | — | 否 |
| 内区逐层均值（拉格朗日，同一算例） | 0 % | -1.83 % | — | **是** |
| 精确合成场的欧拉估计器误差 | 0 % | 9.09 % | — | 否（这就是被诊断的伪影） |

结论：**载荷类标量可以做到 3 % 以内；逐层剖面做不到**，但原报的 +43 % 主要来自分箱，不是 SPH 场。
