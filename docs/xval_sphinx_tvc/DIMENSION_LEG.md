# Dimension leg -- the TVC operator in 1, 2 and 3 dimensions

Anchor: `XVAL-SPH-TRANSPORT-VELOCITY-CORRECTION`.  Generated by
`benchmarks/xval_sphinx_tvc/dimension_leg.py` from
`docs/xval_sphinx_tvc/data/dimension_leg.json`; every number below is read
out of that payload (none is hand-copied).

## 1. The defect this leg found

Every earlier leg graded the port in two dimensions, and the operator had no
dimension at all: `kernel_gradient_integral()` evaluated every `grad W` with the
2-D cubic-spline normalisation `sigma_2 = 10/(7 pi h^2)` whatever the shape of the
point cloud. Upstream is dimension generic -- `base_kernel.cpp` builds
`factor_W_1D_` from the compile-time `Dimensions` of the body, and
`transport_velocity_correction.hpp::update()` multiplies by `h_ref^2` in every
dimension -- so a 3-D body (e.g. `tensorsph.dam_break_3d`, the ship-hydrodynamics
case) was scaled by `sigma_2/sigma_3 = 10 h / 7` without a diagnostic:

| `dx` [m] | `h = 1.3 dx` [m] | pre-fix / correct shift | under-correction |
|---|---|---|---|
| 0.05 | 0.065 | 0.0929 | 10.77x |
| 0.026 | 0.0338 | 0.0483 | 20.71x |
| 0.02 | 0.026 | 0.0371 | 26.92x |
| 0.01 | 0.013 | 0.0186 | 53.85x |

Fixed by `cubic_spline_gradient_dim()` + a `dim=` argument on both entry points
(default: inferred from `positions.shape[1]`; a contradictory `dim` is an error).
`dim = 2` still delegates to `tensorsph.droplet_impact.cubic_spline_gradient`, so the
2-D path of every earlier leg is bit-identical (`tests/test_tvc_dimension_leg.py`).

## 2. Anchor: the free-surface shift against the continuum limit

`g_i = -sum_j (C_i + C_j) V_j grad_i W_ij`, `dr_i = alpha h^2 g_i`; with `C = 1` the
gradient theorem gives `g -> +2 I_d(h,0) n`, so `|dr|/h = 2 alpha h I_d(h,0)`.  `I_d` is
evaluated by quadrature over the explicit profile, whose normalisation is re-checked:
`int W_d dV = 1.000000000000 / 0.999999999976 / 1.000000000000` (d = 1 / 2 / 3).

| d | `I_d(h,0)` at h=0.13 | continuum `|dr|/h/alpha` | measured (dx=0.1, h/dx=1.3) | bias |
|---|---|---|---|---|
| 1 | 5.12821 | 1.33333 | 1.16523 | -12.61 % |
| 2 | 5.24687 | 1.36419 | 1.17115 | -14.15 % |
| 3 | 5.38462 | 1.40000 | 1.17478 | -16.09 % |

Reading:

* the 2-D number, -14.15 %, reproduces `SURFACE_ANCHOR.md`'s
  `14.15 %` -- this leg re-measures the same bias on an independent (smaller) lattice,
  so the earlier leg is confirmed rather than re-quoted;
* **the <15 % gate does not transfer to 3-D**: the cubic lattice sits at
  -16.09 % and fcc at -15.02 %,
  i.e. both 3-D arrangements miss the gate (by 1.1 and 0.02 pp) while the 2-D one
  passes with 0.85 pp of margin; a denser packing is 1.07 pp closer, so the bias is
  arrangement dominated and any quotation of the gate has to carry the arrangement
  family *and* the dimension;
* the shift per unit `alpha` is dimensionally transferable at the continuum level
  (1.3642 -> 1.4000,
  +2.63 %):
  `alpha h_ref^2` is *not* re-scaled by the dimension upstream, and the `1/h` behaviour
  of `|g|` makes `|dr|/h` a pure number in every dimension.

## 3. Resolution ladder: `|dr|/h` is resolution independent in every dimension

| d | dx = 0.2 | dx = 0.1 | dx = 0.05 | spread |
|---|---|---|---|---|
| 1 | 1.165225307 | 1.165225307 | 1.165225307 | 0.00e+00 |
| 2 | 1.171147860 | 1.171147860 | 1.171147860 | 0.00e+00 |
| 3 | 1.174784908 | 1.174784908 | 1.174784908 | 0.00e+00 |

The lattices are self-similar, so the rows are identical to round-off: this is the
dimension-generic form of the statement `SURFACE_ANCHOR.md` derived for `d = 2`
(`|dr|/h` is a pure number, hence `|dr|/dx` grows linearly with refinement -- the
mechanism behind the fixed-`alpha` degradation of `RESOLUTION_LADDER.md`).

## 4. Fixed point, wall branch, and one non-extruded 3-D arrangement

| check | d = 1 | d = 2 | d = 3 |
|---|---|---|---|
| `max |g| h`, bulk (full support) | 1.85e-15 | 2.44e-15 | 3.19e-15 |
| `max |g| h`, wall, `wall_factor = 2` | 3.46e-16 | 8.05e-16 | 1.79e-15 |
| `max |g| h`, wall, `wall_factor = 1` | 0.5826 | 0.5856 | 0.5874 |
| fcc `|dr|/h/alpha` (dx=0.1) | - | - | 1.18970 (-15.02 %) |

The bulk lattice is an exact fixed point in all three dimensions (round-off), the
mirror-ghost wall branch vanishes to round-off *iff* `wall_factor = 2`, and the fraction
retained when it is 1 is dimension independent to 0.82 %
(0.5826 / 0.5856 / 0.5874) -- as expected from `|g| ~ 1/h` in every dimension.

## 5. What this does not claim

* No solver-level 3-D run is graded here: `tensorsph.dam_break_3d` does not run TVC
  (the operator/`benchmarks` level is what this leg covers), so the 3-D front-position
  benchmark is still the open item for a 3-D acceptance number;

* the 3-D `+/-15 %` verdict is arrangement dependent (see section 2) and is reported as
  such, not as a pass;

* a numeric diff against a live SPHinXsys build remains open (needs Boost/TBB, absent
  from this image) -- unchanged from `README.md`.
