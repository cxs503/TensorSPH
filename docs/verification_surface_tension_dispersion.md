本轮**不是**重跑上一轮：m5626/m13812 已经证明"直接时间积分"路线不可用（开路自由面伪加速度
23× ω²A，见 `docs/verification_capillary_wave_open_surface.md`）。本轮换了测量口径——
**离散算子的线性响应色散分析**（下称"模态法"），把"力模型"从"时间积分器"里剥离出来单独评分，
并由此定位到一个此前未被量化的**结构性缺陷**：表面 delta 函数的测度是**几何相关**的。

---

## ① 案例介绍（物理背景 / 几何 / 参数）

两个有闭式表面张力刚度的自由面本征模态被用作基准：

**毛细波**（深水、无粘、二维）：界面 `η(x) = −a cos(kx)`，色散关系
`ω² = σk³/ρ`（Lamb 1932, Art. 267）。

**振荡液滴**（二维柱截面）：`r(θ) = R(1 + ε cos nθ)`，Rayleigh–Lamb 频率
`ω² = n(n²−1)σ/(ρR³)`（Rayleigh 1879；Lamb Art. 275）。

两者在线性区都归结为**同一个可观测量**：表面张力的**法向应力**。对毛细波
`Δp(x) = σκ = σk²a cos kx`；对液滴 `Δp(θ) = σ(n²−1)ε cos nθ / R`。惯性项是精确的
势流值（波 `ρ/k` 每单位面积，液滴 `ρR/n`），因此

```
ω_meas² / ω_theory² = Δp_mode / Δp_mode,theory .
```

**这就是本轮的测量口径**：模态法测的是 CSF **力算子**的离散色散关系，"频率"由模态法向应力
反解，不含时间积分器的耗散/伪流。报告里所有 ω 都由该式给出，**不是**轨迹拟合值——这一点必须
明说，否则 43 % 的误差会被误读成"跑崩了"。

| 参数 | 值 | 说明 |
|---|---|---|
| σ | 0.072 N/m | 水/空气 20 ℃ |
| ρ0 | 1000 kg/m³ | 均匀密度（隔离自由面密度亏损） |
| h/dx | 1.3 | 三次样条核，支撑 2h |
| 波幅 | a/λ = 0.02 | `ak = 0.126`，线性区 |
| 液滴扰动 | ε = 0.10 | 有限幅修正 1.6 %（见 ⑤） |
| 曲率算子 | `fit_quadratic`（4h 界面拟合） | 仓库现行最优算子 |
| 晶格 | 六角密排 | 亚晶格平移 2×2 系综平均 |
| 分辨率 | 波 ppw = 24/32；液滴 R/dx = 16/32 | |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **几何构造**：`wave_geometry` / `drop_geometry` 用六角密排晶格按解析界面裁剪，
   粒子体积 `V = dx²√3/2`、质量 `ρ0V`；界面外法向取**解析几何法向**（不用模型法向，
   否则测的是"模型的自洽性"而不是"模型 vs 真值"）。
2. **模态法估计量**：`Δp` 由 CSF 体积力的法向分量沿法向积分得到，
   `Σ_i (ρ a_i·n_i) V_i` 就是跨界面压力跳的离散形式；再对模态投影：
   波 `Δp_k = (2/L) Σ_i ρ a_i·n_i V_i cos(kx_i)`，液滴 `Δp_n = (1/(πR)) Σ_i ρ a_i·n_i V_i cos(nθ_i)`。
   两个归一化都用合成应力场做过单元测试（`A cos(kx)` 回收到 1e-6）。
3. **亚晶格平移系综**：界面相对晶格的相位是任意的，CSF 场不是相位不变量（阶梯噪声），
   物理成分是。对 `shifts × shifts` 个子格平移取平均，并报系综标准差（单次实现的噪声）。
4. **精确参考**：毛细波的参考不是线性 `σak²`，而是**同一界面形状的精确几何曲率**
   `−η''(1+η'²)^{−3/2}` 的模态系数（含弧长因子），因此有限幅不影响比对
   （`exact_wave_stress_coeff`，小幅极限退化为 `σak²`，测试钉住 1e-3）。
5. **两种 delta 函数归一化对比**：
   * `legacy`（现行，逐位保留）：`δ_s = 2|∇c|`，其中因子 2 等价于硬编码 `Δc = 1/2`；
   * `local_range`（本轮新增，opt-in）：`δ_s = |∇c| / Δc_i`，
     `Δc_i = max_j c_j − min_j c_j` 为核邻域内**实测**颜色跨度。
6. **工具链**：PyTorch 2-D SPH（CPU，float64）、pytest、matplotlib；
   `benchmarks/surface_tension_dispersion/dispersion.py` 可复现（`--shifts/--ppw/--rdx`）。

## ③ 计算结果（数字全部来自 `validation_report.json`）

### 3.1 表面 delta 函数测度 `Σ_i δ_s,i V_i / A`（本轮的**核心新发现**）

理想 CSF 要求该比值恒为 1（与几何无关）。实测：

| 归一化 | 平面（毛细波，ppw=32） | 凸面（液滴 R/dx=16/32） | 几何间离散度 |
|---|---|---|---|
| `legacy` = 2\|∇c\| | **1.84 – 1.86** | **0.70 – 0.74** | **2.6×** |
| `local_range`（新增） | 2.75 – 2.80 | 0.91 – 0.97 | 2.9× |

结论：**现行 delta 函数在两个几何上分别偏强 85 % 与偏弱 30 %，几何间差 2.6 倍**。
这不是分辨率问题（ppw=24→32 时平面值 1.839→1.858 基本不动），是**开路自由面只有半个
颜色剖面**的结构性问题：`∫_fluid |∇c| dn = c_bulk − c_interface ≈ 1/2` 只对"理想双相"
成立，单相自由面上该积分随界面曲率变（凸面外半壳完全没有粒子）。

`local_range` 把液滴测度从 0.71 拉到 0.93（缺陷 29 % → 7 %），但把平面从 1.86 拉到 2.80
（因为平面自由面上实测 `Δc ≈ 0.5`，正好等于 legacy 的硬编码值，归一化只是重复乘了一次
不该乘的因子）。**故：该修复对"曲面/Laplace/Lamb"几何有效，对"近平面/毛细波"几何无效。**

### 3.2 Lamb 模态（drop，ω 误差）

| n | R/dx | legacy ω 误差 | local_range ω 误差 | 测度 S/A (legacy→local) |
|---|---|---|---|---|
| 2 | 16 | −0.74 % | +13.57 % | 0.702 → 0.911 |
| 2 | 32 | −2.57 % | +9.68 % | 0.713 → 0.932 |
| 3 | 16 | −11.39 % | **+0.21 %** | 0.712 → 0.924 |
| 3 | 32 | −11.82 % | **+0.42 %** | 0.721 → 0.945 |
| 4 | 16 | −18.47 % | −8.38 % | 0.726 → 0.932 |
| 4 | 32 | −18.53 % | −7.67 % | 0.737 → 0.971 |

* legacy 的误差随模态数单调增大（−0.7 % → −18.5 %），与测度缺陷 0.71 → `ω` 低约 15 % 的
  渐近行为一致；n=2 被曲率算子偏高抵消。
* `local_range` 把最坏误差从 **18.5 % 降到 9.7 %**，n=3 从 −11.8 % 降到 **+0.4 %**；
  但 n=2 被推高到 +13.6 %。**这是本轮唯一的量化改进，仍不进 3 % 门。**

### 3.3 毛细波（k=1,2,3）

| 归一化 | k | ppw | 刚度比 Δp/(σk²a) | ω 误差 | 系综 std |
|---|---|---|---|---|---|
| legacy | 1,2 | 24 / 32 | −0.206 / −0.298 | −54.6 % / −45.4 % | 0.41 / 0.09 |
| legacy | 3 | 24 / 32 | −0.197 / −0.181 | −55.6 % / −57.5 % | 0.39 / 0.03 |
| local_range | 1,2 | 24 / 32 | −0.249 / −0.320 | −50.2 % / −43.4 % | 0.47 / 0.12 |
| local_range | 3 | 24 / 32 | −0.214 / −0.204 | −53.8 % / −54.8 % | 0.44 / 0.04 |

**刚度比为负**——模态力是抗恢复（反号）的。即：在近平面界面上，CSF 力的模态 k 分量被
阶梯噪声主导，噪声幅度（`κ ~ 0.4`，对应 `κh ~ 0.1`）比波的真实曲率（`κ = ak² = 0.126`）
还大；系综平均后仍稳定地给出负值，说明这是**系统性**的，不是收敛前的抖动。
把幅值加大到 `a/λ = 0.05 / 0.10`（探针 7）也只给出 +0.19 … +0.26（仍 4–5 倍偏低），
且与分辨率几乎无关 ⇒ **曲率算子在 `κh ≪ 1` 的近平面模式下系统性衰减约一个量级**
（`Δp/(σk²a) ≈ 0.2`，而测度还偏大 1.86 倍 ⇒ 隐含曲率仅真值 ~10 %）。
这与 m13812 的审计（离散曲率 4–6× 扰动 `k²A`、伪加速度 23×）互为独立佐证。

### 3.4 收敛阶（C3）

按 `log|ω误差|` vs `log h` 最小二乘（R/dx = 16,32 或 ppw = 24,32 两点）：
`legacy`：波 k=1/2 +0.64、k=3 −0.11、drop l=2 **−1.79**、l=3 −0.05、l=4 −0.00；
`local_range` 同量级。**误差随加密不降反升或停滞** ⇒ 当前 CSF 算子没有 2 阶收敛的证据，
C3 判 FAIL。

### 3.5 σ 敏感性（C4）

drop n=2, R/dx=32，σ = 0.036 / 0.072 / 0.144 N/m：刚度比三种情形**逐位相同**
（0.9492084054609392 / 1.2029378525589234），最大相对离散 **0.0 %** ⇒ PASS。
（CSF 力对 σ 严格线性，这是结构性保证，不是巧合。）

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **测的是算子，不是时间积分器**。"ω"由模态法向应力与精确势流惯性反解；直接积分轨迹在
   HEAD 上不可用（m13812：开路自由面伪加速度 23×）。两者不可混读。
2. **精确参考必须用同一界面形状的几何曲率**。用线性 `σak²` 会把有限幅（`ak = 0.126`）
   的 O(2 %) 偏差混进来；本轮用精确几何模态系数，且有限幅自检（液滴 ε=0.1）给出 −1.64 % 的
   已知偏差。
3. **亚晶格系综不可省**。单次实现的系综 std 在 ppw=24 达 0.41（相对刚度 ~2），任何单点结论
   都无意义；ppw=32 时降到 0.03–0.12，报告取系综均值。
4. **法向必须用解析法向**。用模型法向会把"法向误差"和"力幅误差"混在一起
   （早期一次实现把极坐标法向写成切向，得到刚度为 0 的假象——已由
   `test_lamb_reference_coefficient...` 的独立数值微分类测试钉住）。
5. **`local_range` 不是通用修复**：液滴变好、平面变差，几何间离散度未下降（2.9× vs 2.6×）。
   因此默认仍是 `legacy`（逐位兼容），新归一化 opt-in。
6. **适用范围**：结论对六角密排 + 三次样条核 + h/dx=1.3 + 单相自由面成立；多相（两侧都有
   粒子）时 `Δc` 的定义需要重审。三维未覆盖（`fit_curvature` 只支持 2-D 界面拟合）。
7. **根因未完全定位**：毛细波模态衰减（~10×）的机制（曲率拟合在 κh≪1 下的系统偏差 vs
   法向/权重偏差）本轮只做排除，未做归因——这是下一步的首选靶子。
