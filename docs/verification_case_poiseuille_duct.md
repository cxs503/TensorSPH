## ① 案例

矩形管道 `0<=y<=H`, `0<=z<=W`, x 向周期，均匀体积力 g0，四壁无滑移：

```
nu (u_yy + u_zz) = -g0,   u = 0 on all four walls
```

| 量 | 值 |
|---|---|
| H | 0.1 m |
| W/H | 1.0（方管）、4.0（宽管） |
| nu | 0.01 m²/s |
| rho0 | 1000.0 kg/m³ |
| g0 | 9.81 m/s² |
| c_s | 20.0 m/s |
| tau = H²/(nu pi²) | 0.10132 s |

## ② 方法

(a) **解析参考**：分离变量得到的奇/奇双重 Fourier 级数（White *Viscous Fluid Flow* 3rd §3-3；Bruus *Theoretical Microfluidics* §3.3）：

```
u(y,z) = (16 g0 H²W²/(nu pi⁴)) Σ_{m,n odd} sin(m pi y/H) sin(n pi z/W) / (m n (m²W²+n²H²))
```

(b) **独立交叉验证**：自编五对角 Poisson 有限差分解（格心、壁面在格子面上、镜像条件 u_{-1}=-u_0，稀疏直接解），与级数**零共享代码**。

(c) **极限自检**：宽高比 →∞ 必须回到平面 Poiseuille 抛物线；方管必须给出经典 `u_c/(g0H²/8nu)=0.5894`。

(d) **SPH 边界条件**：四壁镜面（ghost）粒子，每步由当前流体状态重建、速度取反（no_slip）——即 2-D 已验证机制 `tensorsph.wall_mirror` 的 `axis` 扩展（本次新增 y/z 两个法向）。

## ⑤ 注意点 / 局限

1. **SPH 阶梯未跑**。3-D 算子集在 float64 下每个时间步的开销实测 **1.7 s/步 @1920 粒子**（H/dx=8，4 列，cProfile：`pair_kernels` 占 55%、邻居搜索 13%），单档 ~43 min，预声明阶梯（2 宽高比×4 档+控制）超出单张自找活单的算力预算；因此 D3–D9 一律记为 **not_run**，不算通过。
2. **修掉一个真实缺陷**：`threed/operators3.pair_geometry` 把核函数权重留在 kernel 自己的精度上，float64 粒子云（`cubic_lattice` 默认）会直接 `index_add` Float/Double 报错——任何 float64 的 3-D 算例此前根本跑不起来；已改为跟随粒子 dtype，并加了回归测试。
3. **级数截断必须随宽高比缩放**（`default_nmax`）：固定 nmax=81 在 W/H=16 时中心值偏高 2.4e-4，与要测的物理同量级；宽管一律按 aspect 放大模数。
4. 网格/几何：x 向周期仅 4 列且流动 x 不变，发展段（入口长度）问题不在本算例范围内。
5. 解析解本身无自由参数，不能调参去贴合；`D7` 的判别力在于——只对一对壁面生效的边界条件会给出 +70% 的中心速度。
