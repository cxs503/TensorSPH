# CASE-SPH-WEDGE-ENTRY-2D：入水砰击压力的可压性/密度噪声闭合研究

**锚点**：`CASE-SPH-WEDGE-ENTRY-2D`（算例池·二维楔形体入水砰击压力）
**验收**：β=30° 恒速入水，楔形体表面峰值砰击压力系数 vs Zhao & Faltinsen (1993) J. Fluid Mech. 246:593（DOI 10.1017/S002211209300028x），容差 <15%
**本单**：m20914（自找活·generalist 席）｜仓：TensorSPH｜分支：agent/m20914
**重要结论（先说）**：本单**没有**拿到 <15% 的峰值 Cp 验收，**也没有** <3%。拿到的是**为什么不**、以及**哪个量可以**：给定分辨率下"峰值砰击压力系数"这一指标被粒子级压力噪声主导，两种候选"解毒剂"（提高声速比 c₀/V、加 δ-SPH 密度扩散）都没能在可负担网格上把它压进 15%；而**驻点/顶点 Cp**（平滑、有精确解析值）在 dx=2 mm + δ=0.1 时达到 **2.5%**（<3%）。honest FAIL 如实记录。

## ① 案例介绍：物理背景、几何、参数

二维刚性楔形体以恒定速度 V 垂直入水，deadrise half-angle β=30°，忽略重力（Fr→∞，自相似前提）、不建模表面张力（We→∞）与粘性（无粘 + Monaghan 人工粘性）。砰击压力在自相似坐标 τ=|x|/(C·V·t) 下写成

- 湿宽系数 `C = π/(2 tan β)`，
- 驻点/顶点压力 `p(0)/q = 2C`，
- 压力峰值 `p_max/q = C²+1`（峰值横坐标 `τ_peak = √(1−1/C²)`），

其中 `q = ½ρV²`。β=30° 时 **C = 2.72070、Cp_apex = 5.44140、Cp_max = 8.40220、τ_peak = 0.93**。这些数**由 `tensorsph.wedge_entry.wagner_c_coeff / wagner_peak_over_q / wagner_p_over_q` 现算**（`run.refs_derived()`），不手抄；等式档 `docs/audit_wagner_pressure_reference_m17079.md` 已核过单位（早期版本把 Cp_apex 写成 C，差一倍）。

| 参数 | 值 | 说明 |
|---|---|---|
| deadrise β | 30° | 任务指定 |
| 入水速度 V | 1 m/s | 恒速 |
| 密度 ρ₀ | 1000 kg/m³ | 水 |
| 槽宽 / 槽深 | 0.40 m / 0.12 m | 观测窗止于 c_end = 0.05 m（湿半宽） |
| 粒子间距 dx | 4 mm（主阶梯）/ 2 mm（分辨率确认） | 湿宽上 25 / 50 个粒子 |
| 流体粒子数 | 3000（dx=4 mm）/ 12000（dx=2 mm） | 工件 `derived.n_fluid` |
| 壁面粒子数 | 54（dx=4 mm）/ 108（dx=2 mm） | 楔面单层 |
| 声速比 c₀/V | 20 / 40 / 80（/160 未取得） | 阶段一唯一变量；阶段二固定 20 |
| 状态方程 | Tait, γ=7, B = ρ₀c₀²/γ | 弱可压 WCSPH |
| 人工粘性 α | 0.03 | Monaghan |
| 核支撑 h/dx | 1.3 | 三次样条 |
| Courant | 0.35 | dt = 0.35h/(c₀+u) |
| 帧数 | 13（后 5 帧做系综平均） | t_end = 2c_end tanβ/(πV) = 0.0183776 s |
| 参考解 | Wagner (1932) 同一理想化（REAL，机算） | Zhao & Faltinsen 1993 数值：**WITHHELD** |

**参考值处置**：Z&F (1993) 是任务指定参考，但原文 β=30° 表/图数值不可得（闭源 + 仓内无登记副本，见 `benchmarks/case_sph_wedge_entry_2d/refs.json`），故按 WITHHELD 记录，不以记忆值顶替。可机器裁决的参考是 Wagner 解析解——它与 Z&F 属同一无粘不可压势流理想化，Z&F 摘要自述小 deadrise 下与 Wagner 渐近解一致，因此**本单所有误差百分数是"对 Wagner"**，不是"对 Z&F"。

## ② 怎么做的：两阶段序贯设计（假设 + 证伪判据，先写死再跑）

**要解决的问题**：`docs/case_sph_wedge_entry_2d.md` 记录 dx=4 mm、c₀/V=20 时 `Cp_band_peak = 32.01` vs Wagner 8.402（+281%），并把根因**诊断**为弱可压"声学噪声地板"（§5.3 的 Cp 预算公式），但**从未验证过这个诊断**。诊断不经受风险就是猜测，所以本单把它变成可证伪假设。

| 阶段 | 假设 H | 唯一变量 | 证伪判据 F（预声明） |
|---|---|---|---|
| 1 | Cp 超出量 = 弱可压声学噪声地板，故提高 c₀/V 应把它压向解析值 | c₀/V ∈ {20,40,80,160}，dx=4 mm 固定 | Cp_band_peak 不随 c₀/V 下降（每级允许 +2 % 噪声容差） |
| 2 | 超出量由**密度场噪声**承载，故 δ-SPH 密度扩散项能在固定 dx 下削减它 | δ ∈ {0, 0.05, 0.10, 0.20}（Molteni 形式），c₀/V=20、dx=4 mm 固定 | 超出量削减 <50 % |

阶段二的 δ 阶梯是**在阶段一评分之后**声明的（序贯/自适应设计，此处显式披露）；δ\* 选取规则（`argmin |err_band_peak|`，`DD_PICK_RULE`）在 δ 阶梯跑完前写死，随后用 δ\* 在 dx=2 mm 做分辨率确认。另外：在声明阶段二阶梯之前，δ=0.1@dx=4 mm 已作为探索性算例跑过一次（同一配置、同一结果），披露以免"选择性声明"。

代码与工具链（**不改求解器**，只加驱动/判据/聚合）：
- `benchmarks/case_sph_wedge_entry_2d/compressibility.py`：阶段一 `--stage sweep|accept`、阶段二 `--stage dd-sweep|dd-accept`；每个 case 一个 JSON 工件（配置 + 环境 + 逐帧时程 + τ 分箱壁面压力剖面）。
- 指标与评分**复用** `run.py` 的冻结评分器（`base.grade` / `base.ensemble_profile` / `base.refs_derived`），不另写一套：`cp_band_peak` = τ∈[0,1] 内壁面 Cp 剖面后 5 帧系综平均的最大值；`cp_at_peak_tau` = Wagner 自身峰值横坐标处读数；`cp_centre_mean` = 顶点 Cp 后 5 帧平均。
- `make_compressibility_figures.py`：只读 `summary.json` 出图。
- 测试 `tests/test_wedge_compressibility_study.py`（13 项，全绿）：钉死预声明设计（阶梯只动一个旋钮、容差不得放宽）、核验噪声地板闭式解与 Tait 方程一致、并**对分类器做负控**（平台阶梯/上升阶梯必须被裁为 FALSIFIED，弱趋势不得被卖成"主导原因"）。

## ④ 注意点（踩过的坑、局限、适用范围）

1. **指标本身就是噪声的放大器**：`cp_band_peak` 取的是 τ∈[0,1] 内剖面的最大值，等价于对整条剖面的粒子级尖峰取 max。粗网格下它由 1–2 个粒子的压力跳变决定（阶段一 τ@峰值在 0.66/0.98/0.91 之间乱跳、阶段三 0.92 与 0.93 相差 3000 倍），因此**它测的更多是离散噪声而不是砰击压力**。这不是放宽阈值的理由，而是"该指标在可负担分辨率下不可验收"的证据。
2. **c₀/V 不是解毒剂**（定量）：WCSPH 压力由密度误差生成，Cp 噪声 ≈ 2(c₀/V)²·δρ；细网格下 δρ∝(V/c₀)² 时两者相消，Cp 噪声对 c₀ 近乎标度不变。实测 32→52→24 与地板 43→100→89 就是这个"c₀² 吃掉 δρ 收益"的直接体现。
3. **δ-SPH 是部分解毒剂**：最大粒度（δ=0.2）反而退化，δ=0.1 最好但 50 %；非单调说明它与支撑域/接触判定耦合，**不能当旋钮调到过验收**（这正是预声明 `argmin` 规则存在的意义——避免事后挑 δ）。
4. **dx=2 mm 的质量守恒 FAIL（7.4 % > 5 %）**：δ-SPH 扩散项改变了密度场，本配置下 12000 粒子在 555 步内密度偏移反而变大；即"顶点 Cp 变好"伴随"弱可压前提变差"，这条必须与 2.5 % 一起读，不能只报好消息。
5. **参考值仍是 Wagner，不是 Z&F**：所有误差是对 Wagner 的。Z&F β=30° 数值仍 WITHHELD，补齐条件写在 `refs.json`（拿到可文本抽取的原文 + 页/表坐标再重跑 `--stage accept`）。
6. **阶段一未完成**：c₀/V=160（dx=4 mm）与 dx=2 mm 的 c₀ 确认例因集群排队未取回（`cj3044`），`summary.json:missing` 已显式登记，未插值、未外推。三级的 `FALSIFIED_NO_TREND` 已足以否证"提高 c₀ 单调改善"这一条，但**第四级缺席**是如实局限。
7. 适用范围：以上结论限于 β=30°、V=1 m/s、c₀/V∈[20,80]、dx∈[2,4] mm 的 WCSPH（Tait γ=7、Adami 壁面外推、Monaghan 人工粘性）配置；不外推到更钝楔形或更高 We。

**结论（不含糊）**：
- 任务指定的"峰值砰击压力系数 <15 %"**未达成**，最好一级仍 +50 %；<3 % 更未达成。
- 唯一进入 <3 % 的是**顶点 Cp**（dx=2 mm + δ=0.10，−2.5 %），但它不是任务指定的指标，且伴随质量守恒判据 FAIL。
- 因此本锚点的诚实状态是：**验证欠账已从"根因未验证"推进到"四种解释被逐一量化/排除"**，缺口明确落在"峰值型压力指标的噪声抑制（更细网格 / 更稳的压力估计器 / 或改用积分型载荷指标）"，而不是再调 c₀ 或 δ。

## ⑥ 对算例池的处置建议（可机器执行）

1. `CASE-SPH-WEDGE-ENTRY-2D` 的验收指标建议改为**双指标**：主判据 `Cp_apex`（解析时间无关、位置固定，已实测 2.5 %），报告指标 `Cp_band_peak`（要求随 dx 单调收敛/GCI ≤15 %，而非绝对值 ≤15 %）。理由与证据见 §3.3、§4.1。若 owner 坚持原始 `Cp_band_peak` 判据，则该锚点在 dx≥2 mm 的可负担分辨率下应记为 **NOT_SUPPORTED / 分辨率不足**，并把"更细网格（dx=1 mm、0.5 mm，粒子数 ×4/×16）或压力估计器升级（如 MLS/Shepard 重整化壁压或 ISPH 压力 Poisson 解）"列为唯一通路。
2. 下一手最省算力的验证：dx=1 mm + δ=0.1 + c₀/V=20（约 48000 粒子、约 1100 步）看 `Cp_band_peak` 是否进入 15 %；以及把 `cp_max` 换成面积加权载荷 `∫p dA / (½ρV²c)`——积分型量对粒子级尖峰不敏感，是更合理的工程验收量。
3. Z&F 原文补齐后，用 `run.py --stage accept` 即可自动对 Z&F 判分（接口已留好）。
