## 1. 问题：门值比的是什么参考？

算例门禁是 `max |p_SPH - p_ref| / p_ref`，`p_ref = rho0 g (H - y)`，容差 1%。该参考是不压缩极限；而 WCSPH 用的是 Tait 状态方程 `p = B((rho/rho0)^gamma - 1)`，其**自身**的静水精确解不是 `rho0 g (H-y)`，而是把 `dp/dy = -rho(p) g` 积分出来的闭式

    p(y) = B [ (1 + (gamma-1) g (H-y)/c0^2)^(gamma/(gamma-1)) - 1 ],  B = rho0 c0^2/gamma

小深度展开 `p = rho0 g h (1 + (1/2) g h / c0^2 + ...)`，`h = H-y`：
相对偏置 `bias% = 50 x (1 + (2-gamma) x/3 + ...)`，`x = g h / c0^2`：前两阶与 rho0 无关，gamma 只从二阶进入，**与 dx/粒子数完全无关**。
也就是说：再怎么加密网格，理想参考与模型精确解之间都固定差这一截。

## 2. 分解方法与产物

对已入库证据（`tests/data/case_hydrostatic`）逐个动态跑次、逐 band 计算
`err_ideal`（上游门值量）、`bias`（解析）、`residual = (p_SPH - p_eos)/p_eos`。
理想参考在脚本内由 band 中心重算，并与入库 `pressure_analytic` 逐项比对（证据同一性）。

## 4. 关键发现（数字全部取自 JSON）

1. **门值是「解析偏置 + 残差」两段，不是纯离散误差**。8 s 门控配置门带最大误差 0.7710 % = 该带解析偏置 +0.3949 % + 残差 +0.3747 %；门带平均误差 +0.3786 % 中偏置占 +0.3039 %（80 %），残差仅 +0.0745 %。
2. **偏置与分辨率无关，构成 1 % 容差里的硬底**：`c0 = 20 m/s` 时底部偏置 +0.4827 %，在 dx = 0.04 / 0.025 / 0.02 三个跑次上逐位相同（见表 §3「底部 EOS 偏置」列）。因此分辨率阶梯读数是 0.8213（dx 0.040） / 0.7033（dx 0.025） / 0.7710（dx 0.020）：非单调，并且落在 +0.48 %–+0.39 % 的偏置底附近。**结论：该门值不是收敛量**，不能用它论证「加密收敛到 1 % 以下」。
3. **残差主要来自有限时间平均（声学振荡），不是稳态离散偏差**：窗长阶梯（dx 0.02，c0 20）2 s → 门带平均残差 -0.7329 %、max|残差| 1.3152 %、4 s → 门带平均残差 -0.5484 %、max|残差| 1.1285 %、8 s → 门带平均残差 +0.0745 %、max|残差| 0.3879 %。max|残差| 随窗长单调下降，与上游「2 s 窗口振荡采样噪声过大」的预声明理由定量吻合——这也是把门钉在 8 s 窗口的独立佐证。
4. **`sound_c30` 读数变差（1.0203 % vs 门 0.7710 %）不是悖论**：提高 c0 把偏置压到 +0.2164 %（2.23× 小），但门带残差变成全负（6/6 带为负，平均 -0.4836 %），两者不再同号抵消，净误差反而变大。即「提高声速一定更准」被已入库证据**证伪**；残差对 c0 的依赖机制本单未判别。

## 5. 注意点 / 局限

- 分解用的是**已入库**的时间平均证据，未重新仿真；`p_eos` 依赖运行配置里记录的 `sound_speed` 与 `gamma=7`（EOS 常量取 `B = rho0 c0^2/gamma`，与本仓 `droplet_impact.hydrostatic_density` 同约定）。
- `gamma` 未在跑次记录里显式保存，本分解按本仓 EOS 默认 7 计算；若上游改成别的 gamma，偏置数值需重算（脚本读配置，不写死结论）。
- 自由面带（top-2，按 2h 重叠规则排除）仍列在 JSON 里但**不参与**门值与分解结论。
- 偏置的符号与量级是解析结论；**残差的物理来源（壁面求和截断 vs 声学时间平均的二阶项）本单未做判别实验**，只给出「残差随 c0 变化」的观测。

## 6. 给后续工作（可派单）

- 残差来源判别：需要 (dx × c0) 二维阶梯（如 dx ∈ {0.04,0.025,0.02} × c0 ∈ {20,30}），看残差在固定 c0 下是否随 dx 收敛——收敛→截断；不收敛→时间平均/声学项。
- 算例池含义：若要把 `CASE-HYDROSTATIC` 容差收紧到 <0.5 %，必须改用 Tait 一致参考（本模块）+ 加密，否则对 `c0=20` 的配置该容差在物理上不可达。
- `droplet_impact.hydrostatic_density` 是**一阶**近似（与本模块精确解的差为 `O((gh/c0^2)^2)`，Mach 0.14 时 <1e-4 相对）；作为初值可用，作为验证参考不可用，已在模块 docstring 与测试中钉住。

## 7. 误差判定

- 门值 vs 理想参考：0.7710 % → **< 3 %：是**（亦在 1 % 门内）。
- 门值 vs **Tait 一致**参考（本单新增的更强基准）：门带内 |残差| ≤ 0.3879 % → **< 3 %：是**；< 1 %：是。
- 闭式解 vs 数值 ODE 积分（RK4，见 `tests/test_eos_hydrostatics.py`）：相对偏差 < 1e-8 → 参考本身不是误差源。
