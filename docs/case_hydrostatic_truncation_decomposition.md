## 结论（由本记录计算，不手抄）

* 内部条带压强误差 `|e_p| = 51.4 %/m x dx^1.00`（对数最小二乘，6 点）：一阶收敛，系数 51.4 %/m。
* 同一批内部条带的**密度响应**误差 `|e_rho| = 49.9 %/m x dx^1.00`，与压强误差在 0.02 个百分点内重合 -> 压强误差是密度响应的直接继承，不是压强后处理产生的。
* 判据分辨率 `dx = 0.02 m` 处的静态内部截断地板 = 1.004 %：与 1.0 % 判据同量级（余量 -0.004 个百分点）。即判据的通过完全依赖动态时间平均把读数压回判据以内，而不是静态场本身已达判据。
* 同一算例的动态时间平均判据读数 0.7710 %（`tests/data/case_hydrostatic/runs/window_8s.json`，limit 1.00 %，worst band 1）：相对静态截断地板变化 -0.233 个百分点 —— 动态判据几乎贴着一阶截断地板，因此任何改变时间平均的开关（窗口长度、c0、展弦比）都有把读数推过判据的余地。
* 声速扫描：`B` 从 14286 到 128571 Pa（x9.00）时，密度亏损从 -0.0187 % 变到 -0.0021 %（约 1/B），而密度响应误差只从 -1.038 % 动到 -0.987 %，压强误差从 1.060 % 到 0.992 % —— 压强判据对 c0 近似不变，因为亏损 ∝ 1/B 与 Tait 放大因子 ∝ B 反向抵消。

## 读法（必须先于读数声明）

* `max|e_p|` 是**该类别内**的最大绝对压强误差；壁面类与内部类不能相加，也不能互相替代：前者测的是固壁核支撑截断，后者才是分辨率收敛。
* `压强误差 %` = `p_band / p_ref - 1`，`p_ref = rho0 g (H - y_band)` 在实测质量加权条带中心求值（零手抄）。
* `其中由密度决定 %` = 把实测密度比值经 Tait 律 `p = B[(rho/rho0)^7 - 1]` 精确映射到压强比值；它和 `压强误差 %` 的差就是 `后处理残差 %`（自由面闭合 / 壁面压强外推等对压强的直接修改）。
* 只有内部类可以读作分辨率阶梯：`p ~ dx^m` 的 `m` 由对数最小二乘给出，不预设为 1。
