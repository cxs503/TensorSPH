# 表面张力 CSF 模型的解析基准核验（consistent 离散）

**范围**: TensorSPH `src/tensorsph/csf_consistent.py`、`surface_tension.py`、`droplet_impact.py`
**基准**: 2-D 单相静止液滴的 Young-Laplace 定律（本文件所有数字由
`benchmarks/csf_consistent/run.py` 写出的 JSON 程序化注入，无手抄）

## 1. 案例介绍（物理背景与参数）

半径 `R = 0.02 m` 的二维单相液滴，六方密排晶格初始化，四周真空，无重力。
表面张力使液滴内部建立过压 `Delta p = sigma / R`（Young-Laplace，2-D 圆形界面）。
本算例是 CSF 表面张力模型的**唯一可量化判据**：SF 力若强度或方向错误，过压立刻偏离。

| 参数 | 值 |
|---|---|
| 液滴半径 R | 0.02 m |
| 表面张力系数 sigma | 7.2 N/m (水) |
| 参考密度 rho0 | 1000.0 kg/m^3 |
| 声速 c0 | 20.0 m/s (Mach_max ~ 0.03) |
| 状态方程 | Tait, gamma = 7 |
| 分辨率扫描 dx | 0.003, 0.002, 0.0015 m（h = 1.3 dx） |
| 解析参考 | Delta p = sigma/R = 360 Pa；kappa = 1/R = 50 1/m；F_cut = 2 sigma = 14.4 N/m |

三条互不依赖的解析判据（前一轮 m2174 全部 FAIL）：

1. **Young-Laplace**：`p(0) - p(R) = sigma/R`；
2. **切割力恒等式**：穿过液滴切一刀，表面张力传递的总力恰为 `2 sigma`（每单位厚度）——
   它只考核力的**幅值**，完全不依赖压强场；
3. **曲率**：`kappa = 1/R`，且 `delta_s` 必须满足 `int delta_s dn = 1`（CSF delta 函数归一）。

## 2. 怎么做的（方法/流程）

原实现（m277）的三个病灶，逐条替换为标准离散：

| 病灶 | 原实现 | 现在 |
|---|---|---|
| 色函数 c | 邻居数启发式：内部 1，表层 `n_neigh/<n_neigh>` ~ 0.7 → 界面跳变只有 O(0.3) | 核和指示函数 `c_i = sum_j V_j W_ij`（含自身体积项），主体饱和到 1，最外层 ~1/2 |
| 梯度/散度 | 一阶 SPH 算子，自由面处截断偏置未校正 | 一阶完备（MLS/Bonet-Lok）算子，`M_i = sum_j V_j (x_j-x_i) (x) grad_i W_ij` |
| delta_s | `|grad c|`，因 c 跳变小而低估 3-10x | `2 |grad c|`：单相粒子云里指示函数的另一半落在真空中，`int_fluid |grad c| dn = 1 - 1/2`，故两相 delta 函数是流体侧梯度的 2 倍 |
| 曲率 | 直接 `-div n`，法向噪声被微分放大 | 法向先做 2 遍核（Shepard）平滑再做 MLS 散度 |
| 接触角 BC | 合入门禁把 `apply_contact_angle_boundary` 整个函数丢掉，包**无法 import** | 重写为真实实现：`n . n_wall = cos(theta)`，保幅旋转 + 距壁线性混合 |

力的装配不变：`a_i = -sigma kappa_i delta_s_i n_i / rho_i`。

工具链：`benchmarks/csf_consistent/run.py`（instant 诊断 + relax 时间推进 + 出图），
`tests/test_csf_consistent.py`（每个离散算子对解析式单测）。

## 4. 结果判读

- **力的幅值与方向已修好**：切割力恒等式 `F_cut/(2 sigma)` 从 0.28–0.52
  变到 1.074–1.110（三档分辨率全部 < 15%）；
  法向由「向内比例 51-57%」变为中位 `cos(a, rhat) = 0.999–1.000`。
- **曲率仍偏大 25–30%**：direction/幅值已对，但 `div n` 在两层壳内仍偏高，未进 15% 门。
- **伪流下降**：0.201 → 0.044，首次低于 Adami 阈值 0.1。
- **端到端压差仍未过门**：-75.6%（legacy -98.5%）。原因**不在力**而在压强场：
  `Delta p = sigma/R = 360 Pa` 对应的 Tait 压缩只有 `6.30e-03`
  （rho/rho0 - 1），而求和密度在 ~20 邻居下的离散噪声就在 1e-3 量级，
  即压差测量本身被状态方程的**分辨率地板**吞掉。这是 WCSPH 弱可压 + 求和密度的已知限制，
  不是本次改动的回归；要过 15% 需改压强基准（如背景压强/无散修正或降低 c0）。

## 5. 注意点（踩过的坑）

1. **核和必须含自身体积项**：邻居表不含自配对，漏掉 `V_i W(0)` 会让 c 只饱和到 0.773，
   `|grad c|` 随之低 23%（这正是最初复现出来的假象）。
2. **delta_s 的 2 倍因子不是拟合**：单相粒子云里 c 只走完 1 -> 1/2，另一半在真空里没人携带；
   不补这 2 倍，切割力恰好差一半（实测 0.55 → 1.08）。
3. **不要用「所有 |a|>0 的粒子」算向内比例**：内部粒子 `|grad c| ~ 1e-12` 给出零力，
   `cos` 未定义，会把向内比例拉低到 0.46 —— 必须按 `delta_s > 5% max` 筛。
4. **法向平滑抑制曲率过估**：2 遍 Shepard 平滑把 dx=1mm 的曲率误差从 +43% 降到 +31%（本文用 2 遍），
   对径向场方向不产生偏置。
5. **接触角 BC 只能保幅旋转**：CSF 力幅值正比于 `|grad c|`，改幅值等于偷偷改 sigma。
6. 门禁曾两次把 `apply_contact_angle_boundary` 从 `surface_tension.py` 滤掉（m2389/m2399），
   本次是第三次；`tests/test_csf_consistent.py::test_public_api_is_complete` 现在守住这条。

## 6. 误差判定（逐项，显式回答「是否 < 3%」）

| 关键量 | 基准 | 实测（consistent） | 误差 | < 3%？ | < 15%？ |
|---|---|---|---|---|---|
| 切割力 F_cut | 2 sigma = 14.4 N/m | -15.50 N/m | 7.7% | 否 | 是 |
| 曲率 kappa | 50 1/m | 62.4 1/m | 24.9% | 否 | 否 |
| delta_s 归一 | 1.0 | 0.751 | 25% | 否 | 否 |
| 力方向 cos | 1.0 | 1.000 | 0.0% | 是 | 是 |
| Laplace 压差 | 360 Pa | 87.7 Pa | -75.6% | 否 | 否 |

**结论**：力的幅值与方向（切割力恒等式、方向对齐）已满足 15% 平台标准；
曲率、delta_s 归一与端到端压差**未**满足，且已定位到具体原因（曲率算子二阶精度不足；
压强场受求和密度噪声地板限制）。**没有伪造达标**：本轮的净增量是
「包重新可 import + 接触角 BC 恢复为真实实现 + 三档分辨率的切割力恒等式从 ~2x 偏差修到 8-11% +
伪流首次低于 Adami 阈值」，端到端 Laplace 压差仍是 WITHHELD。

## 7. 补记：压差判据的分辨率敏感性（诚实记录）

同一套 consistent 离散，端到端压差在**不同分辨率/量带**下并不一致：

| 算例 | R/h | Delta p 误差 | 是否 < 15% |
|---|---|---|---|
| `benchmarks/laplace_law` relax, dx = 4 mm, steps 380 | ~5 | 见 `tests/test_laplace_law.py::test_laplace_pressure_jump`（本轮已由 xfail 转 pass） | 是 |
| 本文 relax, dx = 2 mm, steps 600 | ~7.7 | -75.6% | 否 |

两者用的是同一 `p_core - p_shell` 量带定义，差别只在分辨率与推进时长。
这说明压差读数被「求和密度噪声 / 状态方程地板」主导（见第 4、5 节），
单点通过**不能**当作「Laplace 定律已解决」的证明；可发表的口径应当是
「力层面（切割力恒等式、法向对齐、delta_s 归一）已进入判据，
压强层面仍是 WITHHELD，需要改压强基准而不是继续调表面张力离散」。

## 7. 后续与勘误（m2592 + m2923）

### 7.1 曲率偏置修复（m2592）
m2592 把上表唯一未达标的曲率判据拆开归因：`kappa = div n` 的偏置**不随加密收敛**，
来自**饱和内壳**（c ≥ 0.99）粒子的法向角噪声被 `~1/dx` 放大；把 MLS 散度喂以精确径向
法向即降到 15% 内。修复为「曲率用一遍 Shepard 平滑的色函数、力仍用锐利场」
（`csf_fields(..., curvature_color_smoothing=1)`，显式开启），dx ≤ 2 mm 曲率误差 14.4 / 10.5%，
切割力比同步改善到 0.997 / 0.969。**未解决**：δ 函数归一缺口 ~25% 与端到端 Δp（relax 读数
未达准静态）。详见 `docs/verification_csf_curvature_bias.md` 与
`benchmarks/csf_consistent/curvature_audit.json`。

### 7.2 压差判据勘误（m2923 复核，2026-11-03）
本文 §3.3 与 §4 把端到端压差 `-75.6%` 归因为「状态方程的**分辨率地板**把压差吞掉」，
并以 `Delta p = p(r<0.5R) - p(0.80R<r<0.95R)` 为判据。复核发现**两处都需要修正**：

1. **判据定义错误**：`0.80–0.95 R` 仍在液滴内部，按二维 Young-Laplace 定律其压强与核心
   压强相同，故该式测的是「内部压强径向非均匀度」（噪声），不是跳变。环境压强在 `R` 之外。
2. **归因赔率不足**：EOS 放大器只放大**噪声**（内部 `std/mean` 随 c0 从 80%→25%），
   不解释稳定的 **-37% 均值缺口**；均值缺口与 c0、与 dx 均无关，是系统性的。

修正后的判据、声速阶梯、δ-SPH 假设检验、径向压强剖面与回归测试见
`docs/verification_laplace_pressure_jump.md`（工件 `benchmarks/laplace_pressure_jump/`）。
本文其余结论（切割力恒等式 1.07–1.11、方向 cos≈1、伪流低于 Adami 阈值）不受影响。
