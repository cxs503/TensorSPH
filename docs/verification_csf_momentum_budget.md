# CSF 表面张力加速度装配口径：f/ρ_sum 还是 f/ρ0（动量预算核验）

**范围**: `src/tensorsph/csf_consistent.py`（新增 `accel_density`）、
`src/tensorsph/surface_tension.py`、`src/tensorsph/droplet_impact.py`（`Config.csf_accel_density`）
**基准**: 2-D 圆形液滴的三条**与 R、分辨率、曲率算子无关**的解析恒等式；本文件所有数字由
`benchmarks/csf_momentum_budget/run.py` 写出的 `validation_report.json` 程序化注入，无手抄。

## 1. 案例介绍（物理背景、几何、参数）

CSF（Brackbill, Kothe & Zemach 1992）把界面上的**单位面积**力摊成**单位体积**力

```
f = -sigma kappa delta_s n ,      int delta_s dn = 1 ,
```

再由 `a = f / rho` 换成加速度。问题在于这个 `rho` 取哪一个：

| 口径 | 除数 | `m a` 等于什么 |
|---|---|---|
| `summation`（历史默认） | 求和密度 `rho_i` | `rho0 V_i f_i / rho_i` |
| `rho0`（本轮新增） | 参考密度 `rho0` | `V_i f_i`（几何体积，纯面积分） |

自由面上的核被截断，`rho_i` 在最外层比 `rho0` 低 15-25%（m2737 实测界面壳
`rho_w/rho0 = 0.80`），于是 `summation` 口径在那一层把动量注入了 `rho0/rho_i` 倍 ——
m2737 已指出这正是界面动量注入高估 25%、伪流与压差超调的直接来源，本轮把它变成
**可判定的口径**（配置项 + 动量预算门）。

| 参数 | 值 |
|---|---|
| 液滴半径 R | 0.02 m |
| 表面张力系数 sigma | 7.2 N/m |
| 参考密度 rho0 | 1000.0 kg/m^3 |
| 声速 c0 | 20.0 m/s |
| 状态方程 | Tait, gamma = 7 |
| 平滑长度 | h = 1.3 dx |
| 曲率算子 | fit_quadratic（上一轮已验证：+0.9%…+5.3%） |
| 格子 | hexagonal，对齐 `benchmarks/laplace_law` |
| 分辨率扫描 | dx = 3.0, 2.0, 1.5 mm |
| 时间推进 | dx = 2.0 mm，t_end = 2.8 t_sigma |
| 解析参考 | `sum m a = 0`、`sum r x m a = 0`、`F_cut/(2 sigma) = -1`、`Delta p = sigma/R = 360.0 Pa` |

## 2. 怎么做的（方法/流程）

1. **先把「力」与「装配」分开**。同一构型上用 `surface_tension_acceleration` 跑两遍：
   只差 `accel_density` 一个参数，两者的牵引 `f` 完全相同，读数因此只反映装配口径。
   `f = a_rho0 * rho0` 直接取回牵引，用于几何口径的切割力与量纲归一。
2. **三条闭合恒等式**（都不依赖 R / 分辨率 / 曲率算子，无法靠标定满足）：
   - 净动量注入 `|sum m_i a_i|`：闭合界面在真空中的牵引必须自相抵消（牛顿第三定律）。
   - 净力矩 `|sum r_i x m_i a_i|`：圆形界面的牵引沿径向，不能携带力矩。
   - 切割力 `sum_{x>0} V_i f_i,x = -2 sigma`（2-D，单位深度力）。
   归一化用 `sum V_i |f_i|`（牵引总量）与 `2 sigma`，都是同一构型内的量，不含自由参数。
3. **A/B 的时间推进**：同一初值、同一步数、同一曲率算子，只切 `csf_accel_density`，
   记录质心漂移 `|Delta x_cm|/h`、伪流 `|v|max/sqrt(sigma/rho R)`、核内过压
   `p_interior/(sigma/R)`。质心漂移是动量注入的**累积证据**（静态读数只看单步）。
4. 工具链：`benchmarks/csf_momentum_budget/run.py`（静态判据 + 推进 + 出图）、
   `make_doc.py`（本文件，数字注入）、`tests/test_csf_momentum_budget.py`（8 条）。

## 3. 计算结果

### 3.1 界面壳密度亏损（口径差值的唯一来源）

| dx [mm] | N | 界面粒子 | mean rho/rho0 | min rho/rho0 | 平均注入因子 rho0/rho | 最坏注入因子 |
|---|---|---|---|---|---|---|
| 3.00 | 161 | 102 | 0.873 | 0.602 | 1.183 | 1.661 |
| 2.00 | 362 | 165 | 0.882 | 0.508 | 1.170 | 1.969 |

## 4. 结果判读

- **装配口径确实改变动量账**：净动量注入占牵引总量的比例，`summation` 为 0.0055, 0.0108, 0.0156，`rho0` 为 0.0037, 0.0048, 0.0087（dx 从小到大）—— 平均改善 1.84x，且两档口径的**相对差**与界面壳密度亏损 `1 - mean(rho/rho0) = 0.113` 同量级，证明差值就来自那片截断核。
- **切割力恒等式不受影响**：两种口径下 `F_cut/(2 sigma) = +0.7102`（1.50 mm），逐位相同 —— 改装配救不了 29% 的幅值亏损。
- **动态上 `rho0` 把核内过压打到 0 附近**（`p_interior/(sigma/R)`：summation +0.466 vs rho0 +0.543），即过量注入是当前离散下唯一「把界面力变成过压」的通道。这既是物理上的坏消息（说明该通道不是正路），也是为什么不改默认值。

## 5. 注意点（踩过的坑 / 适用范围）

1. **切割力与装配口径无关**，两条读数逐位相同（见 §3.2）：它只由牵引 `f` 决定，
   所以「改装配」**不会**救 `F_cut/(2 sigma)` 的 29% 亏损 —— 那个亏损在 `delta_s` /
   求和密度口径里（m2737 已把「几何口径」与「加速度口径」分开记账）。任何切割力读数
   必须先声明口径，否则会把相消误差当成精度。
2. **净力矩在浮点噪声内为零**（~1e-18 相对），说明牵引场本身是径向的、装配没有引入
   旋转机制；这一条同时是两个口径的共同控制量。
3. **质心漂移不是好的动态判据**：两种口径下都在粒子尺度以下（见 §3.3）。原因是液滴
   初值是六方格子且形状对称，净力的**矢量**在对称轴周围几乎抵消，而动量注入的偏差主要
   体现为幅值（径向），不是合力。真正被装配影响的是伪流与核内压强。
4. **`rho0` 口径不是免费的**：它把净动量注入砍掉一半（§3.2），伪流也略降，但核内过压
   反而更接近 0（§3.3）—— 因为历史上那 25% 的过量注入恰是「把液滴压出一点过压」的唯一
   机制。故默认值仍是 `summation`；把 `rho0` 设为默认的前置条件是先修压强基准
   （Adami 压强偏置 / 双相界面），与 m2716、m2737 的交接一致。
5. **覆盖范围**：2-D、单相、静止液滴、无重力、无壁面；3-D、多相、动态接触角未验证。

## 6. 误差判定（逐项，显式回答「是否 < 3%」）

| 关键量 | 基准 | `summation` | `rho0` | `rho0` 误差 | < 3%？ | < 15%？ |
|---|---|---|---|---|---|---|
| 净动量注入 `|sum m a|` | 0 | 0.0156 | 0.0087 | — | 否 | 是 |
| 净力矩 `|sum r x m a|` | 0 | 5.7e-04 | 2.7e-04 | — | 是 | 是 |
| 切割力 `F_cut/(2 sigma)` | -1 | +0.7102 | +0.7102 | 171.0% | 否 | 否 |
| `p_interior`（summation） | 360.0 Pa | 167.7 Pa | — | 53.4% | 否 | 否 |
| `p_interior`（rho0） | 360.0 Pa | 195.5 Pa | — | 45.7% | 否 | 否 |

**结论（honest）**：本轮把「加速度该除哪个密度」从口头约定变成**可判定口径 + 三条闭合恒等式**：`rho0` 口径把净动量注入减半（0.0156 → 0.0087 at 1.50 mm），净力矩在两种口径下都在 1e-18 量级，切割力恒等式与装配口径无关、仍为 +0.710（-29%）。**Young-Laplace 压差仍不达 15%**（维持 WITHHELD）：`rho0` 口径下核内过压反而归零，说明当前单相求和密度离散下不存在可承载 `sigma/R` 的压强通道 —— 与 m2716（无静态平衡）与 m2737（缺压强偏置）的结论一致，不是本轮的装配口径能修的。**默认值保持 `summation`**，`rho0` 作为 A/B 开关与后续「压强基准修好后的默认候选」保留。
