# Dev report — inner-hourglass scope fix for the ported SPHinXsys CSS model

**Anchor** `XVAL-SPH-MIXTURE-MATERIAL-AND-SURFACE-TENSION` · mission **m21855** (round 2 of
m19927 / PR#833) · repository **TensorSPH** · 2026-11-15

## 0. Decision and competing alternatives

**Decision.** Make the ported SPHinXsys CSS surface tension usable with its hourglass penalty
*on* in single-phase (vacuum-reduced) mode by adding a **scope switch**
(`hourglass_scope ∈ {"all", "contact"}`), and re-deliver the Lamb-mode cross-validation record
with the fixed setting.

Alternatives considered:

| alternative | why not chosen |
|---|---|
| rewrite the inner hourglass term | it is a *faithful* transcription of upstream (re-derived in `LAMB.md` §6.1); a rewrite would break the "port" claim and the two-phase path that works |
| rescale the inner hourglass by `4 f (1-f)` | there is no `f` on a free surface (`f → 1`), so the factor is a hidden constant, not a physical one |
| change the default to `hourglass=False` | silently changes every existing consumer of `sphinxys_css`; the scope switch is explicit and backwards compatible |
| leave the strict-`xfail` pins and document only | the record already did that (m19927); mission asked to see it through — the defect had to be *fixed*, not only described |

**Hypothesis.** The single-phase Lamb error of the ported CSS force is dominated by the *inner*
hourglass penalty (a lattice term), not by the stress flux; dropping only the inner part (and
keeping the contact part) restores the physical result on a free surface and is inert on the
two-phase path.

## 2. Results

| R/Δx | scope `"all"` (upstream) | scope `"contact"` (fixed) | hourglass off | Brackbill CSF |
|---|---|---|---|---|
| 16 | -136.71 % | **+0.70 %** | +0.70 % | +1.23 % |
| 24 | +134.65 % | **-0.85 %** | -0.85 % | -2.01 % |
| 32 | +167.39 % | **-0.58 %** | -0.58 % | -8.26 % |

Spurious modal force on a perfect circle (`eps = 0`, R/Δx = 24): `-1.508 Pa = -2.09 σ/R` at
scope `"all"`, `-0.0021 Pa` at scope `"contact"`. Two-phase 1000:1 mixture at R/Δx = 24:
`+1.0107` vs `+1.0107` (ω ratio, Δ = 0.0014 pp) — the fix is inert where the physics is.

## 4. Caveats

* Scope `"contact"` removes the symptom; it does not repair the operator. A vacuum-reduced
  single-phase interface keeps a one-sided colour gradient (delta integral 0.96–0.98), so a few
  percent of residual deficit is normalisation, not curvature.
* The `eps`-scan shows the discrete modal force is not exactly linear in `eps`
  (1.48x–2.16x per doubling at R/Δx = 16), so the gate is checked across amplitudes instead of
  by a linearity law.
* The two-phase inner hourglass is retained at scope `"all"` by default; only the single-phase
  call site is expected to opt in.
