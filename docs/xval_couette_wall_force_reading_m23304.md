# Couette 壁面剪切：力（Newton）读数闭合 17 % 判定的估计器欠账（mission 23304）

**锚点**: `XVAL-SPH-METHOD-SELECTION-2026-11-12`（验收：对标误差 <15 %）｜ **仓库**: TensorSPH ｜
**产物**: `benchmarks/couette/out_force/wall_force_reading.json`（驱动 `benchmarks/couette/wall_force_reading.py`，
图 `docs/figures/m23304_wall_force_reading.png`，测试 `tests/test_couette_wall_force_reading.py`，9 passed）

## ① 案例介绍

平面 Couette 通道：H = 0.1 m、ν = 0.02 m²/s、上壁滑移 U = 0.2 m/s、下壁静止、x 周期，
ρ0 = 1000 kg/m³、c = 20 m/s、h = 1.3 dx、3 层壁面粒子、`wall_friction = 1`、12 个流体列。
H²/ν = 0.5 s，Re = U H/ν = 1，Ma = U/c = 0.01。解析解 u = U y/H、τ = ρν U/H = **40.000 Pa**
（Batchelor 1967 §4.2）。

方法选择账本对 `wcsph_wall_no_slip` 记的滑动壁误差是
`x_couette_viscous_time_top_h8` = 14.203 %、`x_couette_viscous_time_top_h16` = 17.076 %
（均为一格割线 `(u[N-1]-u[N-2])/dy`），其中 17.076 % 超出业主 15 % 标准，是账本里该方法最差的证据。
`docs/dev_report_couette_sliding_wall_reading_m20907.md` 已证同一剖面的 4 行拟合只有 8.60 %，
但该报告 §5 明确留下一条欠账：**斜率不是应力**，教科书定义的壁面剪切是流体对壁面施加的切向力，
而当时用力读数得到的牛顿第三定律残差有 12 Pa（对 40 Pa 应力），所以力读数被判为死路、未入库。
本单就是把这端接上：**用壁面反力（不是剖面斜率）测壁面剪应力**，并让两项簿记恒等式成为可裁的门。

## ② 怎么做的

1. **力读数**：`tensorsph.droplet_impact.rhs(..., split=True)` 的 `loads["reaction"]` 给出流体对每个壁粒子的
   作用力（牛顿第三定律作用于同一个对压力/黏性对项）。取 x 分量、对壁面足迹求和、除以周期长度 L，
   得到 τ_force = F_x/L [Pa]；时间平均取运行后 20 %，与割线读数**同一次运行、同一时间平均**。
2. **簿记修正（m20907 的死路所在）**：原诊断用 **3 份流体云 + 1 条壁带**，反力按整条壁带求和会漏项/重复计数，
   残差 12 Pa 就是这么来的。本驱动把壁格点按 **x 方向三个互不重叠的 L 宽副本** 平铺（与流体云的三副本一一对应），
   只对 `x ∈ [0, L)` 那一份求和——既是严格的一周期载荷，也不需要任何按 x 窗的裁剪。
   遗留布局（单条壁带 + 3dx 外延 + x 窗裁剪）保留为 `legacy` 臂，只用于复现与量化那个残差。
3. **两项内部恒等式（先于读数字写定）**：牛顿第三定律 `Σ_all F_x + Σ_fluid m a_x = 0` < 1 %；
   周期不变性 `F_(copy 0) = F_all/3` < 1 %。精度门：两壁各 5 %（求解器门），业主标准 15 %。
4. **同一运行两种估计器**：力读数与账本割线（`profile_metrics` 的 `wall_shear_ratio_top/bottom`）在同一次运行上同时读出，
   因此两者的差不是"两次运行"的差。
5. 复现：

```bash
PYTHONPATH=src python benchmarks/couette/wall_force_reading.py --res 8  --vt 1.2 --layouts periodic3 legacy
PYTHONPATH=src python benchmarks/couette/wall_force_reading.py --res 16 --vt 1.2 --layouts periodic3 legacy --merge
PYTHONPATH=src python benchmarks/couette/plot_wall_force.py
PYTHONPATH=src python benchmarks/couette/wall_force_reading.py --check
PYTHONPATH=src python -m pytest tests/test_couette_wall_force_reading.py -q   # 9 passed
```

**三条读数**（`periodic3` 臂）：

* **H/dx = 16、t_end = 1.2 H²/ν**：力读数为 **-7.04 % / -10.33 %**（滑动壁 / 固定壁），
  两壁都在业主 15 % 标准内；**同一次运行**的割线读数是 **-17.77 % / -0.73 %**，
  滑动壁超标准。即：账本用来排除该方案的 17 % 量级，在力（应力）口径下缩到 7 %，同一运行两口径相差
  10.7 个百分点。
* **H/dx = 8、t_end = 1.2 H²/ν**：力读数 -10.81 % / -21.94 %，
  固定壁一侧仍在 15 % 之外——**粗档不成立**，且该档 drift = 3.55e-02 不过 1 % 定常门，
  读数本身是启动/振荡态。因此不能说"力口径一律 <15 %"，只能说"账本的 17 % 不是应力缺口"。
* **t_end 阶梯点 H/dx = 8、3.6 H²/ν**：力读数 -9.79 % / -17.71 %，
  该点 drift = 8.63e-02（4 倍定常门都不够），所以这行只作阶梯参考，不作精度主张。

## ⑤ 注意点（踩过的坑 / 局限）

1. **簿记才是 m20907 的死路**：遗留布局的牛顿三定律残差实测 **-10.44 %（H/dx=8）/ -8.86 %（H/dx=16）**，
   而三副本布局是 **-0.15 % / +0.07 %**。
   也就是说"12 Pa 残差"不是物理，是**壁带与流体副本数不匹配**；同一份代码换个簿记方式就闭合到 0.1 % 量级。
2. **副本不变性门（预声明 1 %）未过**：实测 1.58 % / 1.32 %。
   机制清楚——最外两份流体副本各缺一个邻居副本，其动力学与中间副本不完全一致；L/h = 15.6 下这是有限域截断，
   不是实现错误。该子项按诚实降级处理（`copy_invariance_ok = false`），主恒等式（三定律）单列。
3. **账本自身的两个数是 3.6 H²/ν 的**，本产物只有 1.2 H²/ν 的力臂；3.6 H²/ν 的力臂已递交集群
   （`cj4752`，4 核，排队位次 146，本报告窗口内未返回）——**因此 registry 的 17.076 % 还没有被力读数直接复核**，
   只有同 rung、早一个时间层的 17.77 % 割线与 7.04 % 力读数这一对。
4. **同 rung 的 3.6 H²/ν 粗档不可复现**：本产物 `periodic3` H/dx=8、3.6 H²/ν 的割线读数是 -16.72 %，
   而 committed sweep 同点是 14.203 %。两者只差壁面粒子的求和顺序（物理格子相同），
   说明该点（drift 8.63e-02、非定常）的读数对奇异摄动敏感，**不能当作可复现读数引用**。
5. 力读数**不含**壁面法向压力与动量方程的其余项，只取 x 分量；剪切项是主项但非全部，
   两侧压力脉动会进 1 % 量级（三定律残差即其上界）。
6. 未做：`wall_friction`/`ν`/`U` 扫描、时间步与核宽敏感性；H/dx = 32；非周期变体（`diag_wall_force.py` 的旧死路已不需要）。

## ⑥ 误差判定（逐项回答"是否 < 3 %"）

| 关键量 | 实测 | 基准 | 误差 | < 3 % ? | < 15 % ? |
|---|---|---|---|---|---|
| 力读数，滑动壁，H/dx=16，1.2 H²/ν | 37.18 Pa | 40.00 Pa | -7.04 % | **否** | 是 |
| 力读数，固定壁，H/dx=16，1.2 H²/ν | 35.87 Pa | 40.00 Pa | -10.33 % | **否** | 是 |
| 账本割线，滑动壁，同一运行 | — | 同上 | -17.77 % | 否 | **否** |
| 牛顿第三定律残差（H/dx=16） | — | 0 | +0.07 % | **是** | 是 |
| 遗留布局三定律残差（H/dx=16） | — | 0 | -8.86 % | 否 | 否 |

**结论（不粉饰）**：力口径下，账本里那条 17 % 量级的"应力缺口"在细档缩到 7.0 %（滑动壁）/ 10.3 %（固定壁），
**7–10 % 仍不满足 3 %**，但**在业主 15 % 标准内**；粗档固定壁 21.9 % 仍超 15 % 且非定常，
所以"该壁面模型传力合格"这句话现在还不能说——能说的是：**账本 17.076 % 是估计器（一格割线）性质的数，不是壁面少传 17 % 应力**，
registry 的 caveat 措辞应据此改写。
