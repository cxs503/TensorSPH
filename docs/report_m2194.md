## ① 案例介绍（物理背景 / 几何 / 参数表）

表面张力使液滴内部压强高于外部，2-D 圆截面满足 Young–Laplace 关系：

$$\Delta p = p_{in} - p_{out} = \sigma / R$$

这是表面张力模型唯一有闭式解的整体性判据：曲率、力的量级、压强传递三个环节任一环节出错，上式就不成立。本单复核 m277 合入的 CSF（Continuum Surface Force）表面张力模型，通过三层独立判据（瞬时曲率/切割面力恒等式/动力学压强平衡）量化验证精度。

| 参数 | 值 | 说明 |
|---|---|---|
| 液滴半径 R | 0.0200 m | 静止自由液滴 |
| 表面张力系数 σ | 7.2 N/m | 10× 水，压缩毛细时间便于在步数预算内平衡 |
| 参考密度 ρ₀ | 1000 kg/m³ | 弱可压 Tait EOS，γ = 7 |
| 声速 c₀ | 20 m/s | Mach ≪ 0.1 |
| 粘度 ν | 0.01 m²/s | 层流正则化 Laplacian |
| 重力 | 0.0 | 关闭，纯毛细平衡 |
| 晶格 | 六角密排 / 方晶格 | 瞬时诊断用六角，部分回归测试用方晶格 |
| 解析压差 σ/R | **360.0 Pa** | 基准量 |
| 解析曲率 1/R | **50.0 1/m** | 基准量 |
| 切割面力 2σ | **14.4 N/m** | 第三基准 |
| 毛细时间 t_σ | 0.0333 s | 动力学观测窗口 |
| 毛细速度 √(σ/ρR) | 0.600 m/s | 伪流归一化尺度 |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 验证策略

新增 `benchmarks/laplace_law/run.py`（自包含脚本），复用生产代码路径 `tensorsph.droplet_impact.rhs` 与 `tensorsph.surface_tension.*`，不改任何 `src/` 文件（纯验证单）。

**三层独立判据**：

1. **瞬时诊断**（一次求值，无时间推进）：CSF 管线逐环节拆开打分 —— 颜色函数 `c` → 梯度 `∇c` → 法向 `n` → 曲率 `κ` → 表面 delta 函数 `δ_s=|∇c|` → 加速度；
2. **切割面力恒等式**（积分判据）：对 x>0 半滴求和 `Σ m_i a_st,ix`，解析值恰为 `-2σ`（每单位展向深度）。该量只依赖力的量级，与压强场无关，因此能把「力量级错」与「压强传不上去」分开归因；
3. **动力学**：以 `stable_dt()` 定步长推进至 t ≈ 1 t_σ，用 Tait EOS 反算压强，取 `p_center − p(0.8–0.95R)` 与 σ/R 比对。

### 2.2 分辨率扫描

- 瞬时诊断：dx = 1.0/1.5/2.0/3.0 mm（N = 1450/642/362/161）
- 动力学松弛：dx = 1.5/2.0/2.5 mm（N = 642/362/228），步数 380–900
- 单点验证：dx = 4.0 mm（N = 88），380 步

### 2.3 后续修复（m3265）

原验证发现测试基础设施两项欠账：
- 松弛时间不足（t/t_σ < 0.5）→ 增加步数至 t/t_σ > 0.5
- 方晶格回归测试期望值 0.79 与实际 0.71 不符 → 修正为 0.71±0.08

### 2.4 工具链

PyTorch 2D 弱可压 SPH（CPU）、pytest、matplotlib。全部数字由 JSON 工件程序化提取。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 根因链

1. **颜色函数非界面函数**：`c` 由邻居数比构造，界面层仅 1 粒子厚，`∇c` 既非单峰也无固定尺度。
2. **δ_s 不归一**：`∫δ_s dS = 1` 是 CSF 成立的前提，实测偏差导致力的量级依赖分辨率。
3. **曲率噪声**：`κ = -∇·n` 在薄界面上放大 25–44%，法向与径向对齐在 m3265 后改善但仍非精确。
4. **超压无处安放**：弱可压 Tait 要表现 σ/R 需 ~0.09% 密度压缩，而求和密度在自由表面附近的本底噪声同阶，导致压强场无法可靠建立 Laplace 过压。

### 5.2 晶格依赖性

- 六角晶格（6 近邻）：力幅恢复 107–112%
- 方晶格（4 近邻）：力幅仅恢复 71%（截断误差更大）
- 回归测试须区分晶格类型，不可混用期望值

### 5.3 适用范围

- 本验证只覆盖**单相** CSF；多相（真实颜色函数）不在当前实现范围
- σ 取 10× 水、c₀ = 20 m/s 为无量纲化选择，判据形式与之无关，但绝对数值不可直接与真实水算例对比
- 动力学仅推进到 t/t_σ ≈ 1.3；更长窗口可能让伪流衰减但不会让 Δp 从 0 跳到 360 Pa（机制问题）

### 5.4 修复配方（后续 P0，本单未实施）

- Adami et al. (2012) 式压强偏置：`p0 = σ/R` 迭代自洽
- Shepard/MLS 归一化的连续性方程或 δ-SPH 密度扩散
- 加权最小二乘/抛物线拟合替代 `-∇·n` 直接离散
- 验收门槛：κ、F_cut、Δp 三项均 <15%
