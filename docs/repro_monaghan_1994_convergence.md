## 1. 问题：4.38 % 到底是「没收敛」还是「收敛到别处」

已合并的证据束（`docs/repro_monaghan_1994.md`）给出的阶梯是非单调的：
对唯一通过结构审计的参考表（crosscheck），MAE/幅值 = 4.67 %（dx=4 cm）→ 1.65 %（2 cm）→ 4.38 %（1 cm）。
合并时的对抗审计（`docs/audit_repro_monaghan1994_m16936.md` F2）指出这是 **偏置过零**，
并留下一句未经分解的推断：「残余是分辨率无关的，因此不能归因于离散误差」。

这句话跳过了工件本身可以判定的分解：

```
delta(tau, dx) = bias(dx) + scatter(tau, dx)
```

* `bias` 是一次常数配准（空间平移 / 时间滞后）能解释的部分；
* `scatter` 是扣掉常数后剩下的形状差。

若 `scatter` 随加密下降而 `bias` 收敛到非零极限 → 形状在收敛，剩下的是系统性偏移（配准或缺失物理）；
若两者都不降 → 该算例在这三级分辨率上**根本不在渐近区**，4.38 % 既不是求解器精度的上界，也不该读成不收敛。

## 2. 方法（判据先于数字：`PROTOCOL` 已固定在脚本常量里）

* 窗口 τ∈[0.5, 3.0]、161 个采样点、参考表 = crosscheck（唯一通过结构审计的那张）；
* 分辨率阶梯 dx = 4 cm, 2 cm, 1 cm，细化比 2；
* 观测阶 `p = log2(q_coarse / q_fine)`，逐段报，不强行拟合单一 p；
* 配准模型：`M1` 常数空间平移 δz（MAE 最优解 = 残差中位数，闭式）；`M2` 时间滞后 δτ（参考表在 τ 方向平移，窗口按 |δτ| 内缩以免端点钳制）；
* **留出规则**：只在最粗一级（dx = 4 cm）拟合一个参数，**原样**加到 2 cm / 1 cm 上，不重拟合；
* 判据 C1–C4 见 §5，全部在跑数之前写定。

## 3. 结果

### 3.1 分解表

| dx [cm] | 粒子数 | bias (Z/a) | scatter (mean abs) | MAE (Z/a) | MAE/幅值 | max abs | 扣常数后 max abs |
|---|---|---|---|---|---|---|---|
| 4 | 50 | -0.125 | 0.0327 | 0.125 | 4.67 % | 0.210 | 0.091 |
| 2 | 200 | +0.032 | 0.0315 | 0.044 | 1.65 % | 0.089 | 0.110 |
| 1 | 800 | +0.115 | 0.0331 | 0.117 | 4.38 % | 0.165 | 0.160 |

幅值（窗口内参考最大值）= 2.670（Z/a）。

读法：**scatter 三级几乎不动**（0.0327、0.0315、0.0331，相对差 < 5 %），而 bias 从 -0.125 跳到 +0.032 再到 +0.115。MAE 几乎完全由 |bias| 决定 —— 这正是 F2 说的「过零」：dx = 2 cm 的 1.65 % 不是精度更好，是偏置恰好落在零点附近。

### 3.2 收敛阶（逐段，不拟合单一 p）

| 量 | 4→2 cm | 2→1 cm |
|---|---|---|
| scatter 观测阶 | +0.05 | -0.07 |
| biases 观测阶（按幅值） | +1.96 | -1.84 |

scatter 的平均观测阶 p_scatter = -0.01；偏置的平均观测阶 +0.06 因幅值方向而无意义，故**不给** Richardson 外推极限（脚本按判据拒绝外推）。

### 3.3 留出配准检验：一个参数能不能解释全部三级

在最粗一级拟合：δz = -0.119（Z/a），δτ = +0.110（τ）。把这两个数**原样**应用到三级：

| dx [cm] | M0 无配准 MAE/幅值 | M1 空间平移后 | M2 时间滞后后 |
|---|---|---|---|
| 4 | 4.67 % | 9.13 % | 1.26 % |
| 2 | 1.65 % | 3.27 % | 5.70 % |
| 1 | 4.38 % | 1.19 % | 8.79 % |

最粗一级当然被拟合改善（M1 定义即最小化 MAE），但**留出**的两级里，M1 最差 3.27 %、M2 最差 8.79 %。
也就是说：一个在粗网格上定出来的配准参数，不能在细网格上把误差压到论文级 3 % 线以下。
这与 §3.1 是同一件事的两种说法 —— 因为**粗网格要求的平移与细网格要求的平移方向相反**（逐级内样本拟合值：-0.119、+0.029、+0.125），单一常数配准在原理上就不可能同时满足三级。

## 3.4 被测量的定义本身：换一个「前沿读数」，结论差多少

上面的 |bias| 起伏不是纯求解器属性：被判级的量是 `front_position` = 全部粒子 `x` 的 **max**。
本轮把估计器探针补齐到 dx = 1 cm（上一轮只跑到 2 cm，1 cm 是上一轮的缺口），
水深读数目前覆盖 dx = 2 cm, 4 cm 两级（1 cm 级因本地容量纪律与集群排队 536 位未跑，登记为缺口，不外推）。
并新增一条**用物理单位陈述**的读数（不计粒子数，计水深）：前沿 = 宽度 dx 的列中，
水深（列内粒子数 × dx，二维下每粒子携带 dx² 面积）首次达到阈值 h 的**最远列**，
h ∈ {2 cm, 4 cm, 8 cm}。

| 读数 | 最细级 MAE/幅值 | 最细级 bias (Z/a) | 阶梯非增？ |
|---|---|---|---|
| `depth_5%H` | 1.08 % | -0.005 | 是 |
| `p995` | 1.10 % | +0.002 | 是 |
| `p99` | 1.41 % | -0.034 | 是 |
| `x_max` | 1.65 % | +0.032 | 是 |
| `depth_10%H` | 4.98 % | -0.133 | 是 |
| `p95` | 11.26 % | -0.301 | 是 |
| `depth_20%H` | 19.95 % | -0.533 | 是 |

**同一个算例、同一份轨迹**，最细级误差在 1.08 % – 19.95 % 之间移动（差 18.5 倍）。因此本算例任何「误差 = X %」的表述**必须带读数的名字**，否则 X 可以被读数选择移动数倍 —— 这正是把「验证欠账」补上后最该记住的一条。

另有对照：`x_max` 是否被单颗飞溅粒子劫持？上一轮审计在 4 cm / 2 cm 上测得「零飞溅」并据此证伪该假设；补到 1 cm 后发现 3 个输出时刻存在 1 颗领先 99.5 % 分位 > 2dx 的孤立粒子，其 τ = 3.26–3.37，**全部落在判级窗口 [0.5, 3.0] 之外**（窗口已闭合），故不影响被判级的数字，但足以说明上一轮「零飞溅」的外推超出了它实际覆盖的层级。

## 4. 结论（按判据逐条，机读字段在工件 `verdict` 下）

* **C1_offset_survives_refinement** → `not supported`。判据：|bias_limit| > 0.10 Z/a (2x the 0.05 claimed uncertainty of the independent transcription)；实测：`NaN`
* **C2_scatter_converges** → `not supported`。判据：scatter (mean |delta - bias|) strictly decreasing and the observed order p = log2(q_coarse/q_fine) >= 0.7 on both increments；实测：`{"orders": [0.05408445190231645, -0.070011400104601], "mean_order": -0.007963474101142273, "monotone": false}`
* **C3_single_shift_insufficient** → `supported`。判据：after the coarse-fitted shift, no fine case reaches MAE/amplitude < 0.03 (the paper-level 3 % line)；实测：`{"M1_worst_fine": 0.032665710604491964, "M2_worst_fine": 0.08788063997997829}`
* **C4_temporal_vs_spatial** → `spatial`。判据：whichever of M1/M2 gives the smaller out-of-sample MAE/amplitude on the two finer cases, by more than 0.005 absolute；实测：`{"M1": 0.032665710604491964, "M2": 0.08788063997997829, "advantage": 0.055214929375486325}`

**沉淀下来的一句话（按读数分开说，不许混着说）**：

* 对**被判级的 `x_max` 读数**：残差 = 偏置 + 散布，**加密对两者都不起作用** —— scatter 恒定在 0.033–0.033 Z/a，偏置在 -0.125…+0.115 Z/a 之间跳。所以（a）4.38 % 不是求解器精度的上界；（b）把非单调阶梯读成「求解器不收敛」是错的；（c）把它读成「收敛到 4.38 %」同样错 —— 这三级的 `x_max` 上不存在渐近收敛的证据。
* 对**阶梯单调的读数**（`depth_10%H`, `depth_20%H`, `depth_5%H`, `p95`, `p99`, `p995`, `x_max`）：阶梯随加密下降，说明求解器在**这些读数下**是在收敛的；即「加密无用」是 max 估计器的属性，不是求解器的属性。最细一级仍有数倍差距，是因为各读数量的不是同一个几何量（楔形前沿的尖端 vs 主体），不是同一读数在收敛。
* 因此本算例对精度的判别力，在拿到论文原文或更细一级（dx = 0.005，预计 ~1.2 h 单核）之前，只能表述为「读数 + 误差」成对给出；单说一个百分数会被读数选择移动数倍（§3.4）。

## 5. 注意点与局限

* **只有三个成员**：细化比 2 的阶梯给两段观测阶，不足以同时定阶与定极限；`PROTOCOL` 因此明确拒绝在偏置变号时外推 Richardson（工件里 `richardson_bias_limit` 为 null）。
* **单参数留出检验的自由度很低**：M1/M2 各只有一个自由度，能做的是「能否被一个常数解释」，不能反证「存在某个更复杂的配准」。
* **参考表本身不可信到 ±0.05 以下**：两张数字化的分歧是 0.851 Z/a（17× 声明不确定度），scatter 0.033 已经在声明不确定度之内 —— 也就是说，**本算例的残差已接近参考侧的分辨极限**，这与「参考侧是误差地板来源」的既有判断一致，但本文没有、也无法判定哪一张数字化更接近 1952 原文。
* **读数敏感性已量化但没有唯一正确答案**：`x_max`、分位数与水深阈值读数给出的最细级误差相差数倍（§3.4）。水深阈值读数是**物理陈述**、不随粒子数变，但它引入了一个阈值 h 的自由度；本文件不宣称哪个读数「正确」，只宣称**任何单一数字都不是该算例的精度**。
* **渐近区仍在分辨率之外**：dx = 0.005 一级（单核约 1 h）未跑，故「不存在渐近收敛证据」只对 1–4 cm 三级成立，不外推。
* 本文是**诊断**工件：不改 gate、不改 `results/summary.json`、不改 `src/`。
