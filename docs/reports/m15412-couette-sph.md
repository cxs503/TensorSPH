# CASE-COUETTE-SPH: 平面库埃特流（滑移壁驱动）SPH 解析解对标

**算例锚点**：CASE-COUETTE-SPH · **仓库**：TensorSPH · **分支**：`agent/m15412` · **任务**：m15412

**裁决**：`FAIL` （判据阈值预先声明于 `benchmarks/couette/DESIGN.md`）

未达标项：ladder-r16: gate 'steady_drift' missed

## ① 问题与参考解出处

平面库埃特流：两平行壁之间充满不可压流体，下壁静止、上壁以 U 沿切向匀速滑动，通道水平方向周期。定常不可压 Navier–Stokes 方程在 no-slip 条件下退化为 d²u/dy² = 0，解析解为线性剖面

> u(y) = U y / H,  du/dy = U / H,  tau = rho nu U / H,  Q = U H / 2

**参考解出处**：u(y) = U y/H, du/dy = U/H, tau = rho nu U/H, Q = U H/2 -- Batchelor (1967) An Introduction to Fluid Dynamics, CUP, section 4.2 (steady unidirectional flow between parallel plates, one plate moving); identical closed form is the Ls->0 limit of the Navier-slip Couette anchor in TensorLBM/benchmarks/ice_lid_navier_slip.py。

该解析解无自由参数（U、H、nu 全部是输入），因此不存在把答案调准的空间；本算例检验的是 TensorSPH 的**切向移动壁 + no-slip 混合（wall_friction）**这条边界条件通路，而不是粘性算子（后者已由 `benchmarks/poiseuille` 用曲率法单独度量）。

## ② 方法与实现

* 求解器：TensorSPH 现有 2-D 弱可压 SPH 核心 `tensorsph.droplet_impact.rhs`（Tait 状态方程、求和密度、对称压力梯度、Morris 型粘性、Adami 壁面压力外推）。
* **没有新增物理**：上壁速度通过 `rhs(..., wall_vel=...)` 传入——这是`wave_flume` 造波板已经在用的移动壁输入，此处把它的方向由法向改成切向；`wall_friction = 1` 使流-壁粘性作用按壁自身速度而非静止速度计算，即 no-slip。
* 初值静止（上壁脉冲启动），积分到稳态；参考解是闭式，在同一行心取值，不经过任何拟合（拟合只用于线性度诊断与滑移长度）。
* 一段式复现命令见文末 `repro_cmd`；所有数值由 `results.json` 程序化注入本报告。

## ⑥ 失败模式、局限与工件

* **有限滑移长度**：SPH 壁是力边界而非速度 Dirichlet 边界，等效无滑移平面落在壁粒子层外若干分之一 dx 处；这使近壁行剖面系统性偏高，报告用 `滑移长/dx` 字段单独度量并在 4.2 中列出，不混进内部 L2。
* **稳态判据的相位噪声**：弱可压格式不含人工粘性，声学振铃不被耗散，通量在 ±数个百分点内持续脉动；稳态漂移用平均窗两半的均值差而非两点差计算，两点差同时作为 `steady_drift_two_samples` 记录在 results.json 里以备对照。
* **适用边界**：本文验证的是定常、层流、平面、单向剪切；不含转捩、不含离心（Taylor–Couette）效应，也不验证三维性。
* **工件**：`runs/couette_full/results.json`（含每个 case 的完整参数、逐行剖面、时间序列、判定）；`runs/couette_full/couette_*.png`（剖面/收敛/场图/摩擦序列）；设计预声明 `benchmarks/couette/DESIGN.md`；测试 `tests/test_couette.py`。
