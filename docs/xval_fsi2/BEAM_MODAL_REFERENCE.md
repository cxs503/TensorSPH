# FSI2 梁的模态基准与 lock-in 一致性审计

**锚点**：`XVAL-SPH-FSI2-BENCHMARK-AND-FORCE-FROM-FLUID`　**仓**：TensorSPH　**域**：SPH / FSI

> 本文件由 `benchmarks/xval_fsi2/beam_modal_reference.py` 从计算序列程序化生成，表内数字零手抄（工件 `artifacts/xval_fsi2/beam_modal.json`）。

## ① 案例与动机

FSI2 的工程量是**梁尖振幅**，而振幅由「涡脱落周期」与「梁自身周期」是否 lock-in 决定。本仓此前只验证过梁的**静**性质（`EI`、尖端静挠度，V3/V4），**动**性质（模态频率）从未对任何解析基准复核——而判据 `verdict_body_force_transient.physical_admissibility` 只用**流体侧** Strouhal 带 `D/(St·U_mean)` 作可判定性筛检，没有任何独立第二条标尺。

## ② 怎么做

1. **离散模态**：对出厂离散杆能量 `beam_energy` 在直位形求 Hessian，配 `beam_nodal_mass` 对角质量，节点 0 夹持，解广义特征问题 `H v = ω² M v`（无时间推进、无阻尼、无拟合）。
2. **解析基准**：Euler-Bernoulli 悬臂 `f_n = β_n²/(2π)·sqrt(EI/(ρA L⁴))`，`β₁..₄ = 1.8751, 4.6941, 7.8548, 10.9955`。
3. **时间推进交叉检验**：用**同一** `beam_advance`（耦合驱动实际子步进的例程）以第一阶离散特征向量为初值做自由衰减，`dt = 0.3·2/ω_max` 由模型自身最高模态定出，测过零周期，与第 1 步的谱对照。
4. **lock-in 审计**：流体侧 `D/(St·U_mean)` 与结构侧 `T_c = 1/f_c`（含平板附加质量 `ρ_f π (t/2)²`）相比，判是否重叠；再对两份已归档的耦合运行用这把尺子复核（不改其原判）。

## ⑤ 注意点 / 局限

1. **有限夹持刚度是系统性偏差的来源**：离散链把固定端表示为第一个铰的有限转动弹簧 `k_r = EI/l₀`，只有 `l₀→0` 时才趋于刚接，故有限 n 的模型**必然偏软**、误差随 n 单调收缩——这正是阶梯要断言的事，不是巧合。
2. **高阶模态不收敛**：n = 30 时 f₃/f₄ 相对误差 -3.9 % / -21.2 %，短波长模态在该 n 下不可信，只用作存在性检查；判定只用 f₁。
3. **附加质量取无界流体平板值** `ρ_f π b²`，FSSI2 通道的内壁修正 ~1.0024（可忽略）；黏性附加质量与尾流分离附加质量未计入——它们只会**降低** f_c，故本文件给出的 T_c 是偏**保守**（偏短）的一侧。
4. **本文件只提出标尺，不改变任何既有判定**：判据阈值、判据逻辑、归档运行的 `admissible` 全部保持原值（见 ③ 末表 `原判 admissible` 列）。

## ⑥ 误差判定（逐项 vs 基准，显式回答是否 <3 % / <5 % / <15 %）

| 判定项 | 基准 | 误差 | <3 % | <5 % | <15 % |
|---|---|---|---|---|---|
| 离散 f₁ @ n=30（出厂） | Euler-Bernoulli | -3.38 % | ❌ | ✅ | ✅ |
| 离散 f₁ @ n=50（最细阶梯） | Euler-Bernoulli | -2.02 % | ✅ | ✅ | ✅ |
| 自由衰减周期 vs 特征值谱 | 同一模型 | +0.000 % | ✅ | ✅ | ✅ |
| lock-in 一致性（脱落周期/T_c） | 1.0 | +7.96 % | ❌ | ❌ | ✅ |

**结论（honest）**：
* 出厂 n=30 的梁**一阶模态频率比解析解低 -3.38 %**，在 5 % 目标内、不在 3 % 内；最细阶梯 n=50 收敛到 -2.02 %，误差随 n 单调收缩 → 模型对，离散误差可量化。
* 自由衰减与特征值谱吻合到 +0.000 %，说明耦合驱动实际积分的动力学就是这份谱——模态结论可用于解释运行。
* **lock-in 审计：预声明假设「判据的 Strouhal 带是错的、会把结构共振当成 ringing 拒掉」被证伪**。相似性修正算例把 `E ∝ U²` 一并缩放了 (E = 2.24e+05 Pa)，结构周期 T_c = 2.553 s 正好落在流体带 [1.667, 3.846] s 内，两条独立标尺只差 7.96 % → 判据带是**被独立复核过**的，不需要改。
* **反事实对照**：若只把入口流速降到 0.2 m/s 而**不同时**缩放 E（即 'FSI2 shipped (E=4 MPa, U=0.2)' 行，E = 4e+06 Pa），T_c = 0.604 s 与流体带 [1.667, 3.846] s **不重叠**（比值 4.56），lock-in 丧失——此时判据的 Strouhal 带确实会把结构共振误判成 ringing。本仓`fsi2_similarity.similarity_corrected_case` 已经缩放 E，故该缺陷**未落到实算例上**；这条记录在案的用途是：任何绕过相似性修正的变流速运行都不可用该判据判 reading。
* 归档的两份耦合运行实测周期分别偏离 T_c 0.078×、0.125× → 既不在流体带也不在 lock-in 带，**ringing 的结论被第二条独立标尺加固**，其 WITHHELD 维持不变。
