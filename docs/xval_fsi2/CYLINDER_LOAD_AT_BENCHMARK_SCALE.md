## ① 案例介绍

本仓对「流体→圆柱载荷」的所有静态审计（`CYLINDER_BODY_FORCE.md`、
`cylinder_load_audit.py`）都在 **SPHinXsys `test_2d_fsi2` 的放大几何**上做：
半径 `R = 0.5 m`，`dx ≤ 0.04 m` ⇒ `h/R ≤ 0.10`。而**耦合瞬态**用的是 Turek–Hron
原尺度：`D = 0.1 m` ⇒ `R = 0.05 m`，`dx = 0.02 m` ⇒ **`h/R = 0.52`，支持域
`2h = 0.052 m` 大于物体半径**。此时一个表面粒子的邻居集已经不是半空间，而是**绕着
物体一圈**，核加权平均可能把驻点侧与背压侧混在一起。这个区间此前**没有任何审计覆盖**，
而恰恰是耦合驱动报出 `Cd_mean = 0.052`（基准 3.2，见 `VIV_PERIODIC_VERDICT.md`）的配置。

几何/参数（全部程序化生成，零手抄）：

| 项 | 取值 |
|---|---|
| 物体 | 圆，`R ∈ {0.05, 0.5}` m，圆心 (0,0) |
| 表面站位 | `n_circ = max(ceil(2πR/dx), 8)`，面积元 `trib = 2πR/n_circ`（驱动同款规则） |
| 流体 | 格点，间距 `dx ∈ {0.04,0.02,0.01,0.005}` m，剔除 `|x|<R+0.5dx`（`build_fluid_particles` 同款清空规则） |
| 压力场 | 解析给定 `p = 1 + c·x`，`c = (1, −1)`（无求解器、无重力，同 fsi2） |
| 参照 | 散度定理 `F = −∮ p n dl = −cA`，`A = πR²` |
| 核 / 光滑长度 | 求解器自带 cubic-spline，`h = 1.3dx`，支持 `2h` |
| 两条臂 | `kernel` = `boundary_pressure_from_fluid`（核加权平均，驱动默认）；`fit` = `boundary_pressure_from_fluid_linear_exact`（加权平面拟合，线性场精确） |

## ② 怎么做的

1. 表面站位、法向、面积元按驱动的 `cylinder_surface_geometry` 规则生成；
   流体格点按驱动的清空规则剔除（这是「算子看到的邻居」而不是理想半空间）。
2. 邻居对用 `cell_linked_pairs(cat(fluid, wall), 2h)`（与驱动同一函数）。
3. 两条臂各自从同一个解析压力场外推壁面压力，再 `boundary_force_from_pressure`
   积分成单位厚度力 `F = −p n trib`，与 `−cA` 逐分量比较。
4. 三个扫描：
   * **regime**：`R = 0.05`（耦合尺度）与 `R = 0.5`（SPHinXsys 尺度，对照）各 4 档 dx；
   * **stations**：`R = 0.05, dx = 0.02` 固定，`n_circ` 8→128（分辨**求积误差**与**支持域误差**）；
   * 同时记录覆盖度与「站位到最近流体粒子」的间距分布（干区普查，`X4_DRY_BODY_DEFECT.md` 的签名）。

## ⑤ 注意点（含本轮**证伪**的假设）

1. **本轮否定了「载荷臂解释 `Cd −98 %`」这条假设。** 在耦合配置下 kernel 臂的系统偏差是
   **+31.1 %（向上）**，不是向下；方向相反、量级差 4 倍，无法产生 60 倍的亏缺。
   下一步必须指向别处：求解器压力场的**动压含量**，或系数的**参照/归一化链**
   （`u_mean`、`D`、以及 `3.2 / 0.96 / 0.22` 这个三元组的出处——`PARAMETER_TABLE_INTEGRITY.md`
   已把「哪一列才是论文的 FSI2」记作 `WITHHELD`，本轮**没有**获得 PDF，不作判定）。
2. **干区缺陷（X4）在耦合配置不复发**：覆盖度恒为 1.00，最近流体粒子恰好 `0.5 dx`
    （= `R+0.5dx` 清空规则的几何必然），所以 `X4_DRY_BODY_DEFECT.md` 的「静默零载荷」
    **不是**耦合配置的问题。
3. **默认臂在这里不合规格**：`case.cylinder_load_arm` 默认 `kernel`，在 `h/R = 0.52`
   下偏差 +31 %，已越过 owner 的 15 % 线；同一份邻居数据上 `fit` 臂是**机器零**。
   耦合瞬态应以 `cylinder_load_arm="fit"` 出系数（该开关已存在，本轮未改默认值——
   改默认会移动全部在账工件的数字，属于需要单独一单的口径变更）。
4. **适用范围**：静态、解析线性压力场、单层表面站位、刚性圆；不含时间推进、
   不含 `h/R > 1.04`（支持域覆盖整个物体时两条臂都会退化）、不含真实脱体流场。
   因此本轮的 +31.1 % 是**线性场下的几何偏置**，不等于真实流场中的 Cd 偏置。
5. **为什么 `2h/R > 1` 还没炸**：误差随 `h/R` 平滑增长（1.04→48 %，0.52→31 %，
   0.26→16 %，0.13→7.9 %），近似 ∝ `h/R`，说明仍是「一侧支撑被截断」的 O(h/R) 机制在
   起作用，只是系数被整圈邻居放大；没有任何符号反转或非单调跳变。

## ⑥ 误差判定（逐项 vs 解析 `−cA`，显式回答「是否 <3 %」）

| 判定项 | 基准 | 实测 | <3 %？ | <15 %？ |
|---|---|---|---|---|
| `fit` 臂，耦合配置（R=0.05, dx=0.02） | `−cA`（解析） | 5.9e−5 % | **是** | 是 |
| `fit` 臂，全 8 档（h/R 0.013…1.04） | `−cA` | ≤ 2.9e−4 % | **是** | 是 |
| `kernel` 臂，耦合配置 | `−cA` | **+31.13 %** | **否** | **否** |
| `kernel` 臂，SPHinXsys 尺度（dx=0.04, h/R=0.104） | `−cA` | +7.27 % | 否 | 是 |
| `kernel` 臂，dx=0.005（h/R=0.13） | `−cA` | +7.90 % | 否 | 是 |
| 求积收敛（n_circ 16→128，同 h） | 自比 | 散布 < 0.005 % | **是** | 是 |
| 覆盖度 / 干站位 | 1.0 / 0 | 1.00 / 0 | 是 | 是 |
| 「载荷臂造成 Cd −98 %」 | 符号与量级 | **符号相反**（+31 %） | — | **假设被否定** |

结论（honest）：**耦合尺度下 `fit` 臂达标（≈0 %），默认 `kernel` 臂不达标（+31 %）**；
本轮不给 `Cd` 精度判定，而是把一个**错误归因**排除掉了，并把耦合系数的下一步指向
压力场/归一化链。
