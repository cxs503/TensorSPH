> 锚点 `XVAL-SPH-FSI2-BENCHMARK-AND-FORCE-FROM-FLUID`（Xiangyu-Hu/SPHinXsys `test_2d_fsi2` + `FSI::ForceFromFluid`）· 仓 TensorSPH · 域 SPH / FSI
> 本文件由 `benchmarks/xval_fsi2/make_doc_unsteady.py` 从 `artifacts/xval_fsi2/unsteady_farfield.json` 程序化生成。
> 模块 `src/tensorsph/farfield_force.py` · 驱动 `benchmarks/xval_fsi2/unsteady_farfield_audit.py` · 守护 `tests/test_unsteady_farfield.py`

## ① 案例介绍

上一轮（`FARFIELD_FORCE_CHANNEL.md`）给本仓补了第二条独立的载荷通道：**控制体/远场**恒等式，它不碰物体表面，因此与 `pair`/`panel` 两条近场臂的误差机制无关。那一轮只实现了**定常**形式，并把累积项 `-d/dt ∫_CV ρu dV` 明确挂账（2-D 下它的均匀部分随 `R²` 增长，必须与压力通量一起离散，否则比不实现更糟）。

本轮的物理问题：**振荡载荷**（VIV、波浪中附加质量/惯性力、振荡来流）能不能用同一条通道测？如果能，误差多大、在什么半径上能过 owner 的 15 % 门限与 3 % 目标？

算例是纯解析的（不跑求解器，先把算子本身钉死）：

- 几何：固定圆柱 `r ≤ a`，圆心在原点；控制面为同心圆 `r = R`，流体粒子铺在 `a < r < R + Δx` 的规则格点上（远场通道只吃粒子的速度/压力，物体的唯一入口是它的**截面积** `A_b`）。
- 流场：振荡来流 `U(t) = U₀ cos(Ωt)` 绕圆柱的势流，`φ = U(t)(r + a²/r)cosθ`，速度取空间导数、压力取**非定常**伯努利`p = -ρ ∂φ/∂t - ρ|u|²/2 + ρU²/2`，于是 `p → -ρ u̇ x` 在远场（加速均匀流所需的压力梯度）。
- 解析载荷：`F_x = 2ρπa² u̇`（`C_M = 2`：排水质量 `1` + 附加质量 `C_a = 1`），`F_y = 0`。

| 参数 | 值 | 说明 |
|---|---|---|
| 圆柱半径 `a` | 0.500 | 直径 `D = 1.00` |
| 流体密度 `ρ` | 1.0 | 无量纲 |
| 来流幅值 `U₀` | 1.00 | 沿 `+x` |
| 圆频率 `Ω` | 4.00 | 周期 `T = 1.571` |
| Keulegan-Carpenter `U₀/(Ωa)` | 0.500 | 势流有效区（KC 小） |
| 相位采样 `N_t` | 32 | 每周期；`d/dt` 用二阶中心差分（周期回绕） |
| `d/dt` 截断（幅值偏差） | 0.1606 % | `1 - sin(ΩΔt/2)/(ΩΔt/2)`，远低于 3 % 门限 |
| 解析 `F_x` 幅值 | 6.2832 | `2ρπa²U₀Ω` |
| 扫描 | `R/a ∈ [3.0, 5.0, 10.0]`, `Δx/a ∈ [0.025, 0.05, 0.1]` | 共 7 个配置 |

## ② 怎么做的

先把 `-d/dt ∫ρu dV` 直接实现的坑说清楚：2-D 里均匀流的动量是 `ρ πR² u`，加速均匀流对应的均匀压力是 `p_f = -ρ a_f·(x-c)`，其面积分为 `ρ πR² a_f`。两项都是 `R²` 量级，而答案只是 `ρ A_b a_f` 量级 —— 直接写恒等式等于用两个大数相减，相对误差被 `R²/A_b` 放大。**离散形式**的正确解法是标准摄动分解（CV 版的 Froude-Krylov + 附加质量分解）：

```
u = u_f(t) + u' ,   p = p_f(t,x) + p' ,   p_f = -ρ a_f·(x - c)

F_on_body = + ρ A_b a_f                      （排水质量 / Froude-Krylov）
            - d/dt ∫_CV ρ u' dV              （流体摄动动量变化率）
            - ∮_S [ ρ u (u·n) + (p' - p_ref) n ] dS
            + ∮_S τ·n dS                     （调用方挂钩）
```

均匀部分的抵消是解析的：`-ρ A_fluid a_f + ρ πR² a_f = ρ A_b a_f`，其中 `A_fluid = πR² - A_b`。两个面积都用解析值，格点边界的锯齿不进这个抵消 —— 这是与「用采样体积近似 `A_fluid`」的关键差别（后者会把 `Δx/R` 的锯齿误差重新放大成 `R²` 量级）。

工具链：`tensorsph.farfield_force` 新增 `control_volume_force_unsteady`（摄动形式 + 可选未分裂对照臂）、`cv_momentum(..., frame_vel=)`（摄动动量积分）、`d_dt_periodic`（二阶中心差分，周期回绕）、`unsteady_potential_flow_cylinder`（振荡来流势流场，含非定常伯努利压力）。驱动 `benchmarks/xval_fsi2/unsteady_farfield_audit.py` 一次跑完四条臂、四个判据（U0 零场、D1 幅值/相位/交叉分量、D1 对照臂），全 float64。


## ③ 计算结果

### U0 —— 接线零场（无物体、加速均匀流）

流体整体随来流刚性平移，故 `u' = 0`、`p' = 0`：摄动形式里只剩两个均匀项，它们必须**恰好**抵消。这是唯一能抓住「漏掉 `ρπR²a_f` 面项」或「`A_fluid` 用采样面积」这类错接线的判据。

| R | Δx | 粒子数 | 面元覆盖 | 残差 / `ρR²U₀Ω` |
|---|---|---|---|---|
| 1.00 | 0.050 | 1322 | 1.000 | 1.21e-16 |
| 1.00 | 0.025 | 5056 | 1.000 | 2.78e-15 |
| 2.00 | 0.050 | 5204 | 1.000 | 1.39e-15 |
| 2.00 | 0.025 | 20394 | 1.000 | 7.49e-16 |

最坏残差 `2.78e-15`（门限 `1e-09`）→ **PASS**。注意：如果控制面上的面元没有全部填满（覆盖 < 1），零场会因为丢面元而假性失败（实测 `1.2e-1`），所以驱动把覆盖作为判据的一部分打印出来 —— 那是**积分域缺损**，不是物理。

| 分量 | 幅值 | `C_M` 份额 |
|---|---|---|
| 排水质量 `ρA_b a_f` | 3.1416 | 1.0000 |
| 累积项 `-d/dt∫ρu'dV` | 0.0000 | 0.0000 |
| 摄动压力通量 `-∮p'n dS` | 3.1416 | 1.0000 |

这张表是通道可用性的关键：惯性载荷被**干净地拆成**「排水质量（`C_M` 的 1）」与「附加质量（`C_a = 1`）」，后者由摄动项贡献。也就是说这条通道不仅能报力，还能报 `C_a` —— 对 VIV 的质量比与相位问题是直接可用的量。

### 判据结论

- D2 零场：`2.78e-15` < `1e-9` → **PASS**
- D1 幅值（`Δx/a ≤ 0.05` 全部 `R/a`）：最坏 `+0.002 %` → 3 % 目标 **PASS**，15 % owner 门限 **PASS**
- 交叉分量与相位：`1.21e-02 %` / `0.000°` → **PASS**
- D3（未分裂形式是障碍）：最坏 `+38.19 %`，随 `(Δx/a)(R/a)` 线性增长（图 3）→ **成立**

## ⑤ 注意点

1. **`frame_vel`/`frame_acc` 必须自洽**：`a_f` 是 `u_f` 的时间导数。传错（例如来流在加速却给 `a_f = 0`）不会报错，但结果会差 `ρA_b a_f` —— 这是摄动分解的固有契约，已在 docstring 里写明。

2. **控制面必须被面元填满**（`coverage = 1`）。零场腿显示：覆盖 0.75 时残差 `1.2e-1`（相对 `ρR²U₀Ω`）；这不是抵消失效，而是积分域缺损。驱动/守护都断言覆盖。

3. **`d/dt` 的阶**：一阶后差会把谐波幅值偏 `O(ΩΔt)`，在本算例 `N_t=32` 下约 3 %，足以吃掉整个误差预算，所以只提供二阶中心差分（周期回绕）。截断残留 `0.1606 %`。

4. **面元重构**：默认 `reconstruct="fit"`（线性精确的面元拟合）。换成原始平均（`mean`）只差到 `+0.090 %`，因为摄动场的面量本来就是 `O(1/r)`/`O(1/r²)` 的小量、没有平壁那种一阶残差。

5. **仅限无粘势流基准**：本算例验证的是**算子**，不是流体求解器。真实 SPH 场里的粘性通量走 `traction=` 挂钩（调用方给），未在此验证。

6. **半径方向没有收敛性要求**：答案与 `R` 无关（只要 `R > a`），这是恒等式的性质；误差随 `R` 只是面元数/覆盖率的问题。但**分解的份额**依赖 `R`：2-D 中摄动量的 `ln(R/a)` 类贡献会随半径迁移（把答案在「体积项」与「面项」之间挪），所以报「累积项占多少」时必须带 `R`。

8. **本算例里累积项的解析份额为零**：偶极型摄动速度场 `u' = -U(a²/r²)(cos2θ, sin2θ)` 的方位角积分恒为零，故 `∫_CV u' dV = 0`、`C_a` 全部由摄动压力通量承担（见分解表）。累积项的**算子**正确性由 `test_d_dt_is_second_order_on_a_harmonic`（二阶收敛）、`test_accumulation_operator_matches_analytic_derivative`（对解析 `2πρa²ln(R/a)ḟ`）与零场接线守护覆盖，但本算例**没有**让累积项承担非零份额 —— 读「累积项占比」一栏时要按此理解，不得据此外推它在运动物体/非对称控制体上的表现（第 7 条）。

7. **未覆盖**：物体在流中运动（振荡圆柱的附加质量）没有做；那条路的远场积分会出现 `ln(R/a)` 的分解依赖，虽则合力仍解析（`ρA_b a`），但要走另一套场生成器。稳态/时均以外的一般瞬态 SPH 场也仍未接（见下一轮）。


## ⑥ 误差判定

| 量 | 基准 | 最坏误差 | 是否 < 3 % |
|---|---|---|---|
| 惯性力幅值 `F_x`（摄动臂，Δx/a ≤ 0.05） | `2ρπa²U₀Ω` | +0.002 % | 是 |
| 惯性力幅值 `F_x`（全部 `Δx/a`） | 同上 | +0.006 % | 是 |
| `C_M` | 2（解析） | 见上表逐行 | 是 |
| 交叉分量 `F_y` | 0 | 1.21e-02 %（相对 `F_x` 幅值） | 是 |
| 相位滞后 | 0° | 0.000° | 是 |
| 零场残差（无物体） | 0 | 2.78e-15（相对 `ρR²U₀Ω`） | 是 |

**显式回答**：在 `Δx/a ≤ 0.05` 的全部半径上，惯性载荷幅值误差 `+0.002 %` **< 3 %**，因此远场通道现在可以承担振荡载荷的仲裁；`Δx/a = 0.1` 的最坏行为 `+0.006 %`（见上表），仍远优于两条近场臂在弯体上的 30–48 %。

诚实边界：以上全部对**解析势流场**成立。真实 SPH 瞬态场（有粘、有自由面、有粒子无序）上的表现**未测**（not_run），不得从本文件外推。
