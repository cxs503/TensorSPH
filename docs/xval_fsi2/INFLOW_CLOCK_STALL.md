# FSI2 的 Cd −98 % 归因：开边界入流时钟被「最慢粒子」钉死（不是载荷通道，也不是分辨率）

锚点 `XVAL-SPH-FSI2-BENCHMARK-AND-FORCE-FROM-FLUID` · 仓 TensorSPH · 域 SPH / FSI

## ① 案例介绍与要回答的问题

上一轮（m22030）在 `dx = 0.02` 的强耦合长时工件里读到 `Cd_mean = 0.052` vs Turek–Hron 3.2
（−98 %），并把原因**未加证据地**归给「载荷通道或体积力标度」，留下一条待办：
「先让 dx=0.02 的场有物理量级的 Cd，再谈周期窗口」。

本单不新增算例，只做**归因**：−98 % 出在流水线的哪一级？三个互斥候选，逐一用可复现的
证据判掉或留下：

| 候选 | 若成立的可观测后果 |
|---|---|
| **L** 载荷通道/标度（`F = −p n trib` 及其上游的壁面压力算子） | 解析压力场上算子就应当低 60 倍 |
| **R** 分辨率（`dx = 0.02` ⇒ `D/dx = 5`） | 刚性体也必须给出偏低的 Cd，且随 dx 收敛 |
| **F** 流场本身没建立（入口/出口边界处理） | 刚体上的**通流**就不存在：下游通量 ≪ 入口通量、体平均速度 ≪ `U_mean` |

基准几何/参数（`fsi2_similarity.similarity_corrected_case`，与 m22030 工件逐位相同）：
通道 2.5 × 0.41 m，D = 0.1 m 圆心 (0.2, 0.2)，梁 0.35 × 0.02 m，ρ = 1000 kg/m³，
`U_mean = 0.2 m/s`，ν = 2.0e-4 m²/s（Re = 100），`c0 = 5 m/s`（Mach 0.06），
`dt = max_courant·h/c0 = 1.04e-3 s`，力系数标度 `½ρU²D = 2 N/m`。

## ② 怎么做的

三道独立的证据，全部来自仓内既有代码路径（不改算子、不加自由参数）：

1. **算子门（判 L）**：用 `benchmarks/xval_fsi2/cylinder_load_audit.py::run_gate(dx)` 在
   `dx = 0.02 / 0.01` 的解析线性压力场上量算子本身。
2. **工件特征（判 R/F）**：读 m22030 工件 `docs/xval_fsi2/viv_dx002_aitken_admitted.json`
   自带的场量（`max_speed_window`）与入口峰值的关系。
3. **刚体前驱（判 F）**：新增 `benchmarks/xval_fsi2/rigid_cfd_precursor.py`，把**整个结构
   冻结**（圆柱 + 梁边界零速度、节点不推进），流体算子与生产路径完全一致
   （`case.fluid_config` 的 `rhs`、`body_force_from_fluid`、`_apply_open_boundaries`）。
   这样界面子迭代与杆件都不再是混淆变量，量到的就是「流体的那一半」。
   逐样本记录：进出口通量比、体平均速度、流体总质量、注入/删除粒子数、四个载荷臂。

**先声明判据（开工前写下，未观测结果后修改）**：

| 检查 | 合格带 | 依据 |
|---|---|---|
| `injected > 0` | — | 通流存在的最低条件 |
| 流体总质量漂移 | ≤ 1 % | 注入体积 = 删除体积 |
| `flux_ratio` = 下游 slab 通量 / 入口通量 | [0.8, 1.2] | 定常通流 |
| `bulk_speed / U_mean` | ≥ 0.5 | 「场建起来了」 |

## ③ 计算结果

### L：载荷通道无罪（解析门，`dx = 0.02`）

| 臂 | 分析解 | 相对误差 |
|---|---|---|
| A 解析场直接积分 `−p n trib` | `F = −∇p·A`，`A = πr²` | 0.00 % |
| B OSS 核平均壁面压力 | 同上 | **+38.50 %**（横向分量），x 分量 −0.08 % |
| C 平面拟合（`cylinder_load_axis` 生产臂） | 同上 | **0.00 %** |

`dx = 0.01` 时 B 降到 +18.6 %、C 仍为 0.00 %。**没有任何一条臂出现 60 倍的亏损**；
+38 % 是既有的 `+O(h/r)` 凸体过载（`CYLINDER_BODY_FORCE.md`）。⇒ 候选 L 被否掉。

### R：分辨率不是主因

m22030 工件自带 `max_speed_window = 0.29972`，而入口峰值 `U_max = 1.5 U_mean = 0.30`：
全域最大速度**等于入口峰值到第四位有效数字**。绕流（阻塞比 0.24）必然加速到 `> U_max`，
因此这个场里流体根本没有绕过圆柱加速——这不是「分辨率不够导致 Cd 偏低」的形状，
而是「流没有建立」的形状。⇒ 候选 R 不是主因。

### F：开边界入流时钟被钉死 —— 找到缺陷

`_apply_open_boundaries` 原来的注入判据是几何的：`min(fluid_x) > 1.5 dx` 时补一整列。
实测（`dx = 0.02`，初值 `min x = 0.01`，触发阈 `1.5 dx = 0.03`）：

* 400 步（t = 0.416 s）后 `min x = 0.00937` —— 几乎没动；
* 这些粒子在 `y ≈ 0.5 dx`，入口抛物型剖面在那里只有 `u = 0.0145 m/s`（`0.1 U_max`）；
  `y = 0` 的贴壁粒子甚至读到 `u_x = −0.0015 m/s`（负值）。
* 于是**最慢的贴壁粒子把入流时钟钉死**，而出口一直在删粒子。

刚体前驱 1200 步（t = 1.248 s，`dt = 1.04e-3`）实测：

| 量 | 修复前 | 修复后 | 判据 |
|---|---|---|---|
| 注入粒子数 (1200 步累计) | **0** | **240** | `>0` ✔ |
| 删除粒子数 | 26 | 234 | — |
| 流体总质量 [kg] | 1023.65 → 1013.25（**−1.02 %**） | 1023.65 → 1026.05（**+0.23 %**） | ≤1 % ✔ |
| 体平均速度 [m/s]（/`U_mean`） | 0.0382（0.19） | 0.4118（2.06） | ≥0.5 ✔（超上界，见⑤） |
| 下游/入口通量比 | 0.182 | 2.159 | [0.8,1.2] ✘ |
| `max|u|` [m/s] | 0.422 | 2.201 | — |
| 瞬时 `Cd` | −1.20 | +19.77 | — |
| 粒子数 | 2559 → 2533 | 2559 → 2565 | — |

修复前是「通流被抽干」：注入 0、出口删 26、质量掉 1 %、体平均速度只有 `0.19 U_mean`；
修复后注入与删除同量级（240 vs 234，差 2.6 %），质量守恒到 0.23 %。

### 修法（最小改动，`src/tensorsph/fsi2_turek_hron.py`）

把几何时钟换成**质量通量时钟**：

```python
state.inflow_deficit += case.inlet_u_mean() * dt   # 入口边界实际交付的体积（以米计）
if state.inflow_deficit >= dx:                     # 攒够一列
    state.inflow_deficit -= dx
    ...注入一列...
```

`FSI2State` 新增 `inflow_deficit: float = 0.0`；`_apply_open_boundaries` 增加可选
`dt` 形参（缺省用 `case.dt()`），两个调用点显式传入。通量时钟不可能被单个慢粒子钉死，
且注入量就是入口边界条件交付的量。

## ⑤ 注意点（坑与适用范围）

1. **修复后仍未收敛**：`flux_ratio = 2.16`、`bulk/U_mean = 2.06` 超出预声明带，`Cd` 在
   +19.8（t = 1.25 s）。质量是守恒的（注入 ≈ 删除），所以这是**启动瞬态**而非质量源/汇；
   1.25 s ≈ 5 个通道输运时间，不足以给出 `Cd` 的统计窗口。要判 Cd/St 必须跑长时。
2. **短跑 1200 步**是 120 s 本机限时下的取舍；`cj3899`（dx=0.02, 6000 步）与
   `cj3900`（dx=0.01, 12000 步）已递交，但它们用的是**修复前**的工作树快照，回来只能作
   「修复前」基线，不能当修复后结果。
3. 贴壁粒子被 `fluid_pos[:,1].clamp(0, H)` 夹在壁上、入口剖面在壁面取值 0，
   这是「慢粒子」的来源；本单没有动壁面处理（改动面太大），只保证它不会再钉死入流。
4. 归因结论对 `dx` 不敏感：缺陷在边界处理的逻辑里，与分辨率无关（`injected` 是整数计数）。

## ⑥ 误差判定（逐项，显式回答是否 <3 %）

| 量 | 基准 | 实测 | 相对误差 | <3 % |
|---|---|---|---|---|
| 载荷算子 C（平面拟合，`dx=0.02`） | `−∇p·A` | 同左 | 0.00 % | ✔ |
| 载荷算子 C（`dx=0.01`） | 同上 | 同上 | 0.00 % | ✔ |
| 载荷算子 B（OSS 核平均，`dx=0.02`） | 同上 | — | +38.50 % | ✘（既知 `+O(h/r)`，非本单引入） |
| 流体总质量（修复后，1200 步） | 初值 1023.65 kg | 1026.05 kg | +0.23 % | ✔ |
| 流体总质量（修复前，1200 步） | 初值 | 1013.25 kg | −1.02 % | ✔（但方向为流失） |
| `Cd_mean` vs Turek–Hron 3.2 | 3.2 | 未达统计窗口 | — | **不适用（未达窗口）** |
| `bulk_speed / U_mean` | 1.0 | 2.06 | +106 % | ✘（启动瞬态，见⑤.1） |

**锚点验收（<15 %）本单仍未达成**：本单把 −98 % 从「未知的载荷通道问题」定位为「已知的
开边界入流缺陷并修复」，`Cd` 的量级从 0.05 回到 O(10)（过量），但**没有**给出精度判定。
`WITHHELD` 不是 PASS。
