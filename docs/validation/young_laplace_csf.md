# TensorSPH 表面张力（CSF）Young–Laplace 定量复核

**任务**：m2302（自找活 tp-impl-8，platform 席）
**复核对象**：已合入的表面张力 CSF 实现（commit 4357c66 / PR #12 之后的 main）
**判据**：平台精度标准——对标解析解误差 >15 % 不可接受；关键量要求 <3 %
**结论**：**未通过**。修复 3 个实现缺陷后，曲率误差由「符号错误 + 噪声」降到 12.0–20.2 %，
Laplace 压差仍有 72.3–74.3 % 系统性欠积分。诚实记 FAIL，缺口已定位并列入后续。

---

## 1. 物理背景与算例

二维静止圆形液滴（单相自由面，外部真空），这是 CSF 表面张力模型的标准验证算例。
解析参考为 Young–Laplace 定律与圆曲率：

- 曲率：κ = 1/R（外法向，正号）
- 压力跳变：Δp = σ/R
- 等效体力积分：∫ ρa·r̂ dV 应等于 σ·κ·L（L = 2πR，二维单位深度）

| 参数 | 取值 |
|---|---|
| 表面张力系数 σ | 0.072 N/m（水–空气） |
| 参考密度 ρ₀ | 1000 kg/m³ |
| 粒子间距 dx | 0.005 m |
| 光滑长度 h | 1.3·dx = 0.0065 m（Config 默认 h_factor） |
| 液滴半径 R | 0.05 / 0.075 / 0.10 / 0.125 / 0.15 m |
| 粒子数 N | 0.050:308, 0.075:688, 0.100:1224, 0.125:1916, 0.150:2756 |
| 界面壳层粒子数（|∇c| > 0.3 max） | 0.050:120, 0.075:188, 0.100:256, 0.125:324, 0.150:392 |
| 核函数 | 2D cubic spline，归一化 10/(7πh²) |

## 2. 方法与工具链

1. **读代码**：`src/tensorsph/surface_tension.py`（CSF，Brackbill et al. 1992 形式）
   与随模型合入的 `benchmarks/static_droplet/run.py`。
2. **发现伪验证**：原基准的验收判据只有「力非零且总体向内」，实测平均加速度
   0.0434 m/s² 与解析尺度差两个量级仍判 PASS——这类判据无法发现曲率场崩坏。
   于是改为对解析量逐项量化误差（`laplace_validation.py`）。
3. **定位根因（判别实验）**：把**解析法向 r̂** 直接喂进曲率算子 `compute_curvature`，
   若仍能复现 1/R，则算子无误、缺陷在法向场构造。结果见表 3。
4. **最小修复**（`src/tensorsph/surface_tension.py`，共 3 处，公共 API 不变）：
   - `compute_color_gradient` 对称项符号：对粒子 j 的贡献应为
     `+V_i·(c_j−c_i)·∇_i W_ij`（因 ∇_j W_ji = −∇_i W_ij 且 (c_i−c_j) = −(c_j−c_i)，
     两个负号相消）。旧代码写成 `−V_j·(c_j−c_i)·∇_i W_ij`，使 i/j 两项在界面处
     相互抵消，法向方向呈 50/50 内外分裂（实测 median cos(n,r̂) ≈ 0）。
   - 色场构造：实现与模块 docstring 不符。docstring 规定 c ≈ ρ/ρ₀（光滑指示函数），
     代码却用 `neighbor_count / avg_neighbors` 只给表面粒子赋值。该场只有**一个粒子
     层**宽的过渡，其梯度方向由网格对齐而非界面几何决定。改为 docstring 规定的
     核加权数密度 `c_i = Σ_j V_j W_ij`（内部归一为 1）。
   - 力函数内部法向：`compute_normal` 对 |∇c| < eps 的粒子硬置零，内部 74 % 粒子
     法向为 0 却参与散度求和，污染 κ。改为软归一化（δ_s 因子已把内部粒子力压到 0），
     `compute_normal` 公共函数与其测试保持不变。
5. **回归门**：新增 `tests/test_young_laplace.py`（6 项，含参数化），断言法向对齐
   cos > 0.95、κ 相对误差 < 25 %、Δp 相对误差 < 80 %（后者是已知欠账的回归门，
   注释中写明并非达标声明）。
6. **工具链**：PyTorch 2.x（CPU，float64）/ pytest / matplotlib；全程单核
   （`OMP_NUM_THREADS=1`），符合本机 load15 ≥ 100 时的轻量作业纪律。

## 4. 注意点与局限

1. **Δp 系统性偏低 ~73 %**：单相自由面的色场在真空侧被截断（无外部粒子），
   最外层 c ≈ 0.62 而非 0，导致 ∫|∇c| dV 只有界面长度的约 0.27 倍。CSF 的
   δ_s 因子因此欠积分，Δp 随之等比偏小。这是单相 SPH 自由面的结构性困难，
   需引入虚拟外部粒子或对 δ_s 做界面长度归一化，属后续开发项，本单未做。
2. **κ 误差随 R 增大**（12.0 % → 20.2 %）：界面壳层相对 h 变薄，且离散网格与
   圆周的对齐方式随 R 变化。仅 R = 0.05（12.0 %）进入 15 % 以内。
3. **未做时域静水平衡模拟**：本单只检验单帧 CSF 力与曲率（轻量作业限制），
   未做长时间积分下 Δp 与 σ/R 的稳态对照；该检验需要数百步积分，属重计算。
4. **未评估 GPU 行为**：全部量测在 CPU float64 下完成，float32/CUDA 的
   数值差异未测。
5. h/dx 敏感性只抽测了 1.3 与 2.0（法向分裂在两档下均为 50/50，说明旧缺陷
   不是分辨率造成的），未做系统网格收敛研究。

## 5. 误差判定（逐项，显式回答）

| 关键量 | 基准 | 误差范围 | 是否 < 3 % | 是否 < 15 % |
|---|---|---|---|---|
| 界面法向对齐 cos(n,r̂) | 1.0（解析） | 偏差 ≤ 0.004 | 是（≤0.4 %） | 是 |
| 曲率 κ | 1/R | 12.0 – 20.2 % | **否** | **否**（仅 R=0.05 达标） |
| Laplace 压差 Δp | σ/R | 72.3 – 74.3 % | **否** | **否** |
| 曲率算子（解析法向输入） | 1/R | 2.6 – 8.5 % | 否（1/3 档 <3 %） | 是 |

**显式回答**：关键量 κ 与 Δp 均**未达到 <3 %，也未全线达到 <15 %**。
本单的增量是「把 2500 倍量级错误降到 12–20 %，并把伪验证换成定量判据」，
不是「模型已通过验证」。
