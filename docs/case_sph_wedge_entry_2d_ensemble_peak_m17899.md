# CASE-SPH-WEDGE-ENTRY-2D：峰值压力系数——换个估计量就"合格"了，但它仍不可裁决（m17899）

**锚点**：`CASE-SPH-WEDGE-ENTRY-2D`（算例池·二维楔形体入水砰击压力）
**验收原文**：`【算例池|SPH-WEDGE-ENTRY-2D｜ref: Zhao & Faltinsen 1993 J. Fluid Mech. 246:593｜容差: <15% | 指标: 楔形体表面峰值砰击压力系数】`
**本单定位**：验证欠账复核（不新增物理模型、不改求解器、不改算例定义、不放宽阈值）。上一轮 m17548 判定峰值 `Cp` **不可判定**，并把出路列为 (a) 写死分箱规则+扩大帧系综 或 (b) `dx ≤ 1 mm`（算力）。本单按 (a) 做**预声明实验**：同一轨迹、同一物理，只换估计量（样本门 + 自相似帧系综），共 2 个网格 2×61 帧、局部墙钟 134 s。结论：**历史的 +234 % FAIL 确是估计量伪像（改正后 5.85，差 4.8 倍），但改正后的量在 dx = 4 mm 与 2 mm 之间变号（+23.3 % vs −30.4 %），故峰值 Cp 在本分辨率下仍不可裁决**；可裁决量仍是湿宽、顶点 Cp、峰值横坐标。Zhao & Faltinsen (1993) 数值仍 **WITHHELD**（闭源，不以记忆值/二手值代替）。


> **【更正 · m18382（2026-11-13）】** 本报告 ⑤.2 与“建议 3”称“湿面节点数随入水加深从 59.7 掉到 29.8，是壁面接触判据在深穿透下失效”——**这是对本报告自身表格的误读**。`mean_wet_nodes` 是“最后 N 帧”的均值，N 越小窗口越靠后、湿节点越多；已入仓工件 `frame_scan` 的逐帧 `n_wet` 是**单调增**的（dx=2 mm：开头 0–2 个 → 末帧 60 个），与 `c = C V t` 增长一致。故“接触判据在深穿透下失效”不成立，不应据此立求解器项；jackknife 43 % 的真实原因只是“早窗湿节点少”。更正见 `docs/case_sph_wedge_entry_2d_operator_bias_m18382.md` ⑤.1，并由 `tests/test_wedge_estimator_bias.py` 钉住。

## ① 案例介绍

二维对称刚性楔形体以恒速 V 垂直入水，deadrise 角 β = 30°，静水、忽略重力（自相似区：唯一长度尺度 V·t）。参照量全部由仓内闭式现算（`src/tensorsph/wedge_entry.py` 式 (1)–(3)），**不手抄**：

* `C = π/(2 tan β) = 2.72070`，湿半宽 `c(t) = C V t`；
* 壁面压力 `Cp(τ) = 2 C s − s² + 1`，`s = 1/√(1−τ²)`，`τ = |x|/c`；
* 峰值 `Cp_max = C² + 1 = 8.40220`（`τ_peak = √(1−1/C²) = 0.93000`）；顶点 `Cp(0) = 2C = 5.44140`。

| 参数 | 值 | 备注 |
|---|---|---|
| β / V | 30° / 1 m/s | 任务指定，恒速 |
| ρ₀ / γ | 1000 kg/m³ / 7 | Tait EOS，`B = ρ₀c₀²/γ` |
| c₀/V | 20（c₀ = 20 m/s） | 弱可压，Mach = 0.05；声学压力尺度 `2c₀/V = 40`（Cp 单位） |
| α（Monaghan 人工粘性） | 0.03 | 与历轮一致 |
| h/dx / Courant | 1.3 / 0.35（声速） | 三次样条 |
| 观测窗 | `t_end = 2 c_end tanβ/(πV)`，`c_end = 50 mm` → 18.38 ms | 自相似窗 |
| dx | 4 mm（329 步）/ 2 mm（587 步） | 相邻比 2 |
| 帧数 | 61（历轮为 13 帧、系综取后 5 帧） | 本单唯一的方法学改动 |
| 重力 / 表面张力 / 粘度 | 关 / 不建模 / 无（仅人工粘性） | 惯性主导砰击 |

## ② 怎么做的（方法、流程、工具链、关键设置）

**未改求解器、未改算例、未改阈值**。本单只做一件事：把"剖面峰值"这个估计量按**先于任何运行写死**的规则重建，并检验它在什么条件下可裁决。

预声明设计（`benchmarks/case_sph_wedge_entry_2d/ensemble_peak.py` 顶部常量）：

* **帧系综**：`FRAME_COUNTS = (7, 13, 25, 41, 61)`，取窗口**最后 N 帧**。理论依据：Wagner 解在 `τ = |x|/(C V t)` 下自相似，不同时刻的帧是同一剖面，帧可作为系综成员；池化后每 bin 样本数按 √N 降噪。
* **样本门**：`MIN_BIN_SAMPLES = 4`——池化样本数 < 4 的 bin 不许设定峰值（m17548 的 +234 % 正是 120 bin ≫ 每帧 62 个湿面节点、`bin = 单粒子` 造成的）。
* **分箱网格**：`BIN_GRID = (6, 8, 10, 12, 16, 20, 30)`；H1 统计量 = 该网格上峰值的**极差/中位数**。
* **分辨率带（次生统计量，同样先声明）**：bin 的**米制**宽度必须落在 `[1dx, 4dx]`——窄于一颗粒子 = 单粒子读数，宽于四颗粒子 = 抹平喷溅根部的抬升。该带内的峰值极差作为"报出值的不确定度"。
* **H1（预测）**：61 帧 + 样本门后，峰值极差 < 15 %（= 验收容差）→ 峰值 Cp 在 dx = 2 mm 上变得可裁决。
* **H2（H1 被推翻的条件）**：极差仍 > 15 % → 峰值须 `dx ≤ 1 mm`，本网格继续报 WITHHELD。
* **补充自洽检查（先声明）**：帧系综要求**时间平稳**——早/晚半窗各自独立估计必须一致（jackknife 相对差），且估计量必须**随网格收敛**。这两条不满足时，即使 H1 的数字"合格"，也不得宣布可裁决。

复现（局部，4 线程）：

```bash
python benchmarks/case_sph_wedge_entry_2d/ensemble_peak.py --dx 0.004 --frames 61 --threads 4   # 22.9 s
python benchmarks/case_sph_wedge_entry_2d/ensemble_peak.py --dx 0.002 --frames 61 --threads 6   # 111.1 s
python benchmarks/case_sph_wedge_entry_2d/make_ensemble_figure.py
python -m pytest tests/test_wedge_ensemble_peak.py -q                                            # 7 passed
```

工件：`docs/artifacts/case_sph_wedge_entry_2d_ensemble/ensemble_dx{2,4}mm_c0v20.json`（入仓；含逐帧扫描、每 bin 峰值与样本数、环境与墙钟）。本单每条数字都可从这两个 JSON 复算（`tests/test_wedge_ensemble_peak.py` 里有一条测试专门校验"报出值 = 从每 bin 行复算值"，防手抄）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **"合格"的极差 ≠ 可裁决**：H1 在 dx = 2 mm 上字面成立（极差 14.0 % < 15 %），但**补充自洽检查否掉了它**：早/晚半窗 jackknife 相对差 **43.0 %**（4 mm 仅 0.1 %），且 4 mm→2 mm 变号（+23.3 %→−30.4 %）。原因是湿面节点数随入水加深下降（系综平均 59.7（7 帧窗）→ 29.8（61 帧窗）），早窗与晚窗的采样密度不同——**帧系综在本算例不是时间平稳的**，把 61 帧当作 61 个独立样本会低估不确定度。故本单判定仍是**不可裁决**，不因 14.0 % 而宣布通过。
2. **湿面节点数随入水加深而下降**（4 mm：窗首 2 → 窗末 30；2 mm：2 → 60，但平台均值 29.8）：说明相当一部分楔面节点在后期失去核支撑/接触判据，这是壁面压力采样的系统性可用面收缩，**会同时压低峰值与抬高噪声**。这是求解器/接触判据层面的欠账，本单未动（列为进一步工作）。
3. **启动瞬态不可用"帧过滤"解决**：声学松弛时间只占窗长 0.016 %，尖峰出现在**湿面仅 2 个节点**的帧——正确做法是**湿面节点下限**（建议 `n_wet ≥ 8`）作为硬门，这需要写进分箱规则，而不是挑帧。
4. **不与 Zhao & Faltinsen (1993) 比较**：原值仍不可得（闭源，`refs.json` 状态未变）；本单所有对照都是**同理想化的 Wagner 闭式**，不是 Z&F 数值。
5. **算力纪律**：本机 load15 = 143（nproc = 128），故只跑 2 个单例（22.9 s + 111.1 s，4–6 线程），未做 `dx ≤ 1 mm` 网格、未提交集群；`dx = 1 mm`（预计 ~20 min/例）列为下一步。
6. **适用范围**：β = 30°、V = 1 m/s、c₀/V = 20 单点；结论"峰值不可裁决"限定在 `dx ≥ 2 mm`，不外推到更细网格。

## ⑥ 误差判定（逐项，显式回答"是否 <15 %"）

| 关键量 | 基准 | 本单实测 | 相对误差 | 是否 <15 % |
|---|---|---|---|---|
| 峰值 Cp（样本门 + 61 帧池化，dx = 2 mm） | 8.40220（Wagner `C²+1`，仓内现算） | 5.850 | **−30.4 %** | **否** |
| 峰值 Cp（同一估计量，dx = 4 mm） | 8.40220 | 10.360 | **+23.3 %** | **否** |
| 峰值 Cp 的网格一致性 | — | 跨网格差 **53.7 个百分点**（变号） | — | **否 → 未收敛，不可裁决** |
| 峰值的分辨率带内不确定度（最细网格） | ≤ 15 % | 11.8 %（带内）/ 14.0 %（全网格） | — | 是（**但被 3.3/⑤.1 的自洽检查否掉，不据此宣布通过**） |
| 顶点/驻点 Cp(0) | 5.44140（= 2C，仓内现算） | 4.713（dx = 2 mm） | **−13.4 %** | **是** |
| 顶点 Cp(0)（dx = 4 mm） | 5.44140 | 4.999 | −8.1 % | 是 |
| 质量守恒 max ρ/ρ₀−1（61 帧快照） | ≤ 5 %（判据） | 5.58 %（2 mm）/ 5.90 %（4 mm） | — | **否（略超，如实记录）** |
| 峰值 Cp vs **Zhao & Faltinsen (1993)** | — | — | — | **WITHHELD**（基准数值未获得；不以替代值判定） |

**honest 结论**：①历史 +234 % 的 FAIL 是**估计量伪像**，改正后为 −30.4 %（同轨迹、同物理），这是本单最实的产出；②改正后的峰值在 4 mm / 2 mm 之间**变号**且帧系综不平稳（jackknife 43 %），因此**峰值 Cp 在 dx ≥ 2 mm 仍不可裁决**，H1 的字面通过不构成验收通过；③可裁决量维持 m17548 结论：湿宽 `c/(C V t)`（−0.5 %）、顶点 `Cp(0)`（−13.4 %，本单独立复核）、峰值横坐标 `τ_peak`（<1 %）；④质量守恒在更密帧采样下 5.58 %，**略超 5 % 判据**，如实列为待办而非粉饰。

## 建议（给派发器 / 下次找活的线索）

1. **改锚点验收**（沿用 m17548 建议 slug `CASE-SPH-WEDGE-ENTRY-2D-METRIC`，域：耐波/砰击验证面）：验收 = 「`c/(C·V·t)` 误差 < 5 % **且** 顶点 `Cp(0)` < 15 % **且** `τ_peak` 误差 < 5 %（β = 30°, V = 1 m/s, dx ≤ 2 mm）」，峰值 Cp 以**池化 + 样本门**报出并**附 GCI**，`dx ∈ {4, 2}` 两级的峰值必须同号才允许进入判定——本单已证两级不同号。
2. **峰值 Cp 的正经路径**：`dx = 1 mm` 单例（~20 min，建议递交集群）＋湿面节点下限 `n_wet ≥ 8` 写进规则＋按 GCI 判收敛；不要再试图用 δ-SPH 或更细分箱修它（m17548 已否）。
3. **真正的求解器欠账**：湿面节点数随入水加深从 59.7 掉到 29.8，是壁面接触判据（`contact_support`）在深穿透下失效，这会让任何壁面压力判据的系统可测面收缩——建议单独立项（不属本算例的估计量问题）。
