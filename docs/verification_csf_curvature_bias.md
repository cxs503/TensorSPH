# CSF 曲率判据的偏置归因与修复（TensorSPH）

> **[台帐 m3544]** 文中 `p_center = 409.8 Pa`（→ `-78.6%`）为**噪声未分辨的带压差快照**：
> 同一工件 `benchmarks/csf_consistent/validation_report.json` 的 `relax.history.p_center` 在
> 0…2395 Pa 间摆动，尾窗均值 276.4 ± 163.8 Pa（−23.2%），单点读数与尾均值差 4 倍噪声。
> 该工件不能分辨 15% 门内的差异；曲率结论（§偏置归因）不受影响。
> 权威读数见 `docs/verification_ledger.md`（−34.0%，WITHHELD）。机器门禁：`tests/test_verification_ledger.py`。

## 结论（先给判定）

1. **m2447 遗留的曲率判据失败不是分辨率不足**。在 dx = 3/2/1.5/1 mm 四档上，`kappa = div n` 的 δ_s 加权误差为 +28.3%, +22.2%, +21.5%, +24.7%，随加密**没有**收敛（最细网格仍 +24.7%）。
2. **算子无罪，法向场有罪**。把 MLS 散度算子喂以**精确径向法向** r̂，误差降到 +24.5%, +14.9%, +10.9%, +6.8%（最细 +6.8%），说明 `div n` 实现正确，偏置来自单位法向的角向离散噪声被 `~1/dx` 放大。
3. **偏置集中在饱和内壳**。c ≥ 0.99 的粒子只占 δ_s 权的 11.7%、力的 23.6%，却给出 κ = +182.5%（dx = 1 mm），把加权均值从 +7~14% 抬到 +21~25%。
4. **修复已落地且验收过半**：曲率改用**一遍 Shepard 平滑后的色函数**（力仍用锐利场）后，κ 误差变为 +23.8%, +14.4%, +10.5%（dx = 3/2/1.5 mm），**dx ≤ 2 mm 全部 < 15%**；切割力恒等式同步改善到 1.060, 0.997, 0.969（1.000 = 精确 2σ），力方向与 δ_s 归一不变。
5. **仍未解决（honest FAIL）**：端到端 Laplace 压差 relax 判据仍为 -78.6%（阈值 15%），见 §5.2 的观测有效性分析。

## ① 案例介绍

2-D 单相静止液滴，半径 R = 0.0200 m，六方密排晶格初始化，四周真空，重力关闭，Tait 状态方程（γ = 7，c0 = 20 m/s）。表面张力 σ = 7.2 N/m。Young–Laplace 给出 Δp = σ/R = 360 Pa、κ = 1/R = 50 1/m，「表面张力 = 单位长度力」给出 F_cut = 2σ = 14.4 N/m，δ 函数归一要求 ∫δ_s dn = 1。

| 参数 | 值 |
|---|---|
| R [m] | 0.02 |
| σ [N/m] | 7.2 |
| ρ0 [kg/m³] | 1000.0 |
| c0 [m/s] | 20.0 |
| h/dx | 1.3 |
| 分辨率扫描 dx [m] | 0.003, 0.002, 0.0015, 0.001 |
| 粒子数 N | 161, 362, 642, 1450 |
| 解析基准 | κ = 50.0 1/m，F_cut = -14.4 N/m，∫δ_s dn = 1 |

## ② 怎么做的

四档分辨率上各建一次静态液滴，**只做瞬时诊断**（不做时间推进，故整份审计 < 1 min 墙钟）：

| 变体 | 曲率来源 | 用途 |
|---|---|---|
| V0 baseline | `div n`，n 来自**锐利**色函数（m2447 代码路径，`curvature_color_smoothing=0`） | 复现遗留失败 |
| V1 control | `div n`，n 用**精确径向法向** r̂ | 把算子偏置与法向偏置分离 |
| V2 default | `div n`，n 来自**一遍 Shepard 平滑**的色函数（本单修复，`curvature_color_smoothing=1`） | 候选修复 |
| V3 | V2 + δ_s 按测得 ∫δ_s dn 归一 | 联合修复探针（负结果） |

三种变体都在**同一套 δ_s / 法向**上组装 CSF 加速度 `a = -σ κ δ_s n / ρ`（ρ 为局部密度，与生产路径一致），因此三项判据可比。工具链：PyTorch 2D 弱可压 SPH（CPU 2 线程）、`benchmarks/laplace_law/run.py` 的六方格点生成器、matplotlib。

## ③ 计算结果

### 3.1 分辨率阶梯（δ_s 加权曲率误差，% of 1/R）

| dx [mm] | N | V0 baseline | V1 控制（精确法向） | V2 default（本单） | V2 切割力比 F_cut/2σ | V2 ∫δ_s dn |
|---|---|---|---|---|---|---|
| 3.0 | 161 | +28.3% | +24.5% | **+23.4%** | 1.060 | 0.755 |
| 2.0 | 362 | +22.2% | +14.9% | **+14.2%** | 0.997 | 0.751 |
| 1.5 | 642 | +21.5% | +10.9% | **+10.3%** | 0.969 | 0.739 |
| 1.0 | 1450 | +24.7% | +6.8% | **+6.9%** | 0.951 | 0.734 |

阈值：|误差| < 15%。V0 在四档全部 FAIL 且不收敛（28.3 → 24.7%）；V1 在 dx ≤ 2 mm 收敛到 15% 以内（14.9 / 10.9 / 6.8%），证明算子本身没有系统偏置；V2 与 V1 同量级，在 dx ≤ 2 mm 达标（14.2 / 10.3 / 6.9%）且切割力比更接近 1。

### 3.2 偏置归属：哪些粒子在贡献误差

按色函数值分组（dx = 1.0 mm 档最细）：

| 分组 | 粒子数 | κ 均值误差 | δ_s 权占比 | 力占比 | 法向角误差(均值) |
|---|---|---|---|---|---|
| c<0.90 | 136 | +6.5% | 64.4% | 55.2% | 1.78° |
| 0.90<=c<0.99 | 94 | +8.5% | 23.9% | 21.2% | 1.90° |
| c>=0.99 | 124 | +182.5% | 11.7% | 23.6% | 2.02° |

机理：`κ = div n` 对单位法向的角向误差是 **微分放大** —— 相邻粒子间 2° 的法向差在 dx = 1 mm 上就贡献 `Δθ/dx ≈ 35 1/m`，相当于把 κ 抬高一倍。饱和内壳（c→1）处 `|∇c|` 已很小，法向由噪声主导，但其 δ_s 仍有界面峰值的 ~10–25%，于是把加权均值拖到 +22~25%。

### 3.3 联合修复探针（负结果）

δ_s 积分实测只有 0.755, 0.751, 0.739, 0.734（缺口 24.5, 24.9, 26.1, 26.6%），与 κ 高估部分相互抵消，这正是旧方案切割力仍能落在 15% 内的原因。按测得积分把 δ_s 归一（V3）会破坏这个平衡：切割力比升到 1.40, 1.33, 1.31, 1.30（全部超出 15%）。**结论：不能单独归一 δ_s；正确做法是修 κ 而保留锐利 δ_s（本单采用），或整体重整 CSF 力密度。**

## ⑤ 注意点

### 5.1 源码改动的影响面

`csf_fields` 新增 `curvature_color_smoothing: int = 1`：曲率改用一遍 Shepard 平滑的色函数，力仍用锐利场（δ_s、法向、方向不变）。每步多一次 Shepard + 一次 MLS 梯度 + 一次 MLS 散度，端到端 benchmark（含 600 步 relax）墙钟约 30 s（本机 CPU 2 线程），与改动前同量级。`curvature_color_smoothing=0` 可复现 m2447 行为（回归对照用）。

### 5.2 端到端压差仍 FAIL，且该读数的有效性本身存疑
relax 判据（dx = 2 mm，600 步，t = 0.70 t_σ）测得 p_center = 409.8 Pa、p_interface = 332.7 Pa，Δp = 77.2 Pa vs 360 Pa（-78.6%）→ **不达标**。但 p_center 的时间序列在 0…2395 Pa 间振荡（相对目标 360 Pa 达 ±665%），且只推进到 0.70 个毛细时间：该读数**未达准静态**，不能当作“模型压差误差”的证据。要给出可信判定，需（a）推进 ≥ 5 t_σ 并做时间平均，（b）按 σ/(c0²ρ0/γ) 检查所需密度压缩量 0.0063 （实测 0.0010）。这是本单**未完成**的部分。

### 5.3 适用范围

结论基于 2-D 单相静止液滴、六方晶格、h = 1.3 dx。3-D 球形液滴与不规则（非格点）粒子分布下 κ 的噪声结构不同，需重跑本审计；接触角壁面 BC 路径未纳入本审计。

## ⑥ 误差判定（逐项 vs 基准）

| 关键量 | 基准 | 实测（dx = 2 mm，默认路径） | 相对误差 | < 15% ? | < 3% ? |
|---|---|---|---|---|---|
| 曲率 κ（δ_s 加权） | 50.0 1/m | 57.19 1/m | +14.4% | 是 | 否 |
| 切割力 F_cut | -14.4 N/m | -14.36 N/m | +0.3% | 是 | 是 |
| δ 函数归一 ∫δ_s dn | 1.000 | 0.751 | -24.9% | 否（本单未修） | 否 |
| 力方向（cos 中位） | 1.000 | 1.000 | +0.0% | 是 | 是 |
| 伪流 max|v|/√(σ/ρR) | < 0.1（Adami 2012） | 0.033 | — | 是 | 不适用 |
| Laplace 压差 Δp | 360 Pa | 77.2 Pa | -78.6% | 否 | 否 |

显式回答「是否 < 3%」：**曲率、切割力、δ 函数归一、压差四项均未达 3%**；其中曲率与切割力达到平台 15% 门限，δ 函数归一（缺口 25%）与端到端压差（缺口 >70%）未达标，且压差读数本身未达准静态（§5.2），故本单对 Δp *不主张*任何精度结论。
