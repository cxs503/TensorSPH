# Stokes' second problem in a bounded gap — unsteady viscous verification

**Case anchor:** `CASE-SPH-STOKES-2ND-PROBLEM` (open → this document is its evidence)
**Code:** `src/tensorsph/stokes2.py` · **driver:** `benchmarks/stokes2/run.py` ·
**tests:** `tests/test_stokes2.py` · **artifacts:** `benchmarks/stokes2/out/ladder.json`,
`benchmarks/stokes2/out/tables.md`, `benchmarks/stokes2/out/figures/`

## 1. Why this case exists

The repository had three viscosity checks and none of them is an *unsteady* test of
the viscous operator:

| existing check | what it actually measures | what it cannot separate |
|---|---|---|
| `benchmarks/poiseuille` | curvature of a **steady** profile (momentum balance) | phase / unsteady response |
| `tests/test_boundary.py` (quarter-wave shear decay) | one decaying mode, `exp(-nu (pi/2H)^2 t)`; measured rate **0.84** of analytic at `dx = 0.02` | one time constant only: a wrong viscosity and a wrong wall position give the same number |
| capillary wave / oscillating droplet | a damping rate, surface-tension dominated | the operator, because the CSF term is the error budget |

Oscillatory shear carries **both** an amplitude envelope and a phase lag at every
depth, so the measurement splits into a scale error (the fitted `nu_eff / nu`) and a
shape/wall error (the residual at the fitted `nu_eff`, and the depth-independent part
of the phase error). That split is what this case adds.

## 2. Physics and geometry

Gap `0 <= y <= H`; lower plate oscillates in its own plane, `u_wall = U0 cos(omega t)`,
upper plate at rest. The flow is x-invariant, so

```
du/dt = nu d2u/dy2,   u(0,t) = U0 cos(omega t),   u(H,t) = 0
u(y,t) = Re{ U0 sinh(beta (H - y)) / sinh(beta H) e^{i omega t} },
beta = (1 + i)/delta,   delta = sqrt(2 nu / omega)
```

`delta` is the viscous penetration depth. At `y = 0` the ratio is exactly 1 and at
`y = H` exactly 0, so a bounded gap is used rather than the semi-infinite idealisation:
the whole domain has a closed form and no absorbing boundary has to be invented.

| parameter | value |
|---|---|
| `H` (gap) | 0.16 m = `4 delta` |
| `delta` | 0.040 m |
| `omega` | 2.5 rad/s (`T` = 2.513 s) |
| `nu` | 0.002 m²/s |
| `U0` (wall amplitude) | 0.05 m/s |
| `c0` | 1.25 m/s (`U0/c0 = 0.04`, compressibility `O(Mach²) <= 1.6e-3`) |
| gravity | **0** (a pure shear problem; a hydrostatic gradient would only add a compressibility budget) |
| `Re_delta = U0 delta / nu` | 1.0 |
| walls | Adami (2012) extrapolation, 3 layers, `wall_friction = 1` (no-slip through the moving-wall `wall_vel`) |
| periodic in x | width `8 dx` |
| sampling | 2 periods after the analytic initial condition (periodic state present from step 0; no startup transient) |
| ladder | `dx` = 10, 6.67, 5 mm → `delta/dx` = 4, 6, 8 |

`c0` is chosen as `25 U0`. The step count of this case is
`(2 pi / omega) c0 / (0.3 h)` per period, i.e. **proportional to c0**, so a small sound
speed is what makes a viscous time scale affordable in a WCSPH code; the price is a
`O(Mach²)` compressibility error of 0.16 %, two orders below the effect measured.

## 3. Method

1. `tensorsph.stokes2.OscillatoryCouette` holds the closed form, with `delta` and
   `beta` derived, never supplied.
2. `crank_nicolson_reference` solves the *same* diffusion problem with an unrelated
   discretisation (float64 tridiagonal implicit in time, central in space, Dirichlet
   data from the wall motion). The two agree to **0.0017 % of U0** over two periods
   (`test_closed_form_matches_independent_crank_nicolson`), so the closed form is
   verified, not trusted.
3. `run_case` integrates the WCSPH solver from the analytic field at `t = 0`, driving
   the wall through `wall_vel` / `wall_accel` (the moving-wall path), and accumulates
   the Fourier projection of `u_x` on `{cos omega t, sin omega t}` per lattice row
   inside the loop — the complex amplitude `U_hat(y)` is produced by the run, not read
   back from a file.
4. Errors: relative `L2` over the rows, `max |Delta U_hat| / U0`, phase error in
   degrees, plus a one-parameter golden-section fit of `nu_eff` (analytic model only,
   no extra runs) with the residual at the fitted viscosity.

## 5. Error verdict — does it meet the 3 % gate?

**No. Honest FAIL at every resolution tested.**

| key quantity | best measured (`delta/dx = 8`) | gate | verdict |
|---|---|---|---|
| relative `L2` of `u_x(y,t)` | **10.87 %** | < 3 % | FAIL |
| max amplitude error / `U0` | **6.39 %** | < 3 % | FAIL |
| max phase error | **5.45 deg** | (phase gate not set) | — |
| `nu_eff / nu` | **0.856** | 1.000 ± 0.03 | FAIL |

Two things follow, and they are the point of the case:

1. **The viscous operator under-diffuses by 14–25 %.** `nu_eff/nu` climbs 0.748 → 0.856
   as the wall layer is refined, and `L2` at the fitted viscosity still falls only
   13.8 % → 7.2 %, so the error is **not** a pure viscosity scale factor: a residual
   shape error remains at the optimal `nu`.
2. **The phase error is nearly depth-independent** (−8.5° to −8.6° across `y/delta` =
   0.125…0.875 at `delta/dx = 4`). A constant phase offset is the signature of an
   **effective wall position** (the no-slip condition is imposed through the kernel
   weight of the first fluid row, one half-spacing from the nominal plate), not of a
   wrong viscosity — a viscosity error would grow with depth. This is the same
   mechanism the steady Poiseuille benchmark reports as a wall offset `delta/dx`.

**Cross-validation of an existing number.** The quarter-wave shear decay in
`tests/test_boundary.py` records a measured rate of 0.84 of the analytic value at
`dx = 0.02`. This case, a different flow with a different measurement, returns
`nu_eff/nu = 0.856` at `delta/dx = 8`. The two independent numbers agree, which says the
0.84 was not an artefact of that test — and that the deficiency is a property of the
viscous discretisation, not of one benchmark.

**What would close the gap.** Extrapolating the table (error roughly halving per doubling
of `delta/dx`, i.e. first order in `delta/dx`) puts the 3 % gate near `delta/dx ~ 25–30`,
which is ~4x the particle count in each direction and is not a fix. The fix is in the
wall layer: either a correct wall-normal viscosity stencil (so the no-slip plane sits at
the plate, not half a spacing inside it) or an explicit wall-parallel shear boundary
condition. Both are out of scope for this task and are now backed by numbers rather than
by a suspicion.

## 6. Caveats and scope

* The case is **two-dimensional and gravity-free** by design. It verifies the viscous
  operator and the moving-wall condition; it says nothing about the free-surface
  treatment, the pressure solver or the boundary extrapolation under gravity.
* `nu_eff` is a *model-consistent* fit: it answers "which viscosity would make the
  analytic form match the measured rows", which is only meaningful because the residual
  at the fitted value is reported next to it.
* The error is dominated by the wall-adjacent row; interior rows are better (the
  `y/delta = 0.875` row is −5.6 % in amplitude at `delta/dx = 4`).
* Runtime is ~30 s per resolution on the control node at `delta/dx <= 8`; the whole
  ladder is 3 runs, so no cluster job is needed.
