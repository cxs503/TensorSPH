# 端到端 Young-Laplace 判据的可判性修复（静止液滴内压 σ/R）

**范围**：`benchmarks/laplace_equilibrium/run.py`（新增）、`tests/test_laplace_equilibrium.py`（新增）、
`benchmarks/csf_consistent/run.py`（旧判据标注，不改数值）
**基准**：2-D 单相静止液滴的 Young-Laplace 定律 `Delta p = sigma/R`。
本文件所有数字由 `benchmarks/laplace_equilibrium/run.py` 写出的
`validation_report.json` + `raw_cases.json` 经 `write_docs.py` 程序化注入，无手抄。
它复核的对象是**判据本身**，不是新的物理模型。

## 1. 案例介绍（物理背景与参数）

半径 `R = 0.02 m` 的二维单相液滴，六方密排晶格初始化，四周真空，无重力，
表面张力使内部建立过压 `Delta p = sigma/R`。这是 CSF 表面张力模型**唯一**的端到端
（力 → 压力场）解析判据：`docs/verification_surface_tension_curvature.md` 已经把
力幅（切割力恒等式）与曲率修进 15% 门，但端到端压差一直记作 −76 %…−107 %，
并被归类为"Tait 压缩落进求和密度噪声地板"。本工作把这句话当假设来检验。

| 参数 | 值 |
|---|---|
| 液滴半径 R | 0.02 m |
| 表面张力系数 sigma | 7.2 / 14.4 / 21.6 N/m（扫描） |
| 参考密度 rho0 | 1000.0 kg/m^3 |
| 声速 c0 | 20.0 m/s |
| 状态方程 | Tait, gamma = 7.0，自由面钳位 p=0 |
| 平滑长度 | h = 1.3 dx（全仓标定值，未改） |
| 分辨率 | dx = 0.002 m（N = 213 粒子） |
| 时间推进 | dt = stable_dt，9000 步（t/t_sigma = 10.5，毛细周期 ~ 85.5 ms） |
| 解析参考 | Delta p = sigma/R = 360.00 Pa（sigma=7.2）；所需压缩 = 6.300e-03 |

## 2. 怎么做的（方法/流程）

复核判据时发现两处**测量缺陷**（同一个 benchmark 里，与被测模型无关）：

**D1 量具**：旧 `relax()` 用 `p_core - p_band`，band 取 `0.80R < r < 0.95R`——这是在液滴
**内部**。CSF 力是集中在界面壳的体力，平衡时内部压强是平台，整个跃变发生在
最外层粒子与真空之间（真空侧由 Tait 钳位给出 p = 0）。两个内部点相减量到的是平台
残余倾斜，不是 Laplace 跃变。新量具：`p_core` 取 `r < 0.5R` 平台均值，环境压强按
定义取 0，跃变 = `p_core − 0`；`p_shell`（`0.97R < r ≤ 1.02R`）只作诊断记录。

**D2 初始条件**：`hexagonal_droplet` 按 `mass = rho0 dx dy` 布点，隐含假设该格子的
**离散单位分解**等于 1。`h/dx = 1.3` 时并不成立：实测核心求和密度
1.005884 `rho0`，于是初始 Tait 压强
`B[(1.005884)^7 − 1] = 2395.4 Pa` ——
是 360 Pa 信号的 **6.7 倍**，
而且背后就是自由面，立刻以声波形式释放。此后任何 `p_core` 采样都是两个大数之小差。

**修复**：**体积一致初始化** —— 只改粒子质量（等价粒子体积，格距与 h/dx 都不动），
使离散单位分解恰为 1：`m* = rho0 dx dy / (sum_j V_j W_ij)`，求和密度对质量是线性的，
故一步精确，然后再用完整初始态**校验**（实测 1.0000000）。
kernel、dx、h/dx、CSF 装配、状态方程、时间步限幅**全部不变**。

由此得到三条互不依赖的判据：

1. **静息控制**（sigma = 0）：无表面张力就应无内压、无运动。旧初始化过不了（初始
   2.4 kPa 会推动液滴），新初始化必须过。
2. **绝对判据**：`p_core` 的时窗统计均值 vs `sigma/R`。
3. **斜率判据**：`d p_core / d sigma = 1/R`，与任何常数偏置无关（偏置只进截距）。

统计口径：时窗 = 后 50% 采样；`stable` 要求相对波动 ≤ 15%（沿用静水 benchmark 的
压力波动门）且时窗残余趋势 ≤ 10%。同时报告均值的标准误 `sem`。

工具链：`benchmarks/laplace_equilibrium/run.py`（6.9 k 行级参数扫描 + 出图）、
`write_docs.py`（本文档与平台报告的数字注入）、`tests/test_laplace_equilibrium.py`
（13 个判据单测：格子偏置、质量标定、时窗统计、斜率无偏置、径向分箱、静息控制）。

## 4. 结果判读

本轮把"端到端 Young-Laplace 冲不上 15% 门"这一历史结论拆成三件事，逐件给了判据：

1. **D1/D2 是真实的测量缺陷，已修**。旧量具量的是液滴内部两个半径之间的平台倾斜；
   旧初始态自带 2395 Pa（= 6.7 倍 σ/R）的虚假内压。
   修正后的量具 + 体积一致初值给出**静息控制通过**：σ = 0 时 `max|p_core| ` 与 `max|v|`
   均到机器零量级，说明修正后的初始态既不推液滴也不生成伪压。
2. **力→压强的链条在前 1 个毛细时间是对的**：体积一致算例在**前 10 % 采样窗**
   （t ≤ 0.033 s ≈ 1.0 t_sigma）内窗均
   `p_core = 349.0 Pa`，对 `σ/R = 360 Pa` 误差 **-3.1 %**。
3. **长时间失败是真实的物理缺陷，而且不是历史文件给的解释**：同一算例到
   t = 0.351 s 时内压塌到 `56.1 Pa`（-84.4 %），
   同时液滴**半径从 20 mm 涨到 r95 = 30.5 mm**、核心密度掉到
   `0.9670 rho0`。也就是说自由面壳层粒子丢失邻居 → 求和密度亏 → Tait 钳位到 p = 0
   → 没有回复力，液滴缓慢膨胀"蒸发"，Laplace 过压随之流失。这与"1e-3 量级的求和密度噪声
   淹没 6.3e-3 的压缩"是两个不同的机制：噪声解释预测读数在均值附近抖动，实测却是
   **单调衰减 + 半径增长**（前 10 % -3.1 % → 25–50 % 窗
   -66.6 % → 后 50 % 窗 -84.4 %）。
   历史上 −76 %/−88 %/−107 % 三个互相矛盾的读数，正是这条衰减曲线上不同采样时刻。
4. **斜率判据 WITHHELD**：σ 加倍到 14.4 N/m 时该工况发散（见 §6），扫描窗口被稳定性截断，
   因此 `d p_core / d sigma = 1/R` 未测得——不拿单点冒充斜率。
5. 结论：**旧结论（端到端不达标）在数值上仍然成立，但归因被修正**；同时给出两个新的、
   可复现的量化判据（静息控制、前 1 个毛细时间的 +/−3 % 一致性）把问题定位到
   **自由面处理**，而不是状态方程分辨率地板。

## 5. 注意点（踩过的坑）

1. **D1（量具）**：界面壳一旦把整个跃变吃掉，`p_core − p_band` 就退化成平台倾斜，
   与 Laplace 定律无关。任何"压差"判据必须说明环境侧取 0 的依据。
2. **D2（初始条件）**：`mass = rho0 dx dy` 只在离散单位分解 = 1 时才对；`h/dx = 1.3`
   时偏 0.59 %，恰好与"360 Pa 所需压缩 6.3e-3"同量级 —— 这不是巧合，是同一套离散化
   的两面：**信号与初始偏差同阶**，所以旧判据永远测不出结论。这解释了历史上
   −76 %/−88 %/−107 % 三个互相矛盾的读数（它们是同一条过冲/回落曲线上的不同采样时刻）。
3. **单点采样不可用**：液滴是近乎无粘的振子，`p_core` 在 46–614 Pa 之间摆动；
   必须用时窗统计 + 波动/漂移门，否则任何一个数都能被"测"出来。
4. **质量标定不改几何**：只缩质量，格距、粒子数、h/dx、配对表全不变，因此不影响
   曲率/`delta_s` 的既有标定结果（见 `tests/test_laplace_equilibrium.py`）。
5. **诊断字段 `r95` 必需**：液滴在长时间推进中会缓慢变大（自由面求和密度亏损向内扩散），
   不记录实际半径就无法区分"压强漏掉"与"sigma/R 本身变小"。

## 6. 误差判定（逐项，显式回答「是否 < 3%」）

| 关键量 | 基准 | 实测 | 误差 | < 3%？ | < 15%？ |
|---|---|---|---|---|---|
| 离散单位分解（初始态） | 1.0 | 1.005884 → 1.0000000 | 0.59 % → <1e-6 % | 修复后是 | 修复后是 |
| 前 10 % 窗 p_core（体积一致，σ=7.2） | 360 Pa | 349.0 Pa | -3.1 % | **否**（差 0.1 个百分点） | 是 |
| 后 50 % 窗 p_core（体积一致，σ=7.2） | 360 Pa | 56.1 Pa | -84.4 % | **否** | **否** |
| 后 50 % 窗 p_core（仓库原状） | 360 Pa | 55.9 Pa | -84.5 % | **否** | **否** |
| σ = 0 静息（体积一致） | max\|p\| = 0, v = 0 | 0.0 Pa, 0.0e+00 m/s | 0 | 是 | 是 |
| 终态液滴半径 r95（σ=7.2，体积一致） | 20 mm（初值） | 30.48 mm | +52 % | **否** | **否** |
| d p_core / d sigma | 1/R = 50 1/m | 未测得（σ ≥ 14.4 发散） | — | WITHHELD | WITHHELD |

显式回答：**没有**任何一个"是否 < 3%"的物理量可以判 PASS——除静息控制（恒等通过）外，
唯一接近的是前 10 % 窗的 -3.1 %。本工作**不**用早期窗口冒充稳态判据；
登记为 honest FAIL（端到端稳态 Laplace 不达标，归因=自由面壳层膨胀），并把可判性本身修好。

## 7. 未完成 / 交接

1. **自由面壳层膨胀**（本轮定位、未修，是本仓表面张力线的真问题）：需要背景压强 /
   δ-SPH 密度扩散 / 自由面壳层的 MLS 体积修正之一，并用本 benchmark 的
   `r95(t)`、`rho_core(t)`、`p_core(t)` 三条曲线做验收（判据：t = 10 t_sigma 时
   `r95/R0 ≤ 1.05` 且后 50 % 窗 `|误差| ≤ 15 %`）。
2. **σ 扫描的稳定性边界**：σ = 14.4 在 dx = 2 mm、c0 = 20 下发散（NaN + `vmax/vref` ≈ 11）。
   需要先找稳定边界（降 c0 或加阻尼），才能评斜率判据 `d p/d sigma = 1/R`。
3. 旧 `benchmarks/csf_consistent/run.py::relax` 的量具（0.80–0.95R 波段）已在本仓保留原数值，
   但不应再被引用为 Laplace 判据；建议下轮把它的 `delta_p_measured_Pa` 标记为 deprecated
   并指向本 benchmark。
4. 本次未做分辨率扫描（`dx` 扫描需要 3× 计算量）；前 10 % 窗的 −3.1 % 是否随 dx 收敛未知。
