## 1. 案例

Langevin 动力学的 Lennard-Jones 流体（约化单位 ε=σ=m=k_B=1），BAOAB 分裂，周期边界，
既是「涨落流体热力学验证面」的底座（能量均分 / Stokes–Einstein 扩散 / Green–Kubo 粘度），
也是 PR#433 声称的 8 条验收判据 (a)–(g) 的载体。

| 参数 | 值 |
|---|---|
| 密度 ρ* | 0.8 |
| 温度 T* | 1.0（质量控制点）/ {0.5, 1, 2}（扫描）|
| 摩擦 γ | 1.0 |
| 时间步 Δt | 5e-3（生产）/ 2.5e-3 … 2e-2（收敛） |
| 粒子数 N | 64（判据）/ 128（生产夹具）/ 32（精确 FCC 格子）|
| 平衡段 | 前 40% 步（`n_eq = 0.4 n_steps`）|

m14489 审计在 HEAD 记录 4 条红：T=0 负对照、均分 1.3116（限 20%）、Δt 敏感性 21.6%（限 15%）、
`extract_viscosity_green_kubo` 在 T=0 的 `ZeroDivisionError`。本单逐条复现并定位根因。

## 3. 结果

### 3.1 缺陷 1（高）：T=0 负对照是「自证」——乘以 0.0 的伪证据

```python
# run_verification(...) 修复前
results["T0_control"] = {
    "mean_ke": result_t0.equipartition_ratio * 0.5 * dimension * 0.0,   # 恒 0
    "max_ke_per_dof": 0.0,  # should be exactly 0 —— 硬编码
}
```
测试侧同构：`max_ke = result.equipartition_ratio * 0.5 * 3 * 0.0; assert max_ke < 1e-14`
恒真；`test_t0_control_no_motion` 的 `equipartition_ratio == 0.0` 也恒真（T=0 时
`expected_ke = 0`，函数按定义返回 0.0）。报告生成器再以 `mean_ke < 1e-14` / `max_ke_per_dof < 1e-14`
判 PASS → **判据 (d)/(e) 在结构上不可能失败**，PR#433 的「T=0 无涨落已验证」属未验证声明。

实测真实值（A 组，固定 t=2）：

| Δt | 步数 | ⟨T_res⟩ | T_res/Δt² | max KE/粒子 |
|---|---|---|---|---|
| 2e-2 | 100 | 1.655e-3 | 4.14 | 3.50e-3 |
| 1e-2 | 200 | 6.772e-4 | 6.77 | 1.36e-3 |
| 5e-3 | 400 | 2.651e-4 | 10.6 | 5.64e-4 |
| 2.5e-3 | 800 | 1.092e-4 | 17.5 | 2.33e-4 |
| 1.25e-3 | 1600 | 4.416e-5 | 28.3 | 9.04e-5 |

- 残差随 Δt 单调下降，log-log 斜率 **1.31**（不是 2：格子弛豫使力的分布随 Δt 变，故不满足纯 dt² 标度）——
  「O(Δt²)」的说法**只部分成立**，本单只主张「单调下降 + 量级 1e-4」。
- 与旧判据阈值 1e-14 的差距：**10 个数量级**。旧阈值不是「严格」，而是物理上不可达。

根因（代码级）：BAOAB 的 O 子步 `if zero_temperature: velocities = 0`，随后 B 半步踢给出
`v = (Δt/2)·F/m`；采样点落在半步踢之后 → 残差是确定性的离散化人工量，不是涨落。

### 3.2 缺陷 2（中）：Green-Kubo 在 T=0 的除零

`eta_full = volume / temperature * integral` 无 T=0 保护。生产窗 >10 个 ACF 样本时抛
`ZeroDivisionError`；短窗（≤10 样本）静默返回 0，所以既有负对照「碰巧」没炸（潜伏缺陷）。
修复后：`extract_viscosity_green_kubo` 对 `temperature <= 0` 显式 `ValueError`（k_BT 归一化在
T=0 无定义），`run_lj_fluid` 在 T=0 跳过粘度估计（E2：2000 步 T=0 运行无异常，η=0.0）。

### 3.3 判据缺陷 1（中）：Δt 敏感性测的不是离散化

原判据：`Δt=5e-3`（500 步，t=2.5）vs `Δt=2.5e-3`（500 步，**t=1.25**），单 seed。两个物理时间不同，
测到的是弛豫瞬态差。

| 协议 | rel diff |
|---|---|
| 原判据（不同物理时间，1 seed） | **21.6%**（1.130 vs 1.373） |
| 相等物理时间 t=2.5，单 seed ×3 | 11.9% / 10.3% / 6.7%（均值 9.6%） |
| 相等 t=5，2 seed 集合平均 | **3.2%** |
| 相等 t=2.5，3 seed 集合平均，Δt=1e-2 vs 5e-3 | **4.7%** |

→ 21.6% 红态的主因是「比不同时间 + 单 seed 抽样噪声（理想气体单跑相对标准差 √(2/3N)=10%）」，
不是离散化误差；真正的离散化差在集合平均下约 3–5%。节点头里的「≤5%」只在集合平均下可达。

### 3.4 判据缺陷 2（中）：20% 均分门限在 t=2.5 的窗口内不可达

N=64、500 步（t=2.5 = 2.5/γ）单 seed 6 次：1.039 / 1.230 / 1.100 / 1.145 / 1.157 / 1.046
→ 均值 **1.120 ± 0.030(SE)**，理想气体单跑散度 10.2%；t=20（4000 步）：0.929 / 0.990。
温度扫描（500 步，2 seed）：

| T* | ratio (seed42 / seed7) |
|---|---|
| 0.5 | 1.315 / 1.286 |
| 1.0 | 1.130 / 1.067 |
| 2.0 | 1.090 / 0.991 |

t=10（2000 步）3 seed：0.935 / 1.002 / 1.003 → 均值 **0.980**（距 1 仅 2.0%）。
**结论**：均分定理没有被违反；红态是「压缩的 FCC 初始格子弛豫热」叠加小样本噪声，
在 T*=0.5 时最大（+29–31%），随 t 衰减。原判据把这个瞬态当成了均分违背。

## 6. 注意点 / 局限

1. **残差标度不是纯 dt²**（实测 1.31）：若日后有人按 dt² 外推会低估残差，故测试只断言单调性。
2. **T=0 的 O 子步清零是设计选择**，不是真 Langevin T=0 轨迹（真轨迹是过阻尼弛豫）。若要严格，
   应改为「在采样前不施加半步踢」或改用 BAOAB 的对称输出；本单不做数值格式变更，只把判据改成
   能反映真实观测量的形式。
3. **均分瞬态偏差与 N、初格有关**：ρ*=0.8 的 FCC 最近邻 1.21σ 是压缩构型，势能释放成动能；
   T*=0.5 时相对效应最大（+30%）。任何「短跑均分」判据都应注明 t/τ 比。
4. 集合平均把单跑 10% 的散度压到 ~2%，但**成本 ×3**：`test_temperature_dt_sensitivity` 已标 `slow`。
5. 本单未在集群上跑；负载 load15≈115 时只用单核短跑（每次 <2 min），不占控制面。
