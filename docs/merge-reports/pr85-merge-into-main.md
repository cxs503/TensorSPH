## 1. Why the PR was dirty

The PR adds the "B2 dam-break reference audit" — an audit of the experimental reference the
dam-break case is validated against. Between the PR's base and `main`, a *different* audit of
the *same* subject landed on `main` (Ritter closed form, frame bookkeeping, front-speed sweep),
together with its own artifact, document and regression tests. Both sides therefore created the
same four paths with disjoint content, which git reports as `add/add` conflicts:

| path | on `main` | on `agent/m2905` |
|---|---|---|
| `benchmarks/dam_break/reference_audit.py` | 390 lines: table integrity + Ritter identity + `c = d(Z/a)/d tau` sweep in `dx` and `wall_friction` | 312 lines: table structure (arithmetic lattice, ordinate quantum, slope levels) + kinematics + cross-source spread, no solver |
| `benchmarks/dam_break/reference_audit.json` | 1719 lines: `table_audit`, `ritter`, `table_slope`, `runs`, `figures` | 234 lines: `tables`, `grid_stats`, `cross_source_spread`, `gates`, `verdict` |
| `tests/test_dam_break_reference_audit.py` | 12 tests, importing no audit code (JSON + table guards) | 11 tests, importing `grid_stats`, `cross_source_spread`, `evaluate`, `load_bundled`, `load_crosscheck`, `_interp`, `error_vs` |
| `docs/benchmarks/dam-break-reference-audit.md` | 81 lines, generated by `make_audit_doc.py` | 125 lines, generated by `make_reference_audit_doc.py` |

The PR's remaining six files (`martin_moyce_1952_crosscheck.json`, `reference_ladder.{py,json}`,
`make_reference_audit_doc.py`, `.scratch/probe.py`, `.scratch/sim040.json`) merged cleanly.

The two sides are **complementary**, not duplicates: `main`'s half measures *the solver against*
the reference, the PR's half measures *the reference itself*. The union therefore keeps both, and
the verdicts agree (`physical_validation = withheld`, reached by independent routes).

## 2. Per-file resolution

### 2.1 `benchmarks/dam_break/reference_audit.py` — one module, both halves

Spliced by an AST-checked script (`/tmp/splice.py` run in the worktree), not retyped, so no line
of either side was paraphrased:

* docstring: rewritten as one text with **half A** (items 1–3) and **half B** (items 4–6) of the
  same audit; the `Usage` block lists both CLIs;
* imports/constants: union (`sys`, `time`, `tensorsph.dam_break`, `A`, `ASPECT`, `ORDINATE_QUANTUM`,
  `WINDOW`, `T_SECONDS` from `main`; `argparse`, `json`, `math`, `HERE` shared);
* `main`'s definitions from `audit_table` to `make_figures` are byte-identical to `main`;
* the PR's definitions from `_interp` to `evaluate` are byte-identical to the PR **except** the two
  declared edits in §2.5;
* the two `main()` drivers are replaced by **one** driver (`build_payload` + `main`) with the union
  of the CLI flags: `--sizes --frictions --seconds --json-out --plot --figdir --plot-out --from-json`
  (main) plus `--bundled --crosscheck --data-only` (PR). `--data-only` runs half B plus the
  table/Ritter checks in seconds instead of minutes;
* the single artifact is written once, with `main`'s keys first and the PR's keys appended.

AST check after splicing: 17 top-level definitions, **no duplicate names**, `ast.parse` OK.

### 2.3 `tests/test_dam_break_reference_audit.py` — both test sets in one file

union module.

### 2.4 `docs/benchmarks/dam-break-reference-audit.md` — two documents, one per generator

Kept `main`'s document at its path, unchanged (its generator `make_audit_doc.py` and its
numbers-checking test both still apply). The PR's document moved to
**`docs/benchmarks/dam-break-reference-crosssource-audit.md`**, which is what its generator now
writes (`make_reference_audit_doc.py`: `OUT` repointed, title retitled *cross-source audit*, and a
cross-link paragraph added naming the companion document).

The alternative — one file written by two independent generators — would have made the document
non-deterministic, so the split is deliberate. Regenerating the relocated document from the union
JSON reproduces the PR's own document **byte for byte apart from the retitled heading and the
cross-link** (`diff` evidence in §4), which also proves the union artifact carries the PR's numbers
unchanged.

### 2.5 Declared edits to the PR side (2 code substitutions, 1 retitle)

1. `load_bundled()` / `load_crosscheck()`: `"path": str(p)` → `"path": _repo_path(p)`, with a new
   helper `_repo_path()` that returns a repo-relative path when the file is inside the checkout.
   Reason: the committed artifacts carried absolute paths into the producing worktree
   (`/root/tp-agent/work/m2905/...`, 5 occurrences across `reference_audit.json` and
   `reference_ladder.json` — the latter gets them through the same loader). Rows, values and
   conclusions are untouched; only the path metadata becomes portable. `reference_ladder.py` also
   routes `plot_path` through `_repo_path` and imports the helper.
2. Document title retitled (§2.4).

Both substitutions are declared in `artifacts/m3958/union_verification.py`, which re-applies them
to the branch source and requires the result to equal the merged source — an *undeclared* rewrite
still counts as a loss and fails the check.

## 5. Notes, limits, and what this does **not** claim

* **Pre-existing on `main`, not caused by this merge:** the committed `table_audit` block in
  `reference_audit.json` is *not* reproducible from `main`'s own module — running `audit_table()`
  today yields a different `grade_reason` wording and no `smoothness_note` key. Both values were
  preserved as they are on `main` rather than silently rewritten; refreshing them is a separate,
  science-changing edit (it would delete `main`'s `smoothness_note`).
* The PR's `crosscheck` table is transcribed from a frozen anchor table, not from the paywalled
  original; its "independence" is therefore *value* independence only. Both audits say so.
* No solver code was touched by the merge, and no number in either audit was recomputed or
  re-tuned to make the merge look clean.
* `main`'s document claims `physical_validation = withheld`; the PR's document still quotes the
  earlier ladder verdict "physical validation fails" as history. The two are consistent in
  substance (the reference cannot arbitrate a 15 % gate) but the wording differs by document.
  Editing the older text to match was left out of scope: it is prose, not a conflict.
